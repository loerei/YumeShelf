# 01.1.2 — Database Schema, Scanner Whitelist, and Virtual Tree IPC Infrastructure

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build

Extend the main process `db.json` database schema to store `virtualTree`, `favoriteOrder`, and configuration settings (`legacyMode`, `activeWorkspaceMode`). Extend the scanner configuration whitelist and establish secure IPC channels.

## Database Schema & IPC Endpoints
```typescript
interface DatabaseSchema {
  schemaVersion?: number;                       // Monotonic integer: 0/1 (legacy), 2 (PRD 03)
  games: Record<string, any>;
  virtualTree?: VirtualFolderNode;
  favoriteOrder?: string[];
  titleResolutionConfig?: Record<string, any>;
  config: LibraryConfig & {
    legacyMode?: boolean;                         // Default: true (Legacy Mode active)
    activeWorkspaceMode?: 'favorites' | 'library'; // Default: 'library'
  };
}
```
- IPC Endpoints:
  - `get-virtual-tree` $\to$ Returns `Promise<{ tree?: VirtualFolderNode | null; favoriteOrder?: string[] }>`.
  - `save-virtual-tree` $\to$ Returns `Promise<{ ok: boolean; error?: string }>`.
  - `save-favorite-order` $\to$ Returns `Promise<{ ok: boolean; error?: string }>`.
  - `migrate-virtual-workspace` $\to$ Returns `Promise<{ ok: boolean; error?: string }>`.
