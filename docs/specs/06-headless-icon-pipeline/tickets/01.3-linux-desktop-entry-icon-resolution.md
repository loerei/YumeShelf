# 01.3 — Linux Desktop Entry Icon Resolution ($S$)

## Epic
PRD: Move Headless Icon Extraction to @yumeshelf/engine

## What to build
Implement Linux desktop entry icon resolution inside `@yumeshelf/engine` in `packages/yume-engine/src/bundle/desktop-entry.ts`. Inject parameter seams (`fs`, `env`, `targetPlatform`, `signal`) into all resolution functions. Implement strict security containment and sanitization: reject null bytes (`\0`, `%00`) and control characters in `iconVal`; resolve relative paths against `baseDir` and enforce containment within `baseDir` (rejecting `..` traversal sequences); restrict absolute paths strictly to `baseDir` or standard authorized icon search paths (`$XDG_DATA_HOME/icons`, `~/.local/share/icons`, `/usr/share/icons`, `/usr/share/pixmaps`), requiring matched paths to possess an allowed image extension (`.png`, `.svg`, `.xpm`, `.ico`, `.webp`, `.jpg`, `.jpeg`). Safely reject arbitrary system paths (such as `/etc/shadow`). Check `options?.signal?.aborted` before performing disk I/O. Implement and export `parseDesktopFileIcon`, `resolveDesktopIconPath`, `findDesktopEntryIcon`, and synchronous variants `findDesktopEntryIconSync` and `resolveDesktopIconPathSync`. Re-export from `packages/yume-engine/src/bundle/index.ts`. Implement unit test suite in `packages/yume-engine/tests/desktop-entry.test.ts` using `MockFileSystemProvider`.
