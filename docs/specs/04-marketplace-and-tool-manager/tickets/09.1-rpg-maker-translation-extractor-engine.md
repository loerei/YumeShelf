# 09.1 — RPG Maker Translation Extractor Engine Core Module (@yumeshelf/engine)

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The headless `RpgMakerExtractor` module under `packages/yume-engine/src/translation/extractors/rpg-maker/` providing high-performance, deterministic text extraction and safe JSON patching for RPG Maker MV, MZ, and VX Ace games, exported cleanly on the `YumeEngine` facade.

## Explicit Assumptions & Boundaries
- Pure Headless Architecture: Strictly resides within `packages/yume-engine/` with zero Electron, DOM, or renderer dependencies.
- Non-Destructive Patching: String extraction and injection must preserve exact JSON structure, event command codes, script variables (`\V[n]`, `\N[n]`, `\G`, `\C[n]`), and control escape sequences.

## Blocked by
- Epic 01: YumeEngine Core Extraction & 100% F95zone PE Binary Inspector

## Status
ready-for-agent

## Acceptance criteria
- [ ] Implement `RpgMakerExtractor` under `packages/yume-engine/src/translation/extractors/rpg-maker/`:
  - Support RPG Maker MV / MZ JSON data files (`data/Map*.json`, `data/CommonEvents.json`, `data/System.json`, `data/Troops.json`, `data/Actors.json`, `data/Items.json`, `data/Skills.json`).
  - Support RPG Maker VX Ace marshaled data files (`Data/Map*.rvdata2`, `Data/CommonEvents.rvdata2`, `Data/System.rvdata2`).
- [ ] Implement event command text extraction identifying dialogue and message codes:
  - Code `401`: Message text continuation.
  - Code `402`: When [**Choice**] branch.
  - Code `102`: Show Choices command list.
  - Code `108` / `408`: Event comments (optional filterable extraction).
  - Code `356`: Plugin commands containing display strings.
- [ ] Generate structured translation entries with deterministic entry keys (`${fileName}#event_${eventId}_page_${pageIndex}_cmd_${cmdIndex}_line_${lineIndex}`).
- [ ] Implement bidirectional serialization:
  - `extract(gameDir: string, options?: ExtractOptions): Promise<TranslationManifest>`: Extracts all translatable dialogue into structured key-value maps.
  - `patch(gameDir: string, translationData: TranslationManifest, options?: PatchOptions): Promise<PatchResult>`: Injects translated strings back into target JSON data files without corrupting event structure.
- [ ] Export `RpgMakerExtractor` on the `YumeEngine` facade (`packages/yume-engine/src/index.ts`).
- [ ] Comprehensive unit tests with synthetic RPG Maker map/event fixtures verifying extraction accuracy, escape code preservation, and round-trip JSON patching fidelity.
- [ ] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test` or `node --test packages/yume-engine/tests/rpg-maker-extractor.test.ts`.
