# 09.2 — RPG Maker Pre-Translator Standalone CLI & Manifest Integration

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The standalone CLI translation pipeline tool (`rpgm-pre-translator`) in its dedicated repository, importing `@yumeshelf/engine`'s `RpgMakerExtractor`, supporting multi-provider AI translation (Claude, GPT, DeepL, Google Translate), translation memory caching, rate-limited queuing, newline-delimited `json-stream` stdout progress emission, and official `rpgm-pre-translator.manifest.json` packaging for YumeShelf Marketplace compatibility.

## Explicit Assumptions & Boundaries
- Operates as a standalone CLI tool that can be run independently in terminal or executed seamlessly by YumeShelf's `TaskRunnerService` (`strategy: 'task'`).
- Streams real-time progress events over `stdout` in newline-delimited JSON (`json-stream`) format parseable by Ticket 08.1.1.

## Blocked by
- 09.1 — RPG Maker Translation Extractor Engine Core Module (@yumeshelf/engine)
- 08.1.2 — Task Runner & Queue Execution Engine

## Status
ready-for-agent

## Acceptance criteria
- [ ] Initialize standalone Node/TypeScript project (`rpgm-pre-translator`) importing `@yumeshelf/engine` as a core dependency.
- [ ] Implement CLI argument parser supporting options interpolated from YumeShelf task runner:
  - `--game-dir <path>`: Target game root directory.
  - `--target-lang <lang>`: Target language code (e.g. `vi`, `en`, `zh`).
  - `--source-lang <lang>`: Source language code (default `ja`).
  - `--provider <name>`: Translation provider (`claude`, `openai`, `deepl`, `google`).
  - `--api-key <key>`: Decrypted API key from YumeShelf credential vault.
  - `--batch-size <n>`: Batch prompt sizing for dialogue line grouping.
- [ ] Implement translation pipeline:
  - Extract translatable text via `yumeEngine.rpgMakerExtractor.extract(gameDir)`.
  - Check local translation cache (`.translation-cache.json`) to skip already translated phrases.
  - Dispatch uncached lines to configured AI provider with prompt templates preserving RPG Maker variable placeholders (`\V[n]`, `\N[n]`, `\G`).
  - Patch translated results back into game data files via `yumeEngine.rpgMakerExtractor.patch(gameDir, translatedData)`.
- [ ] Implement stdout stream progress emitter outputting newline-delimited JSON (`json-stream`):
  - Emits `{"percent": 45, "step": "Map005.json (45/100)", "message": "Translating dialogues"}\n`.
- [ ] Author and validate official `rpgm-pre-translator.manifest.json`:
  - `strategy: 'task'`.
  - `engineCompatibility: ['RPGM', { tag: 'RPGM', variants: ['mv', 'mz', 'vx-ace'] }]`.
  - Declare actions (`extract`, `translate`, `revert`).
  - Declare `configSchema` and `credentialsSchema` for API key management.
- [ ] CLI entry point supports receiving LLM / translation API keys via standard environment variables (`OPENAI_API_KEY`, `DEEPL_AUTH_KEY`, `GEMINI_API_KEY`, or `YUMESHELF_CREDENTIAL_*`) in addition to `--api-key` CLI options, prioritizing environment variables to prevent secret leakage in process tables when spawned by `TaskRunnerService`.
- [ ] Unit & end-to-end CLI integration tests verifying argument parsing, cache hits, stdout stream formatting, and mock AI translation workflows.
- [ ] Execute automated tests via `npm test`.
