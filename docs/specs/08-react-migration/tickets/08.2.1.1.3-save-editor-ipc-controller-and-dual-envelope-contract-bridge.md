1. **Save Editor IPC Controller (`src/main/ipc/controllers/save-editor.controller.ts`)**:
   - Maintain strict architectural layering: `save-editor:load-data` delegates to `saveEditorService.loadSaveData(gameKey, fileName, sanitizedOptions)`.
   - Safe filename validator:
     ```typescript
     const SAFE_FILENAME_REGEX = /^(?!(?:CON|PRN|AUX|NUL|COM[0-9]|LPT[0-9])(?:\..*)?$)[^\\/:*?"<>|\x00-\x1f]+(?<![. ])$/i;
     ```
   - Enforce channel-differentiated ingress parameter validation matching declared return contracts:
     - `save-editor:load-data`: validate `gameKey` as a non-empty string without path traversal slashes ('/', '\') or prototype pollution identifiers, and validate `fileName` against `SAFE_FILENAME_REGEX`. On invalid input, log `console.warn` and throw `new Error('invalid-payload')`. Wrap service execution in `try ... catch`, emit structured diagnostics via `console.error('[IPC][save-editor:load-data] Failed to load save file:', { gameKey: sanitizeUserPaths(gameKey), fileName, error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)), stack: err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined })`, and rethrow `new Error(sanitizeUserPaths(err instanceof Error ? err.message : String(err)))`.
     - `save-editor:list-files`: validate `gameKey` as non-empty string without prototype pollution identifiers; throw `new Error('invalid-payload')` on failure. Strip procedural unredacted `console.log` statements. Wrap service execution in `try ... catch`, emit structured failure diagnostics via `console.error('[IPC][save-editor:list-files] Failed to list save files:', ...)` routing `gameKey`, `error`, and `stack` through `sanitizeUserPaths`, and rethrow `new Error(sanitizeUserPaths(rawMsg))`.
     - `save-editor:cancel-load`: on invalid parameters, resolve `{ cancelled: false }`.
     - `save-editor:rename-file` and `save-editor:delete-file`: validate `gameKey` without traversal slashes and validate `fileName`/`oldFileName`/`newFileName` against `SAFE_FILENAME_REGEX`. On failure, resolve `{ ok: false, error: 'invalid-payload' }` without invoking service. Strip procedural unredacted `console.log` statements. Wrap service execution in `try ... catch`, emit structured diagnostics via `console.error('[IPC][save-editor:rename-file]' / '[IPC][save-editor:delete-file]')` with `gameKey`, `fileName`/`oldFileName`/`newFileName`, `error`, and `stack` routed through `sanitizeUserPaths`, and rethrow `new Error(sanitizeUserPaths(rawMsg))`.
     - `save-editor:write-data`:
       - Validate `gameKey` as a non-empty string without path traversal slashes ('/', '\') or prototype pollution identifiers, and validate `fileName` against `SAFE_FILENAME_REGEX`.
       - Terminal guard: reject incoming payloads that provide neither `updates` nor `data` (`if (updates === undefined && data === undefined)`), logging structured `console.warn` and resolving `{ ok: false, error: 'invalid-payload' }` rather than falling through or returning `undefined`.
       - When `payload.updates !== undefined` (modern React Save Editor path):
         - Validate envelope against `options.isUpdates`: if `sanitizedOptions.isUpdates === false`, emit structured warning log via `console.warn('[IPC][save-editor:write-data] Rejecting mismatched write envelope and isUpdates option:', { abort_reason: 'ENVELOPE_OPTION_MISMATCH', envelope: 'updates', optionIsUpdates: sanitizedOptions.isUpdates, gameKey: sanitizeUserPaths(gameKey), fileName: sanitizeUserPaths(fileName) })` and resolve `{ ok: false, error: 'invalid-payload' }` without calling `saveEditorService.writeSaveData`. Otherwise pin `sanitizedOptions.isUpdates = true`.
         - On malformed payload, resolve `{ ok: false, error: 'invalid-payload' }`.
         - Strip prototype pollution keys (`__proto__`, `constructor`, `prototype`) across `tabId`, `fieldKey`, and dotted segments. Enforce scalar primitives only (`null`, boolean, string, finite number):
           ```typescript
           const DANGEROUS_KEYS = new Set(['__proto__', 'constructor', 'prototype']);
           const QUALIFIED_KEY_REGEX = /^[a-zA-Z0-9_-]+:[^\0\r\n\t]+$/;

           const sanitizedUpdates: Record<string, any> = Object.create(null);
           for (const [rawKey, value] of Object.entries(payload.updates)) {
             if (typeof rawKey !== 'string' || !QUALIFIED_KEY_REGEX.test(rawKey)) {
               continue;
             }

             const colonIdx = rawKey.indexOf(':');
             const tabId = rawKey.slice(0, colonIdx);
             const fieldKey = rawKey.slice(colonIdx + 1);

             if (
               DANGEROUS_KEYS.has(tabId) ||
               DANGEROUS_KEYS.has(fieldKey) ||
               fieldKey.split('.').some((seg) => DANGEROUS_KEYS.has(seg))
             ) {
               continue;
             }

             const isScalar =
               value === null ||
               typeof value === 'boolean' ||
               typeof value === 'string' ||
               (typeof value === 'number' && Number.isFinite(value));

             if (!isScalar) {
               continue;
             }

             sanitizedUpdates[rawKey] = value;
           }
           ```
         - If incoming `payload.updates` is truly empty (`{}`), resolve `{ ok: true }` as a benign safe no-op without invoking service.
         - If incoming updates were non-empty but all keys were stripped, log structured warning with `abort_reason: 'ALL_KEYS_STRIPPED'` and resolve `{ ok: false, error: 'invalid-payload' }`.
         - Wrap service invocation in `try ... catch`, emit structured diagnostic log to `console.error('[IPC][save-editor:write-data] Write save data failed:', ...)` with `gameKey`, `fileName`, `error`, `code`, and `stack` routed through `sanitizeUserPaths`, and resolve `{ ok: false, error: sanitizedErrorMsg, ...(errorCode ? { code: errorCode } : {}) }`, preserving Node.js system error codes (`EBUSY`, `EACCES`, `ENOENT`).
       - When `payload.updates` is omitted and legacy `payload.data` is provided (legacy coexistence fallback):
         - Validate envelope against `options.isUpdates`: if `sanitizedOptions.isUpdates === true`, emit structured warning log via `console.warn('[IPC][save-editor:write-data] Rejecting mismatched write envelope and isUpdates option:', { abort_reason: 'ENVELOPE_OPTION_MISMATCH', envelope: 'data', optionIsUpdates: sanitizedOptions.isUpdates, gameKey: sanitizeUserPaths(gameKey), fileName: sanitizeUserPaths(fileName) })` and throw `new Error('invalid-payload')` without calling `saveEditorService.writeSaveData`. Otherwise pin `sanitizedOptions.isUpdates = false`.
         - Validate `gameKey` and `fileName`. Re-throw errors (`throw err`) on failure so legacy view controllers catch the rejection in their `catch` block.
     - `save-editor:load-translations` and `save-editor:save-translations`:
       - `load-translations`: validate `lang` with BCP-47 regex; emit `console.warn` with `sanitizeUserPaths(lang)` on invalid tag and return `{}` cleanly without throwing.
       - `save-translations`: validate BCP-47 tag, enforce max 10,000 entries, strip prototype keys, enforce key length $\le 300$ and value length $\le 4096$, allow slashes in variable keys, resolve `{ ok: true }` on empty `{}`, resolve `{ ok: false, error: 'invalid-payload' }` with `ALL_KEYS_STRIPPED` warning when all keys are stripped, catch errors and resolve `{ ok: false, error: sanitizedErrorMsg }` routing messages through `sanitizeUserPaths`.
     - `save-editor:set-save-folder-override`:
       - Accept `{ gameKey: string; folderPath: string | null }`, normalizing `null` or `""` to `""` before calling `libraryState.setSaveFolderOverride(gameKey, "")` to cleanly reset overrides, and rejecting non-string/non-null payloads with `{ ok: false, error: 'invalid-payload' }`.
