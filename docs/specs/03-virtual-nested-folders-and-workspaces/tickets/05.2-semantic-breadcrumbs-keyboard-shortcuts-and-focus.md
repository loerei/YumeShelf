## What to build

A semantic breadcrumb navigation bar rendered directly below the header when inside a folder, supporting 1-click ancestor navigation, keyboard shortcuts (`Escape`, `Backspace`), and automatic focus restoration to exited folder cards.

## Acceptance criteria

- [ ] Mount breadcrumb items into the pre-mounted `refs.breadcrumbsBar` container (`08.1`), rendering semantic breadcrumb navigation (`<ol><li>...</li></ol>`, marking active crumb with `aria-current="page"`) directly below the header bar ONLY when `activeWorkspaceMode === 'library'` AND `currentPath.length > 0`. Ensure breadcrumb item labels are set via `textContent` or HTML entity escaping to prevent XSS injection. When switching to "Favorite Desk", hide the breadcrumb bar container (`display: none`), preserving `currentPath` in memory.
- [ ] Clicking any ancestor item in the breadcrumb bar immediately navigates the grid in-place to that ancestor level.
- [ ] Pressing `Escape` or `Backspace` while inside a folder navigates up one level in the hierarchy (`pop()` active path), protected by comprehensive input, modifier, modal presence, non-element target, overlay/dropdown, and workspace mode guards:
  ```typescript
  function handleKeyDown(event: KeyboardEvent): void {
    if (event.defaultPrevented) return;
    // 1. Workspace mode gating: never pop preserved path when on Favorite Desk
    if (state.getActiveWorkspaceMode() !== 'library') return;

    // 2. System shortcut modifier guard: do not intercept Ctrl+Escape, Alt+Backspace, etc.
    if (event.altKey || event.ctrlKey || event.metaKey || event.shiftKey) return;

    // 3. Modal / dropdown active presence guard: protect against un-trapped focus on document.body or backdrop
    const isAnyModalOrMenuOpen = Boolean(
      document.querySelector(
        '.settings-overlay.show, .settings-overlay[style*="display: flex"], .stack-overlay.show, .stack-overlay[style*="display: flex"], .save-editor-overlay, .dropdown-menu.show, dialog[open], [role="dialog"]'
      )
    );
    if (isAnyModalOrMenuOpen) return;

    const target = event.target as EventTarget | null;

    // 4. Non-Element target normalization: guard against document / window targets throwing on closest()
    const element = target instanceof Element
      ? target
      : (target instanceof Node ? target.parentElement : null);

    // 5. Form input expansion: do not intercept Backspace while user is typing (including <select>)
    const isTextInput = Boolean(
      element?.closest('input, textarea, select, [contenteditable="true"]') ||
      element?.classList?.contains('folder-rename-input')
    );
    if (isTextInput) return;

    // 6. Modal, overlay, and dropdown menu isolation: do not intercept Escape/Backspace inside dialogs or menus
    const isInsideOverlayOrMenu = Boolean(
      element?.closest(
        '.settings-overlay, .stack-overlay, #duplicate-stack-overlay, .save-editor-overlay, .modal-overlay, .dropdown-menu, dialog, [role="dialog"]'
      )
    );
    if (isInsideOverlayOrMenu) return;

    // 7. Active global search guard: do not pop breadcrumbs on Escape when search query is active
    if (refs.searchInput && refs.searchInput.value.trim().length > 0) return;

    if (event.key === 'Backspace' || event.key === 'Escape') {
      const currentPath = state.getCurrentPath();
      if (currentPath.length > 0) {
        event.preventDefault();
        const nextPath = currentPath.slice(0, -1);
        state.setCurrentPath(nextPath);
      }
    }
  }
  ```

  5. Pressing `Ctrl+Escape`, `Alt+Backspace`, or `Ctrl+Backspace` does NOT pop `currentPath` and does NOT call `event.preventDefault()`.
