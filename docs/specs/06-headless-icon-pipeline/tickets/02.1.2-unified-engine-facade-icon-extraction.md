## What to build
Implement unified icon extraction facade `extractGameIcon` in `packages/yume-engine/src/icon/icon-extractor.ts`. Export domain interfaces `ExtractedGameIcon` and `ExtractIconOptions` (including `preferLocalArtwork?: boolean; maxArtworkSize?: number; maxRsrcSize?: number; timeoutMs?: number; signal?: AbortSignal; fs?: IFileSystem; env?: IEnvironmentPaths; targetPlatform?: NodeJS.Platform;`). Wrap pipeline execution in `withTimeout` with `fallbackValue: null` to return `null` safely upon timeout or cancellation. Implement Priority 1 (Local Artwork Candidates): if `preferLocalArtwork !== false`, call `findLocalGameImage(targetPath, { fs, env, targetPlatform, signal, maxArtworkSize: options?.maxArtworkSize, maxRsrcSize: options?.maxRsrcSize })`, inspect candidate with pre-read file size check `stat.size <= (options?.maxArtworkSize ?? options?.maxRsrcSize ?? DEFAULT_MAX_ARTWORK_SIZE)`, read buffer into memory, and return `ExtractedGameIcon` tagged with `source: 'local-image'` or `'desktop-entry'`. Implement Priority 2 (Executable Binary Resources): for Windows PE binaries, delegate to `extractPeIconAsync(targetPath, { fs, signal, maxRsrcSize: options?.maxRsrcSize })` forwarding parameter seams (`fs`, `signal`, `maxRsrcSize`); for macOS `.app` bundles, delegate to `findAppBundleIcon(targetPath, { fs, signal, maxArtworkSize: options?.maxArtworkSize, maxRsrcSize: options?.maxRsrcSize })`, checking `bundleIcon.ext === 'png'` to preserve PNG format and MIME type. Re-export extraction functions and types from `packages/yume-engine/src/icon/index.ts`. Re-export canonical types from `packages/yume-engine/src/types.ts`. Expose facade methods `YumeEngine.extractIcon`, `extractPeIcon`, and `extractPeMetadata` in `packages/yume-engine/src/index.ts`. Add unit test suite in `packages/yume-engine/tests/icon-extractor.test.ts` using `MockFileSystemProvider`.

- Implement `extractGameIcon(targetPath: string, options?: ExtractIconOptions | IFileSystem): Promise<ExtractedGameIcon | null>`:
  - Normalize options to extract `fs` (supporting direct `IFileSystem` or `{ fs, env, ... }`, defaulting to `NodeFileSystemProvider`), `env` (`(options && 'getXdgDataHome' in options ? options : (options && !('open' in options) ? options.env : undefined)) ?? new StandardEnvironmentPaths()`), `targetPlatform` (defaulting to `process.platform`), `preferLocalArtwork` (defaulting to `true`), `signal`, `timeoutMs`, `maxRsrcSize`, and `maxArtworkSize`.
  - Wrap internal extraction cascade with `withTimeout`, catching unexpected internal extraction exceptions to safely return `null` instead of unhandled rejections (where `withTimeout` schedules no timer when `options.timeoutMs` is omitted or undefined, preventing premature 0ms timeout):
    ```typescript
    const safeInternalExtract = async () => {
      try {
        return await internalExtract(targetPath, normalizedOptions);
      } catch {
        return null;
      }
    };
    return await withTimeout(
      safeInternalExtract(),
      {
        timeoutMs: normalizedOptions.timeoutMs,
        signal: normalizedOptions.signal,
        fallbackValue: null
      }
    );
    ```
  - Orchestrate extraction cascade following priority hierarchy:
    1. **Priority 1: Local Artwork Candidates**: If `preferLocalArtwork !== false`, call `findLocalGameImage(targetPath, { fs, env, targetPlatform, signal, maxArtworkSize: options?.maxArtworkSize, maxRsrcSize: options?.maxRsrcSize })`. Forward size constraints to avoid oversized reads into memory. If a candidate is found, wrap file inspection and reading in a `try...catch` block to cleanly fall through to Priority 2 on `ENOENT`, `EACCES`, file locks, or empty placeholder files:
       ```typescript
       try {
         const stat = await fs.stat(localImg.imgPath);
         if (!stat.isFile() || stat.size <= 0 || stat.size > (options?.maxArtworkSize ?? options?.maxRsrcSize ?? DEFAULT_MAX_ARTWORK_SIZE)) {
           // Skip oversized, empty (0-byte), or non-file candidate, fall through to Priority 2
         } else {
           const raw = await fs.readFile(localImg.imgPath);
           return {
             buffer: Buffer.isBuffer(raw) ? raw : Buffer.from(raw),
             mimeType: getImageMimeType(localImg.ext),
             isPng: localImg.ext.toLowerCase() === 'png' || getImageMimeType(localImg.ext) === 'image/png',
             source: localImg.source ?? 'local-image',
             filePath: localImg.imgPath
           };
         }
       } catch {
         // Cleanly catch read/lock errors and fall through to Priority 2
       }
       ```
    2. **Priority 2: Executable Binary Resources**: If no local artwork is found (or if `preferLocalArtwork === false`):
       - On macOS / `.app` bundles (`resolveBundleRoot(targetPath)` or `targetPath.toLowerCase().endsWith('.app')`): invoke `findAppBundleIcon(targetPath, { fs, signal, maxArtworkSize: options?.maxArtworkSize, maxRsrcSize: options?.maxRsrcSize })`. If resolved, check `bundleIcon.ext`:
         ```typescript
         const isPng = bundleIcon.ext === 'png';
         return {
           buffer: bundleIcon.buffer,
           mimeType: isPng ? 'image/png' : 'image/x-icns',
           isPng,
           format: isPng ? 'png' : 'icns',
           source: 'app-bundle'
         };
         ```
       - On Windows / PE binaries (`targetPath.toLowerCase().endsWith('.exe')` or when target platform is `win32` without being a macOS `.app` bundle): call `extractPeIconAsync(targetPath, { fs, signal, maxRsrcSize: options?.maxRsrcSize ?? options?.maxArtworkSize, maxResourceEntries: options?.maxResourceEntries, maxRecursionDepth: options?.maxRecursionDepth, maxIconFrames: options?.maxIconFrames })` forwarding parameter seams:
         ```typescript
         const peIcon = await extractPeIconAsync(targetPath, {
           fs,
           signal,
           maxRsrcSize: options?.maxRsrcSize ?? options?.maxArtworkSize,
           maxResourceEntries: options?.maxResourceEntries,
           maxRecursionDepth: options?.maxRecursionDepth,
           maxIconFrames: options?.maxIconFrames
         });
         if (peIcon && peIcon.buffer) {
           return {
             buffer: peIcon.buffer,
             mimeType: peIcon.isPng ? 'image/png' : 'image/x-icon',
             isPng: peIcon.isPng,
             format: peIcon.isPng ? 'png' : 'ico',
             source: 'pe-resource',
             width: peIcon.width,
             height: peIcon.height
           };
         }
         ```
    3. Return `null` if no priority produces an icon.
