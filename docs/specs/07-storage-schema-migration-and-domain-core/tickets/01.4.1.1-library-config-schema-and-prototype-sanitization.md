## Epic
[PRD: Storage Schema Migration & Library Domain Core](file:///d:/Projects/YumeShelf/docs/specs/07-storage-schema-migration-and-domain-core/PRD.md)

## What to build
Extend `LibraryConfig` interface in `src/main/library-state/scanner.ts` with `folderAliases?: Record<string, string>` mapping canonical folder paths to user display names. Update `normalizeLibraryConfigShape` in `scanner.ts` to accept an explicit parameter seam `targetPlatform?: PlatformInput` (`export function normalizeLibraryConfigShape(config: any, targetPlatform?: PlatformInput): LibraryConfig`), defaulting to `resolvePlatform(targetPlatform)`, and safely sanitize and normalize `folderAliases` and `libraryPaths`: filter out entries from `libraryPaths` that are non-strings, empty strings, contain illegal control characters or null bytes (`/\0|\r|\n/.test(p)`) emitting structured security warning `console.warn('[SECURITY][CONFIG_PATH_INJECTION] Omitted invalid library path containing illegal characters:', { path: p })`, or evaluate to canonical filesystem root paths unconditionally (`canonicalPath === '/' || /^[A-Za-z]:\/?$/.test(canonicalPath)` where `canonicalPath = normalizePathForPlatform(p, targetPlatform)`) logging structured diagnostic warning `console.warn('[SECURITY][CONFIG] Blocked configuration of filesystem root as library path:', { targetPath: p })`; sanitize and canonically deduplicate valid `libraryPaths` on read/normalization using `seen: Set<string>` keyed by `canonicalPath` while preserving the authentic casing and platform path separators of each surviving element in the returned `libraryPaths` array (storing the trimmed string with non-root trailing slashes stripped, `p.trim().replace(/[\\/]+$/, '')`, rather than overwriting elements with the lowercased forward-slash output of `normalizePathForPlatform`), so legacy configs on disk containing duplicate, trailing-slash, or case-variant paths normalize into a unique array without duplicates while preserving authentic host path strings; guard against prototype pollution by rejecting/stripping `__proto__`, `constructor`, `prototype`, and inherited `Object` properties across BOTH the raw key (`key`) AND the post-normalization `canonicalKey = normalizePathForPlatform(key, targetPlatform)` (`if (!canonicalKey || canonicalKey === '__proto__' || canonicalKey === 'constructor' || canonicalKey === 'prototype' || /\0|\r|\n/.test(key)) continue;`, blocking relative/case-variant/trailing-slash bypasses such as `./__proto__`, `foo/../constructor`, `__PROTO__`, and `prototype/`, as well as illegal control characters and null bytes), defensively enforce type verification or safe string coercion on alias values (`const rawAlias = typeof val === 'string' ? val : '';`) before applying string methods, bound alias string values to a maximum of 255 characters, strip non-printable and newline control characters (`[\r\n\t\x00-\x1f]`), trim string keys and values, prune any key whose trimmed alias evaluates to empty string `""` or whose value is non-string without throwing exceptions, normalize dictionary keys via `normalizePathForPlatform(key, targetPlatform)` stripping non-root trailing slashes for canonical key indexing, and always populate `folderAliases` as a guaranteed `Record<string, string>` defaulting to `{}` when omitted or invalid.

Author comprehensive Vitest unit tests in `src/main/library-state/config.test.ts`.
