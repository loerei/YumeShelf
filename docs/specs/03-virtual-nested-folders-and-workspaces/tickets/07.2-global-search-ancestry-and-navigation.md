## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
A global search query engine in `[NEW] src/renderer/search/global-search.ts` operating across all nested virtual folders in the library (preserving legacy `src/renderer/search.ts` for Legacy Mode), featuring regex query sanitization, parent ancestry path badges, dedicated zero-match empty state banner, drill-down location restoration upon clearing search, and implementing the decoupled `SearchStrategy` lifecycle interface (`attach()` / `detach()`).

## Acceptance criteria
- [ ] Implement search input query engine in `[NEW] src/renderer/search/global-search.ts` operating globally across all games in the library regardless of current folder depth, leaving legacy `src/renderer/search.ts` intact for Legacy Mode.
- [ ] Sanitize search queries and match highlighting by escaping regex metacharacters (`query.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) or utilizing case-insensitive substring searching (`String.prototype.includes` / `indexOf`) and safe string splitting to prevent unhandled `SyntaxError` crashes when queries contain regex special characters. Construct match highlighting DOM nodes safely using `document.createElement('mark')` and `document.createTextNode()`, or pass all non-matching string segments through `escapeHtml(...)` before template assembly to prevent DOM-based XSS.
- [ ] Display parent ancestry path badges on search result cards (e.g. `In: Visual Novels / Key`) indicating the containing virtual folder path, escaping folder names via `textContent` or HTML entity encoding to prevent XSS injection.
- [ ] Render a dedicated empty state banner when 0 results match ("No games found matching '{query}'. Press Escape to clear search"), setting the query string via `textContent` or HTML entity encoding to prevent reflected XSS.
- [ ] Formally define `GlobalSearchControllerOptions` in `src/renderer/search/global-search.ts` (consuming `SearchStrategy` from `src/renderer/types/search.ts`):
  ```typescript
  export interface GlobalSearchControllerOptions {
    state: UiRuntimeState;
    refs: Pick<RendererRefs, 'searchInput' | 'virtualFolderContainer' | 'breadcrumbsBar'>;
    clock?: IClock;
    debounceMs?: number;
    showToastPillFn?: (message: string) => void;
  }
  ```
  Implement `createGlobalSearchController` accepting `GlobalSearchControllerOptions` and implementing `SearchStrategy` (`attach(): void`, `detach(): void`), exposing `dispose(): void`:
  - When a search query is active (`query.trim().length > 0`), hide `refs.breadcrumbsBar` (`display = 'none'`) and render matching cards (decorated with ancestry badge `<div class="search-ancestry-badge">In: ...</div>` constructed via `findAncestryPath`) directly into `refs.virtualFolderContainer`.
  - When 0 results match, render the empty state banner directly into `refs.virtualFolderContainer`.
  - When search is cleared (empty input or `Escape`), restore `refs.breadcrumbsBar` (if `state.getCurrentPath().length > 0`) and trigger grid view re-rendering at the pre-search `state.getCurrentPath()`.
  - `attach()` binds debounced `input` listener to `refs.searchInput`.
  - `detach()` unbinds event listeners, clears active debounce timers, and resets active search query state.
  - `dispose()` calls `detach()`.
- [ ] Wire `createGlobalSearchController({ state, refs, clock, debounceMs })` into `src/renderer/bootstrap/app-composition.ts` (`createRendererComposition`), instantiating the controller and passing it to `settingsLegacyToggleController` under `searchStrategies.global`.
- [ ] Unit and component tests in `src/renderer/search/global-search.test.ts` verifying search query regex sanitization, match highlighting safe DOM/HTML entity escaping, zero-result banner rendering in `refs.virtualFolderContainer`, ancestry path badge formatting, drill-down location restoration, `attach()` and `detach()` lifecycle binding/unbinding, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated search ancestry tests via `npm run test:vitest -- src/renderer/search/global-search.test.ts` with standard output containing `'✓ renderer/search/global-search.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
