## What to build
Mount the 1-click header SVG toggle between Favorite Desk and Library mode, persist `activeWorkspaceMode` in `db.config` via IPC, and render Favorite Desk as a flat grid showing only favorited games with independent sort presets and an onboarding empty state.

## Acceptance criteria
- [ ] Mount 1-click SVG toggle icon in the header bar binding to `refs.workspaceToggleBtn` (`08.1`) to switch between Favorite Desk and Library mode, respecting legacy mode visibility toggling (`08.2`).
- [ ] Persist `activeWorkspaceMode: 'favorites' | 'library'` in `db.config` via `electronAPI.updateLibraryConfig`.
- [ ] In `src/renderer/views/folder-grid-view.ts`, extend `reSortAndRender()` to inspect `state.getActiveWorkspaceMode()`: when `'favorites'`, filter `state.getAllGames()` for `favorite === true`, sort by canonical keys in `favoriteOrder` when sort preset is `'custom'` (or standard sort presets), and render standard game cards without folder cards.
- [ ] Implement independent sort presets on Favorite Desk without affecting Library folder structures.
- [ ] Synchronize client-side `UiRuntimeState.favoriteOrder` immediately in-memory using canonical physical game keys (appending on favorite, removing on un-favorite) upon optimistic favorite toggles so Favorite Desk updates ordering instantaneously without requiring application reload.
- [ ] Implement `createWorkspaceViewsController` reading initial mode from `state.getActiveWorkspaceMode()` and exposing `dispose(): void` to unbind toggle button listeners and clean up workspace observers.
- [ ] Wire `createWorkspaceViewsController` into `src/renderer/bootstrap/app-composition.ts` (`createRendererComposition`), binding DOM refs, state accessors, and lifecycle teardown.
- [ ] In `src/renderer/views/folder-grid-view.test.ts`, author component test cases verifying that when `activeWorkspaceMode` is `'favorites'`, `createVirtualizedGridController` filters `state.getAllGames()` for `favorite === true`, sorts items according to canonical physical keys in `favoriteOrder` when sort preset is `'custom'` (or standard sort presets), and suppresses rendering of folder cards.
- [ ] Author component unit tests in `src/renderer/controllers/workspace-views.test.ts` verifying workspace mode toggling, independent sorting presets, empty state rendering, in-memory `UiRuntimeState.favoriteOrder` synchronization, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated unit and component tests via `npm run test:vitest -- src/renderer/controllers/workspace-views.test.ts src/renderer/views/folder-grid-view.test.ts` with standard output containing `'✓ renderer/controllers/workspace-views.test.ts'` and `'✓ renderer/views/folder-grid-view.test.ts'` with exit code 0.
