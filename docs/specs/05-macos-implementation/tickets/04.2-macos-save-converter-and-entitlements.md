# 04.2 — macOS Save Converter Packaging & Hardened Runtime

## Epic
PRD: Implementation for macOS Platform Support (In Progress - Beta Released)

## What to build

Include the cross-compiled `ModernSaveConverter` binary for macOS in packaged application bundles under `extraResources` once Ticket 03 is completed. If an Apple Developer certificate is acquired in the future, configure entitlements (`entitlements.mac.plist`) and hardened runtime in `package.json` for Gatekeeper notarization.

## Acceptance criteria

- [ ] Ensure packaged macOS builds include native `ModernSaveConverter` binaries in `extraResources` / `asarUnpack` once Ticket 03 is resolved.
- [ ] Configure `entitlements.mac.plist` and hardened runtime settings in `package.json` (`hardenedRuntime: true`, `gatekeeperAssess: false`) when signing certificates are configured.
- [ ] Verify save converter execution from inside packaged macOS DMG / app bundle in CI or test environment.
