## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement `src/renderer/library/shelf-tabs.ts` for managing the horizontal Variant C segmented shelf tabs bar (`#shelf-tabs-wrapper`):
1. Coordinator factory:
   `createShelfTabsController(options: { container: HTMLElement; electronAPI: any; getLibraryConfig: () => any; targetPlatform?: PlatformInput; onTabReorder?: (oldOrder: string[], newOrder: string[], movedPath?: string) => Promise<void> | void; onTabSelect?: (tabId: string) => void; onConfigUpdated?: (config: any) => void; animationDuration?: number; fallbackTolerance?: number; overflowThreshold?: number; i18n?: (key: string) => string; showToastPill?: (text: string) => void; sortableFactory?: { create: (element: HTMLElement, options?: any) => any; get?: (element: HTMLElement) => any; }; resizeObserverFactory?: { new (cb: ResizeObserverCallback): ResizeObserver }; scheduleAnimation?: (cb: () => void) => any; cancelAnimation?: (handle: any) => void; })`
   Defaulting `sortableFactory` to imported `Sortable` and `resizeObserverFactory` to `globalThis.ResizeObserver` (with defensive fallback to window `resize` event listeners guarded by `typeof window !== 'undefined'` or initial static evaluation when `typeof ResizeObserver === 'undefined'`) to provide seamless testability in headless Vitest environments without JSDOM. Prohibit accessing ambient globals (`(window as any).electronAPI`).
2. Public lifecycle and query interface:
   - `updateTabs(sections?: any[], activeTabId?: string, favoritesCount?: number): void`: caches arguments in internal controller state (`cachedSections`, `cachedActiveTabId`, `cachedFavoritesCount`) on each invocation, updates tab elements, badges, active styling, and refreshes the horizontal SortableJS instance. When called with partial or no arguments (such as during error rollback or live inline rename synchronization), it re-renders using the cached arguments without arity or type errors, dynamically resolving folder tab display names on every tab rendering pass by extracting the folder path supporting both `.path` and `.folderPath` (`const folderPath = section.path || section.folderPath;`), canonicalizing the lookup key via `normalizePathForPlatform(folderPath, options.targetPlatform)`, checking own-properties on `options.getLibraryConfig()?.folderAliases`, and resolving via `(folderAliases && Object.prototype.hasOwnProperty.call(folderAliases, normalizedKey) && folderAliases[normalizedKey]?.trim()) ? folderAliases[normalizedKey].trim() : getFolderBaseName(folderPath)` to eliminate stale label persistence and prevent resurrecting cleared aliases from cached section objects. Symmetrically with `path-dnd.ts`, ensures any pre-existing Sortable instance on `scrollable` is safely destroyed via `Sortable.get(scrollable)?.destroy()` prior to creating `Sortable.create(scrollable)`, preventing listener leaks across render passes. Focus Continuity: Updates tab elements, text labels, badges, and attributes in-place using stable, immutable folder path keys without unmounting or detaching focused tab elements, preserving existing tab DOM nodes across render cycles. Tab DOM elements must only be created or removed when the set of configured paths changes, maintaining roving `tabindex` continuity across inline folder rename synchronizations, configuration refreshes, and order failure rollbacks without querying the DOM for activeElement after rendering.
   - Zero-favorite fallback rule: when `activeTabId === 'fav'` and `favoritesCount === 0`, automatically transitions active tab to `'all'` ("All Folders") and invokes `options.onTabSelect?.('all')`, returning the user to the "All Folders" accordion view when the last favorite is removed. If keyboard focus was on `#shelf-tab-fav`, anchors and restores focus to `#shelf-tab-all`, preserving roving `tabindex` continuity without focus eviction to `document.body`.
   - `getActiveTab(): string`: returns the currently active tab ID.
   - `destroy(): void`: cancels any pending scroll measurement frame (`if (scrollRafId !== null) { if (typeof cancelAnimationFrame !== 'undefined') { cancelAnimationFrame(scrollRafId); } else { options.cancelAnimation?.(scrollRafId); } scrollRafId = null; }`), invokes `sortable.destroy()`, disconnects `ResizeObserver`, and symmetrically detaches event listeners (including window resize listeners if attached).
   - `handleTabDragEnd: (evt: any) => Promise<void> | void`: exposes the drag end drop handler on the controller interface to enable headless unit testing of tab reordering, identity guards, and transactional rollback without private state hacking.
3. State & DOM XSS Prevention:
   - Maintains authoritative folder path order in controller state (`currentFolderOrder: string[]`, populated during `updateTabs`).
   - All user-controlled folder display names, aliases, and titles MUST be rendered into the DOM using safe DOM text bindings (`tabTitle.textContent = ...`) or context-aware HTML escaping (`escapeHtml`). Direct interpolation into `innerHTML` or HTML template literals is strictly prohibited.
4. Renders "All Folders", "Favorites" (if `favoritesCount > 0`, rendered with an accessible inline vector SVG star icon with `aria-hidden="true"` and `currentColor` / gold styling, strictly banning raw Unicode emoji glyphs), and draggable folder tabs with count badges according to WAI-ARIA Tabs pattern:
   - The tabs container element (`scrollable`) must have `role="tablist"` and `aria-label="Shelf folders"`.
   - Individual tab elements have `role="tab"`, dynamic `aria-selected="true"` for the active tab and `aria-selected="false"` for inactive tabs, `aria-controls="game-grid-wrapper"`, and a deterministic unique element `id` (`shelf-tab-all`, `shelf-tab-fav`, `shelf-tab-<sanitized-folder-key>` where `<sanitized-folder-key>` replaces non-alphanumeric characters via `/[^a-zA-Z0-9_-]/g, '_'` to ensure valid HTML ID tokens and CSS selector resolution). When in "By Folder" sort mode, `#game-grid-wrapper` dynamically declares `role="tabpanel"` and `aria-labelledby` referencing the active tab's unique element `id`; when switching to flat sort modes where `#shelf-tabs-wrapper` is hidden, `#game-grid-wrapper` removes `role="tabpanel"` and `aria-labelledby` to restore standard grid presentation.
   - Implements roving `tabindex` (`tabindex="0"` on the currently active tab, `tabindex="-1"` on all inactive tabs). If the provided `activeTabId` is no longer valid (not matching `'all'`, not matching `'fav'` with `favoritesCount > 0`, and not present in `allSections`—such as when a folder path is deleted in Settings or subsumed), `updateTabs` must defensively fall back to `activeTabId = 'all'`, assign `aria-selected="true"` and `tabindex="0"` to `#shelf-tab-all`, and notify caller via `options.onTabSelect?.('all')`, preserving the WAI-ARIA roving tabindex invariant.
   - Horizontal keyboard arrow navigation: handles `ArrowRight` / `ArrowLeft` (and `Home` / `End`) on focused tab to cycle focus and active selection, automatically calling `scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'nearest' })`. While a tab reorder transaction is in flight (spanning coordinator animation and IPC persistence), keyboard arrow navigation and selection triggers are suppressed, ignoring keydown activations until the reorder transaction completes or rolls back.
    - Overflow buttons render canonical vector SVG chevron glyphs (inheriting theme color via `currentColor`) rather than raw ASCII text characters, paired with explicit visual tooltip attributes (`data-tooltip` backed by localized strings `options.i18n?.('scroll_tabs_left') ?? 'Scroll tabs left'` / `options.i18n?.('scroll_tabs_right') ?? 'Scroll tabs right'`), descriptive names (`aria-label` matching the localized strings), dynamic `aria-disabled="true"`, and visual disabled styling (reduced opacity) when scroll headroom is exhausted (`scrollLeft <= 0` for left; `scrollLeft + clientWidth >= scrollWidth - 1` for right). Interaction blocking is enforced via functional activation guards (`if (btn.getAttribute('aria-disabled') === 'true') return;`) in click, mousedown, and keydown handlers rather than applying CSS `pointer-events: none` on the button, preserving mouseover and focus events for tooltip discovery while preventing scrolling past boundary limits.
5. Horizontal mouse wheel scrolling (handling both `evt.deltaY` and `evt.deltaX`) + `<` and `>` arrow scroll buttons governed dynamically by container geometric overflow (`scrollable.scrollWidth > scrollable.clientWidth`), rather than a static item count threshold. The controller must evaluate geometric overflow on initial render, during tab updates, and via a container `ResizeObserver` (or window resize listener). To eliminate `ResizeObserver` feedback loops ('ResizeObserver loop limit exceeded') and layout thrashing, the controller and layout MUST isolate overflow button dimensions from container measurements (e.g. reserving button layout footprint using `visibility: hidden` / `opacity: 0` instead of `display: none` / `''`, or placing navigation buttons outside the measured flex container so their appearance does not alter `scrollable.clientWidth`) or schedule dimension evaluation within `requestAnimationFrame` with a hysteresis threshold to prevent oscillation between overflow and non-overflow states. Static container event listeners on `scrollable` (wheel scrolling and a passive `scroll` event listener `scrollable.addEventListener('scroll', handleScroll, { passive: true })`), navigation buttons (`navPrevBtn`, `navNextBtn` click handlers), and the `ResizeObserver` must be attached strictly once during `createShelfTabsController` initialization (or managed idempotently via `AbortController`), and MUST NOT be re-attached during `updateTabs()` invocations, with clean disconnection in `destroy()`. `handleScroll` re-evaluates directional headroom (`scrollLeft <= 0` for `navPrevBtn`, `scrollLeft + clientWidth >= scrollWidth - 1` for `navNextBtn`), scheduled via `requestAnimationFrame` with hysteresis/caching to prevent layout thrashing, dynamically toggling `aria-disabled="true"` / `aria-disabled="false"` and visual disabled opacity on `navPrevBtn` and `navNextBtn` as the user scrolls horizontally using trackpad gestures, horizontal mouse wheel, keyboard navigation, or drag-scrolling.
6. Horizontal SortableJS reordering with pinned tab protection (mandating an `onMove` callback guard that rejects insertion before or between pinned tabs, returning `false` when `!evt.related.classList.contains('draggable-tab')` or when targeting `.pinned-tab`), identity guard in `onEnd` (`if (oldOrder.length === newOrder.length && oldOrder.every((p, i) => p === newOrder[i])) return;`), authoritatively extracting `movedPath = (evt.item as HTMLElement)?.dataset?.folderPath || resolveMovedPath(oldOrder, newOrder)`. Array diffing between single-element relocations evaluates boundary displacement: finding first differing index `start` (`oldOrder[start] !== newOrder[start]`) and last differing index `end` (`oldOrder[end] !== newOrder[end]`), where `oldOrder[start] === newOrder[end]` identifies rightward movement of `oldOrder[start]`, and `oldOrder[end] === newOrder[start]` identifies leftward movement of `newOrder[start]` (banning raw index lookups `oldOrder[evt.oldIndex]` or naive `newOrder.find(...)` which misidentifies shifted neighbors on rightward moves). Invoking `reorderLibraryPathsWithSubsumption`, executing `onTabReorder(oldOrder, newOrder, movedPath)`, and persisting via `electronAPI.updateLibraryConfig({ libraryPaths: reorderedAllPaths })`. Upon successful persistence resolution, re-orders `cachedSections` to match `newOrder` by normalizing both `orderMap` keys and `section.path || section.folderPath` via `normalizePathForPlatform(..., options.targetPlatform)` prior to unlocking pointer interactions or invoking `options.onConfigUpdated`, ensuring subsequent parameterless `updateTabs()` invocations preserve the user's reordered tab sequence. On persistence error, rolls back in-memory order, restores tabs via `controller.updateTabs()`, dispatches ephemeral notification via `options.showToastPill?.(options.i18n?.('toast_tab_reorder_failed') ?? 'Failed to update tab order. Reverting changes.')`, and notifies caller via `options.onReorderFailed?.(oldOrder)`.
7. Regular click (< 5px drag distance): switches active tab, invokes `options.onTabSelect?.(tabId)`, and smooth-scrolls tab into view.

Provide comprehensive Vitest unit tests in `src/renderer/library/shelf-tabs.test.ts`.

    ```typescript
    Sortable.create(scrollable, {
      draggable: '.draggable-tab',
      direction: 'horizontal',
      animation: options.animationDuration ?? 180,
      fallbackTolerance: options.fallbackTolerance ?? 5,
      forceFallback: true,
      onMove: (evt) => {
        return evt.related.classList.contains('draggable-tab');
      },
      onEnd: async (evt) => {
        const tabs = Array.from(scrollable.querySelectorAll('.draggable-tab')) as HTMLElement[];
        const newOrder = tabs.map(t => t.dataset.folderPath!).filter(Boolean);
        const oldOrder = [...currentFolderOrder];

        if (oldOrder.length === newOrder.length && oldOrder.every((p, i) => p === newOrder[i])) {
          return;
        }

        const movedPath = (evt.item as HTMLElement)?.dataset?.folderPath || resolveMovedPath(oldOrder, newOrder);

        const currentConfig = options.getLibraryConfig() || { libraryPaths: [] };
        const reorderedAllPaths = reorderLibraryPathsWithSubsumption(currentConfig.libraryPaths || [], newOrder, options.targetPlatform);

        currentFolderOrder = newOrder;
        options.container.style.pointerEvents = 'none';

        let reorderPhase: 'coordinator' | 'persistence' = 'coordinator';
        try {
          if (options.onTabReorder) {
            await options.onTabReorder(oldOrder, newOrder, movedPath);
          }
          reorderPhase = 'persistence';
          const nextConfig = await options.electronAPI.updateLibraryConfig({ libraryPaths: reorderedAllPaths });
          if (nextConfig) {
            if (cachedSections) {
              const orderMap = new Map(newOrder.map((p, i) => [normalizePathForPlatform(p, options.targetPlatform), i]));
              cachedSections.sort((a, b) => {
                const keyA = normalizePathForPlatform(a.path || a.folderPath, options.targetPlatform);
                const keyB = normalizePathForPlatform(b.path || b.folderPath, options.targetPlatform);
                return (orderMap.get(keyA) ?? Number.MAX_SAFE_INTEGER) - (orderMap.get(keyB) ?? Number.MAX_SAFE_INTEGER);
              });
            }
            options.onConfigUpdated?.(nextConfig);
          } else {
            throw new Error('updateLibraryConfig returned falsy');
          }
        } catch (err) {
          // Revert in-memory order, restore DOM tabs, and notify coordinator of failure to rollback sections
          currentFolderOrder = oldOrder;
          controller.updateTabs();
          options.onReorderFailed?.(oldOrder);
          options.showToastPill?.(options.i18n?.('toast_tab_reorder_failed') ?? 'Failed to update tab order. Reverting changes.');
          console.error('[SHELF_TABS] Failed to process shelf tab reorder, rolled back:', { oldOrder, newOrder, movedPath, phase: reorderPhase, error: err });
        } finally {
          options.container.style.pointerEvents = '';
        }
      }
    });
    ```
