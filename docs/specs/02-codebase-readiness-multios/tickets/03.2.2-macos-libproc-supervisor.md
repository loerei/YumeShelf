# 03.2.2 — macOS Process Tree Supervisor via libproc C FFI ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement Darwin-specific process supervision in `native/playtime-helper/src/main.rs` under `#[cfg(target_os = "macos")]`. Declare `libproc` C FFI bindings (`proc_listpids`, `proc_pidinfo` with `PROC_PIDTASKALLINFO`). In `main.rs`, allocate a sized vector in Rust with minimum capacity `2048` entries (`let mut pids: Vec<pid_t> = Vec::with_capacity(2048)`), passing the raw buffer pointer to `proc_listpids`. If the returned byte count indicates the buffer was completely filled, dynamically grow the buffer and re-query to guarantee no running processes are truncated. Query parent PID via `proc_pidinfo` per process with error isolation (`EPERM`/`ESRCH`). Build child process relations and delegate tree evaluation to pure function `pid_tree_has_live_members_from_relations(root_pid, &relations)` from `03.2.1`. Retain defensive fallback stub for unsupported platforms.

## Explicit Assumptions & Boundaries
- Behavioral expansion ($B$) consuming pure tree traversal seam `pid_tree_has_live_members_from_relations` from `03.2.1`.
- Compiles conditionally on macOS (`#[cfg(target_os = "macos")]`).
