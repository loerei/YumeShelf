## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build

Support dropping dragged game cards and folders directly onto ancestor breadcrumb links in the navigation bar to reparent them up the hierarchy, persisting mutations via IPC, and displaying feedback toast notifications.

## Acceptance criteria

- [ ] Make breadcrumb navigation items in `<nav aria-label="Breadcrumb">` (`05.2`) active drag-and-drop targets during an ongoing drag session (`06.1.2.2`).
- [ ] Provide immediate visual drop-target hover highlight (<100ms) when a dragged item hovers over a breadcrumb link.
- [ ] Implement `createBreadcrumbDropController` accepting optional parameter seam `showToastPillFn?: (message: string) => void` (defaulting to `showToastPill`) and exposing `dispose(): void` to clean up event listeners and hover observers.
- [ ] Dropping a card onto a breadcrumb node captures a snapshot of `virtualTree` and invokes `VirtualTreeManager.moveNode` (`03.1.2`) to reparent the target node into the selected ancestor folder (or root).
- [ ] Prevent invalid drops: disallow dropping a node onto its current parent or onto itself/descendants.
- [ ] Persist tree modifications via `electronAPI.saveVirtualTree` through `AtomicWriteCoordinator`. If save fails or returns `{ ok: false }`, roll back in-memory `virtualTree` to the captured snapshot, re-render the active view, and display an error toast via `(options?.showToastPillFn || showToastPill)('Failed to save folder changes')`.
- [ ] Display an immediate feedback toast notification via `(options?.showToastPillFn || showToastPill)` (e.g., `"Moved [Item Name] to [Folder Name]"` or `"Moved [Item Name] to Library"`).
- [ ] Unit and UI interaction tests in `src/renderer/controllers/breadcrumb-drop.test.ts` verifying breadcrumb drop hit testing, reparenting dispatch, snapshot rollback on save failure, invalid drop prevention, toast notification trigger, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated breadcrumb drop tests via `npm run test:vitest -- src/renderer/controllers/breadcrumb-drop.test.ts` with standard output containing `'✓ renderer/controllers/breadcrumb-drop.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
