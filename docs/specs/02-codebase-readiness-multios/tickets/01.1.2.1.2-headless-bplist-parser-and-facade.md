# 01.1.2.1.2 — Headless Binary bplist00 Deserializer & Unified Facade in YumeEngine ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement binary property list deserializer `BPlistParser` in `packages/yume-engine/src/bundle/bplist-parser.ts` decoding the binary `bplist00` format up to 5MB with bounded recursion depth (max depth 64), cyclic reference prevention, Cocoa epoch offset (`978307200`s), and prototype pollution protection (`Object.create(null)` / stripping `__proto__`, `constructor`, `prototype`). Implement unified entrypoint `parsePlist(content: Buffer | Uint8Array | string)` in `packages/yume-engine/src/bundle/plist-parser.ts` detecting XML vs `bplist00` headers and routing accordingly. Re-export `parsePlist` from `packages/yume-engine/src/index.ts`.

- Zero external runtime dependencies.
