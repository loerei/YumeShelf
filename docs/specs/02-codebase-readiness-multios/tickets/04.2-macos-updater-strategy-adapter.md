# 04.2 — macOS AppUpdaterStrategy Adapter ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement the `MacUpdaterStrategyAdapter` in `src/main/app-updates/mac-strategy.ts` implementing `AppUpdaterStrategy` for Darwin environments accepting `AppUpdaterStrategyOptions` (including `execCommand`, `downloadTimeoutMs`, `fetch`, and `downloadFile` test seams). Expand `RuntimeUpdateStrategy` in `src/main/app-updates/runtime-strategy.ts` to support `channel: 'mac'` and `artifactKind: 'mac-dmg' | 'mac-zip'`. Update `resolveRuntimeUpdateStrategy` in `src/main/app-updates/runtime-strategy.ts` to branch on `process.platform === 'darwin'` for packaged applications. Update `resolvePackagedFeedOverride` in `src/main/app-updates/feed-resolver.ts` to accept Darwin runtime channels (`mac`/`dmg`) and parse `latest-mac.yml`. Support `.dmg` and `.zip` extensions in SHA-512 cryptographic checksum verification in `pickExpectedSha512` and enforce HTTPS transport with configurable socket timeout (`options.downloadTimeoutMs ?? 30000`) and abort signal handling for all update downloads and release feed queries. Consume `options.fetch ?? globalThis.fetch` (or `options.downloadFile`). In `dispose()`, abort any active HTTP requests via `AbortController` and clear active timers. Update `enrichUpdateInfo` in `src/main/app-updates/helpers.ts` to enrich stacked release notes, release names, and release URLs for `runtimeStrategy.channel === 'mac'` in addition to `'nsis'`. Execute `hdiutil` disk mount/unmount (`-nobrowse -readonly`) and installer handoff via parameterized array calls routed through `options.execCommand` (defaulting to `child_process.execFile` with `shell: false` in production), guaranteeing `hdiutil detach -force` in a `try...finally` block, cleaning up partial downloads on network failure, and recording structured diagnostic logs via `appendUpdateLog`. Document unnotarized `.dmg`/`.zip` quarantine attribute handling in operational context. Author dedicated test suite `tests/app-updates.test.js` providing mock `execCommand`, mock `fetch`/`downloadFile`, `t.afterEach` teardown hooks calling `adapter.dispose()`, and deterministic stream timeout testing via `AbortSignal.abort()` or simulated stream errors to validate `latest-mac.yml` feed resolution, macOS strategy routing, teardown reliability, release notes enrichment, and error handling deterministically on Windows CI.

## Explicit Assumptions & Boundaries
- Operates on top of the `AppUpdaterStrategy` seam established in Ticket 04.1.
- Expands update channel and artifact kind types to support macOS release packaging.

## Acceptance criteria
- [ ] Expand `RuntimeUpdateStrategy` in `src/main/app-updates/runtime-strategy.ts` to support `channel: 'mac'` and `artifactKind: 'mac-dmg' | 'mac-zip'`.
- [ ] Update `resolveRuntimeUpdateStrategy` in `src/main/app-updates/runtime-strategy.ts` to branch on `process.platform === 'darwin'`, returning `channel: 'mac'` and `artifactKind: 'mac-dmg'` with `supportsUpdater: true` and `supportsInPlaceApply: true` for packaged macOS applications.
- [ ] Implement `MacUpdaterStrategyAdapter` in `src/main/app-updates/mac-strategy.ts` accepting `options?: AppUpdaterStrategyOptions` (supporting `fetch`, `downloadFile`, `execCommand`, `downloadTimeoutMs`) and implementing `AppUpdaterStrategy`.
- [ ] Maintain an internal `AbortController` and references to active download timers; in `dispose()`, abort any pending requests and cancel all active timers.
- [ ] Route all `hdiutil` disk mount/unmount operations (`attach`, `detach`) and installer handoff through `options.execCommand` (defaulting to `child_process.execFile` with `shell: false` in production), passing `-nobrowse -readonly` flags.
- [ ] Update `enrichUpdateInfo` in `src/main/app-updates/helpers.ts` to execute `resolveNewerReleases` and enrich release metadata for `runtimeStrategy.channel === 'mac'` alongside `'nsis'`.
- [ ] Record structured diagnostic logs via `appendUpdateLog` across all update lifecycle phases (feed resolution, download, SHA-512 verification, `hdiutil attach/detach`, payload staging), capturing exit codes, stderr, and digests upon error.
- [ ] Record temporary mount point and execute `hdiutil detach <mountPoint> -force` inside a guaranteed `try...finally` teardown block.
- [ ] Clean up partial temporary download files on network timeouts, socket drops, or abort events using `options.downloadTimeoutMs ?? 30000`.
- [ ] Support `.dmg` and `.zip` extensions in SHA-512 cryptographic checksum verification in `pickExpectedSha512` and `MacUpdaterStrategyAdapter`.
- [ ] Enforce HTTPS transport for all update downloads and release feed queries (`new URL(url).protocol === 'https:'`).
- [ ] Update `resolvePackagedFeedOverride` in `src/main/app-updates/feed-resolver.ts` to accept Darwin runtime channels (`mac`/`dmg`) and parse `latest-mac.yml` release feeds.
- [ ] Update `createAppUpdaterStrategy` to return `MacUpdaterStrategyAdapter` when `process.platform === 'darwin'`.
- [ ] Author automated unit tests in `tests/app-updates.test.js` providing mock `execCommand`, mock `fetch`, `t.afterEach(() => adapter.dispose())` teardown hooks, and deterministic timeout simulation validating `latest-mac.yml` feed resolution, macOS strategy routing, `try...finally` unmount teardown, stream timeout handling, release notes enrichment, and error handling deterministically on Windows CI.
- [ ] Execute automated unit tests via `npm run build:main && node --test tests/app-updates.test.js` (or `npm run test:single -- tests/app-updates.test.js`).
