# 02.4.2.2.2 — Library Grid Single-Click Inline Folder Rename ($B$)

## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement single-click inline folder rename and live shelf tab synchronization in `src/renderer/library-grid.ts`:
1. Title Activation (Click and Keyboard):
   - Ensure the folder title element (`.section-title` or `.folder-title`) is keyboard-focusable (`tabindex="0"`) and rendered as an independent sibling within the section heading container (`role="heading"`), strictly decoupled from the accordion toggle button (`role="button"`). Provide text-editing visual affordance (text selection cursor styling and subtle edit hover state), an accessible visual tooltip on hover/focus, and an accessible description attribute (`aria-description="Click or press Enter/F2 to rename folder"`) informing assistive technology and keyboard users of the rename capability, disambiguating title interaction from the sibling accordion toggle button.
   - Attach click listener to folder title element, and listen for `F2` keydown shortcut (or `Enter` keydown when focus is on the title element) to activate inline rename mode. Check `if (options.isReordering?.() || isReordering) return;` before activating inline rename to strictly block edit mode while section reorder animations or IPC reorder persistence transactions are in flight.
   - Invoke `e.preventDefault()` on activation as part of a preventable event contract so the section header toggle handler detects that the event was handled and avoids toggling collapse state, while allowing events to bubble unimpeded to document listeners.
   - Replace title text with a section-header-scoped inline text input (`<input class="rename-input" type="text">` styled with left text alignment and natural layout width to override card-level centered styling) populated with current display name or alias, assign `aria-label="Rename folder " + (trimmedValue || getFolderBaseName(folderPath))`, select input text, and focus the element. Preserve native `Space` key character insertion within the text input by intercepting and applying `e.preventDefault()` exclusively for `Enter` (to commit rename) and `Escape` (to cancel edit mode). On `<input class="rename-input">`, do NOT invoke `e.preventDefault()` on `mousedown` so native text insertion caret positioning and drag-selection remain fully functional; parent accordion section header handlers guard against toggling accordion collapse by checking `if (e.target.tagName === 'INPUT' || (e.target as HTMLElement).closest('.rename-input') || e.defaultPrevented) return;`, ensuring events bubble unimpeded to document-level listeners.
2. Edit Lifecycle & Key Handlers:
   - Maintain an edit lifecycle guard (`let isEditingComplete = false;`).
    - Enter key & Blur commit flow:
      - If `isEditingComplete` is `true` or saving is already in-flight, return immediately.
      - Extract trimmed value. If unchanged from `originalTitle`, mark `isEditingComplete = true`, remove input, restore `titleElement.style.display = ''`, and focus `titleElement`.
      - During in-flight saving, mark input with `readOnly = true`, `aria-busy="true"`, and submitting visual styling (`.is-submitting`) while preserving keyboard focus inside the input.
      - Wrap persistence in a `try ... catch` block:
        ```typescript
        try {
          const res = await options.electronAPI.setFolderAlias(folderPath, trimmedValue);
          if (res && res.ok) {
            isEditingComplete = true;
            titleElement.textContent = trimmedValue || getFolderBaseName(folderPath);
            titleElement.style.display = '';
            inputElement.remove();
            titleElement.focus();
            options.onConfigUpdated?.(res.config);
            shelfTabsController?.updateTabs?.();
          } else {
            throw new Error(res?.error || 'setFolderAlias returned false');
          }
        } catch (err) {
          // Failure recovery: retain input element and preserve user's typed text
          inputElement.readOnly = false;
          inputElement.removeAttribute('aria-busy');
          inputElement.classList.remove('is-submitting');
          inputElement.setAttribute('aria-invalid', 'true');
          inputElement.classList.add('has-error');
          inputElement.focus();
          options.showToastPill?.(options.i18n?.('toast_folder_rename_failed') ?? 'Failed to update folder alias. Press Enter to retry or Esc to cancel.');
          console.error('[LIBRARY_GRID][INLINE_RENAME] Failed to set folder alias:', { folderPath, alias: trimmedValue, error: err });
        }
        ```
        Guarantees that `setFolderAlias` updates title text, safely transfers keyboard focus to `titleElement`, and removes the input strictly upon successful persistence, updating in-place (resolving to `trimmedValue` or falling back to `getFolderBaseName(folderPath)` when alias is cleared), synchronizing configuration via `options.onConfigUpdated?.(res.config)`, and updating shelf tabs without calling `renderLibraryGrid('folder')`. On persistence error or rejection, the input element is retained mounted and focused with `aria-invalid="true"` and error styling (`.has-error`), the user's typed text is preserved, `readOnly` and `aria-busy` locks are released allowing immediate editing or retry with Enter, and an actionable error toast notification is displayed. Reversion to `originalTitle` and input removal occurs strictly when the user explicitly cancels via Esc, or when a subsequent retry succeeds.
    - Esc key:
      - Check whether saving is already in-flight (`if (inputElement.readOnly || inputElement.getAttribute('aria-busy') === 'true') return;`), suppressing cancellation while an asynchronous IPC persist transaction is pending to eliminate unmounted DOM node mutation race conditions.
      - Mark `isEditingComplete = true` prior to removing input from DOM to prevent blur event from triggering IPC save.
      - Restore original title text, restore `titleElement.style.display = ''`, restore keyboard focus to `titleElement` (`titleElement.focus()`), and remove input element without invoking IPC.
3. DOM XSS Prevention:
   - Render all folder titles, aliases, and input attributes using safe `textContent` bindings or context-aware escaping. Direct HTML string concatenation is strictly prohibited.

Provide comprehensive Vitest unit tests in `src/renderer/library-grid.test.ts`.
