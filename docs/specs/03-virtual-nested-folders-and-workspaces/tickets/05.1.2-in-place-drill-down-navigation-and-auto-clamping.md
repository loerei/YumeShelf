## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Manage the active navigation path stack (`currentPath: string[]`, where `[]` represents root), implement in-place grid transitions into folder contents on click or `Enter`, wire folder card callbacks (`onRename`, `onDissolve`) to `VirtualTreeManager` mutations, and auto-clamp navigation on folder dissolution or rescan pruning.

## Acceptance criteria
- [ ] Maintain an active navigation path stack (`currentPath: string[]`, storing immutable folder IDs, where `[]` represents `root`).
- [ ] Clicking a folder card or pressing `Enter` when focused triggers an in-place grid transition to display that folder's child nodes.
- [ ] Implement `createFolderDrillDownController` accepting optional parameter seam `showToastPillFn?: (message: string) => void` (defaulting to `showToastPill`) and exposing `dispose(): void` to clean up event listeners and navigation observers.
- [ ] Wire folder card action callbacks (`onRename`, `onDissolve`) to `VirtualTreeManager` mutations (`03.1.2`). Before applying mutations, capture a snapshot of the current `virtualTree`. Dispatch `electronAPI.saveVirtualTree`; if persistence fails or returns `{ ok: false }`, roll back in-memory tree state to the snapshot, re-render the view, and show an error toast via `(options?.showToastPillFn || showToastPill)('Failed to save folder changes')`.
- [ ] On virtual tree mutation or library rescan reconciliation, validate `currentPath` against `virtualTree`; if the current folder or any ancestor was pruned, clamp navigation state to the nearest surviving ancestor or fallback to `root`.
- [ ] Unit and component tests in `src/renderer/controllers/folder-drill-down.test.ts` verifying in-place drill-down transitions, card action callback wiring, snapshot rollback on save failure, navigation auto-clamping on folder pruning, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated drill-down tests via `npm run test:vitest -- src/renderer/controllers/folder-drill-down.test.ts` with standard output containing `'✓ renderer/controllers/folder-drill-down.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
