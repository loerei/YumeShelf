# 02.2.1.2.1 — Headless Standard AppSupport Save Resolvers in YumeEngine ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Update standard headless save resolvers in `packages/yume-engine/src/save-resolvers/engine-save-resolvers.ts` (`resolveRenPySave`, `resolveGodotSave`, `resolveUnrealSave`) to resolve macOS save locations (`~/Library/Application Support/RenPy/<stem>`, `~/Library/Application Support/Godot/app_userdata/<stem>`, `~/Library/Application Support/Epic/<stem>/Saved/SaveGames`) when `fs.getMacApplicationSupportHome()` is available. Normalize line endings using `/\r?\n/` when reading `app.info` or configuration files. Require that sanitized company, product, and application names have non-zero length (`company.length > 0 && product.length > 0`), and validate that resolved save directories are contained within the base application support directory without equaling `appSupportHome` or `preferencesHome` directly.

- Behavioral expansion ($B$) consuming the `IEnvironmentPaths` abstraction from `02.1` and stem utility from `02.2.1.1`.
- In-bundle resource parsing (Unity/RPG Maker) is handled in `02.2.1.2.2`.
