## What to build

Continuous viewport edge auto-scrolling during card drag-and-drop operations on the virtualized grid container to enable effortless dragging across large collections.

## Acceptance criteria

- [ ] During an active drag session (`06.1.1`) inside the virtualized grid container, monitor pointer position relative to the container's top and bottom viewport boundaries, accepting optional parameter seams `autoScrollOptions?: AutoScrollOptions` and `clock?: IClock`.
- [ ] Inject operational parameters via `AutoScrollOptions`:
  ```typescript
  export interface AutoScrollOptions {
    edgeThresholdPx?: number;       // default: 40
    maxVelocityPx?: number;         // default: 25
    scrollStepMultiplier?: number;  // default: 1.5
  }
  ```
- [ ] Implement `createDragEdgeScrollController` exposing `dispose(): void` to unbind listeners and cancel active animation frame loops. Resolve animation frame providers via:
  ```typescript
  const rAF = clock?.requestAnimationFrame
    ? ((cb: (timestamp: number) => void) => clock.requestAnimationFrame!(cb))
    : (typeof requestAnimationFrame === 'function'
      ? requestAnimationFrame
      : ((cb: (timestamp: number) => void) => (clock ? clock.setTimeout(() => cb(clock.now()), 16) : (setTimeout(() => cb(Date.now()), 16) as unknown as number))));
  const cAF = clock?.cancelAnimationFrame
    ? ((id: number) => clock.cancelAnimationFrame!(id))
    : (typeof cancelAnimationFrame === 'function'
      ? cancelAnimationFrame
      : ((id: number) => (clock ? clock.clearTimeout(id) : clearTimeout(id as unknown as ReturnType<typeof setTimeout>))));
  ```
- [ ] Trigger auto-scrolling when pointer is within `edgeThresholdPx` (40px) of top or bottom container viewport boundaries, consuming pure `calculateEdgeScrollVelocity` from `[NEW] src/renderer/utils/virtual-grid-windowing.ts` (`04.2`).
- [ ] Implement an animation frame-driven auto-scrolling loop via `rAF`/`cAF` with scroll velocity proportional to edge proximity (capped at `maxVelocityPx` to prevent disorientation).
- [ ] Seamlessly coordinate edge auto-scrolling with the virtualized grid windowing engine (`04.2`) to update visible row slices dynamically without stuttering or dropping frames (>55 FPS).
- [ ] Terminate edge auto-scrolling immediately on drag end, pointer release, or pointer leaving the grid viewport boundaries.
- [ ] Unit and component tests in `src/renderer/controllers/drag-edge-scroll.test.ts` verifying edge detection threshold (40px), velocity scaling, `requestAnimationFrame` loop lifecycle, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated edge scroll tests via `npm run test:vitest -- src/renderer/controllers/drag-edge-scroll.test.ts` with standard output containing `'✓ renderer/controllers/drag-edge-scroll.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
