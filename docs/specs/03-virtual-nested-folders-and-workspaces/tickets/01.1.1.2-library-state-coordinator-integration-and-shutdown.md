## What to build

Integrate `AtomicWriteCoordinator` into `src/main/library-state/index.ts`, bind `isDegraded()` on `libraryState`, implement `resolveCoordinator(context)`, refactor all mutations in `actions.ts` and `config.ts` to route through `resolveCoordinator(context).mutate`, and register synchronous `flushSync()` on Electron `app.on('before-quit')` in `src/main.ts`.

## Acceptance criteria

- [ ] In `src/main/library-state/index.ts`:
  - Pass `coordinator: IWriteCoordinator` on internal `context` object assembled in `createLibraryState` and update `LibraryContext` type definition.
  - Extend `LibraryContext` options to accept `writeCoordinatorOptions?: WriteCoordinatorOptions` (or `debounceMs?: number`). When custom persistence delegates (`loadDB`/`saveDB`) are provided without an explicit `debounceMs`, default `debounceMs` to `0` to guarantee immediate synchronous persistence in unit test harnesses (`tests/library-state.test.js`).
  - Forward `coordinator.flushSync()` to public `libraryState.flushSync()`.
  - Bind `isDegraded: () => coordinator.isDegraded()` on `libraryState` and `context`.
- [ ] Implement `resolveCoordinator(context: LibraryContext)` in `src/main/library-state/index.ts` (or shared helper) providing backward-compatible fallback when `context.coordinator` is omitted in test harnesses:
  ```typescript
  function resolveCoordinator(context: LibraryContext): Pick<IWriteCoordinator, 'mutate'> {
    if (context.coordinator) {
      return context.coordinator;
    }
    return {
      mutate: async <T>(mutator: (db: any) => Promise<T> | T): Promise<T> => {
        const rawDb = (context.loadDB ? await context.loadDB() : null) ?? {};
        const workingCopy = structuredClone(rawDb);
        const result = await mutator(workingCopy);
        const saveFn = context.persistDbDirectly || context.saveDB;
        if (saveFn) await saveFn(workingCopy);
        if (rawDb && typeof rawDb === 'object') {
          Object.assign(rawDb, workingCopy);
        }
        return result;
      }
    };
  }
  ```
- [ ] Refactor `actions.ts` (`toggleFavorite`, `renameGame`, `addPlaytime`, `setGameCover`, `updateGameMetadata`, etc.) to execute all mutations through `resolveCoordinator(context).mutate((db) => { ... })`. Retain structured error logs (`console.error('[LIBRARY_STATE][...] Failed to persist ...', { ... })`) around `resolveCoordinator(context).mutate(...)` so existing test spies pass without regression.
- [ ] Refactor `config.ts` (`updateLibraryConfig`, `setupLibrary`, `setManualPathResolution`, etc.) to execute all configuration mutations through `resolveCoordinator(context).mutate((db) => { ... })`, preserving structured error logs.
- [ ] In `src/main.ts`, register `libraryState.flushSync()` on Electron `app.on('before-quit')`:
  ```typescript
  app.on('before-quit', () => {
    libraryState.flushSync();
  });
  ```
- [ ] Maintain 100% backward compatibility with existing unit test suites (`tests/library-state.test.js` and `src/main/library-state/migrations.test.ts:252-274`), ensuring that persistence aborts and structured warning `'[LIBRARY_STATE] Persistence aborted: database is in DEGRADED state.'` are preserved when the database enters degraded state.
