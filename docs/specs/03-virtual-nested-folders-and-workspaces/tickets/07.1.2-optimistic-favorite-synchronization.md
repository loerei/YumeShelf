## What to build
Implement global optimistic favorite star state updates (<100ms) across all UI surfaces (card dropdowns, folder views, Favorite Desk), with asynchronous IPC persistence and rollback error handling on failure.

## Acceptance criteria
- [ ] Implement `createFavoriteSyncController` accepting optional parameter seams `toggleFavoriteFn?: (gameKey: string) => Promise<boolean>` and `showToastPillFn?: (message: string) => void` (defaulting to `showToastPill`), with an explicit `dispose(): void` method to remove event listeners and prevent memory/listener leaks across view changes and test cycles.
- [ ] Wire `createFavoriteSyncController` into `src/renderer/bootstrap/app-composition.ts` (`createRendererComposition`), instantiating it with `state`, `electronAPI`, and `showToastPill`, and binding `commonCardCallbacks.onFavoriteToggled` to `favoriteSyncController.toggleFavorite`.
- [ ] Refactor the existing click handler in `src/renderer/game-cards.ts:130-139` to remove the direct un-optimistic `await electronAPI.toggleFavorite(gameKey)` call and delegate star click execution to `onFavoriteToggled(gameKey)` (or injected `toggleFavoriteFn`).
- [ ] Maintain an internal per-key in-flight concurrency lock `inFlightKeys = new Set<string>()` in `createFavoriteSyncController`. Inside `toggleFavorite(gameKey: string)`:
  - If `inFlightKeys.has(gameKey)`, immediately return to ignore redundant clicks while an asynchronous IPC toggle is already pending for that game.
  - Add `gameKey` to `inFlightKeys` before capturing snapshots and applying optimistic mutations.
  - In a `finally` block after IPC resolution or error rollback, remove `gameKey` from `inFlightKeys`.
- [ ] Inside `favoriteSyncController.toggleFavorite`, resolve canonical physical key `canonicalKey = game.primaryInstance?.gameKey || game.gameKey || gameKey`, update both `game.favorite` in `allGames` AND symmetrically update `UiRuntimeState.favoriteOrder` using `canonicalKey` immediately in-memory in `<100ms>` before awaiting IPC resolution.
- [ ] Dispatch IPC `electronAPI.toggleFavorite(gameKey)` returning `Promise<boolean>` (`true` if favorited, `false` if un-favorited), symmetrically updating `db.favoriteOrder` via `AtomicWriteCoordinator`. Invalid `gameKey` inputs or unresolvable game records reject with explicit errors (`'invalid-game-key'`, `'game-not-found'`) rather than resolving `false`.
- [ ] Delta-Based Key-Specific Rollback: In the controller, treat any boolean return value (`typeof res === 'boolean'`) as successful persistence. If the IPC call rejects or throws an error:
  - If the game was optimistically favorited, remove ONLY `canonicalKey` from `UiRuntimeState.favoriteOrder`:
    ```typescript
    state.setFavoriteOrder(state.getFavoriteOrder().filter((k) => k !== canonicalKey));
    ```
    and revert `favorite = false` across all physical instances of the logical game in `allGames` (`game.instances?.forEach(inst => { const g = state.getGameByKey(inst.gameKey); if (g) g.favorite = false; })`).
  - If the game was optimistically un-favorited, restore `canonicalKey` back into `UiRuntimeState.favoriteOrder` at its prior index:
    ```typescript
    const currentOrder = state.getFavoriteOrder().filter((k) => k !== canonicalKey);
    const nextOrder = [...currentOrder];
    nextOrder.splice(priorIndex, 0, canonicalKey);
    state.setFavoriteOrder(nextOrder);
    ```
    and revert `favorite = true` across all physical instances of the logical game in `allGames`.
  - Display error toast notification via `(options?.showToastPillFn || showToastPill)('Failed to update favorite status')`.
  - Concurrently committed favorite changes for other game keys remain preserved without whole-array snapshot clobbering.
- [ ] Author automated unit tests in `src/renderer/state/favorite-sync.test.ts` verifying optimistic update on both favorite (`true`) and un-favorite (`false`), per-key in-flight deduplication, delta-based key-specific rollback on IPC failure preserving concurrent toggles on multi-instance games where `gameKey !== canonicalKey`, toast display, `toggleFavoriteFn` seam injection, and lifecycle teardown via `afterEach(() => controller.dispose())`.
- [ ] Execute automated tests via `npm run test:vitest -- src/renderer/state/favorite-sync.test.ts` with standard output containing `'✓ renderer/state/favorite-sync.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
