# 05.1.1.1 — Headless Heterogeneous Partition Sorter

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Author a pure headless calculation utility in `[NEW] src/renderer/utils/folder-sort.ts` that implements partition sorting for heterogeneous child collections: child folders pinned at top, followed by game references sorted across 4 presets (`custom`, `az`, `dateAdded`, `lastPlayed`).

## Acceptance criteria
- [ ] Author `[NEW] src/renderer/utils/folder-sort.ts` exporting `partitionSortChildren(children: Array<VirtualFolderNode | VirtualGameRefNode>, sortMode: string, games: Record<string, any> | any[]): Array<VirtualFolderNode | VirtualGameRefNode>`. Defensively normalize `games` if an array is passed (`Array.isArray(games) ? Object.fromEntries(games.map(g => [g.gameKey || g.id, g])) : games`).
- [ ] Accept canonical UI sort keys: `'date'` (alias for `'dateAdded'`), `'played'` (alias for `'lastPlayed'`), `'az'`, and `'custom'`.
- [ ] When `sortMode === 'custom'`, return `children.slice()` without folder-pinning partitioning, preserving the exact sequence in `node.children` and retaining user-defined 1D drag-and-drop order (`06.1.1`).
- [ ] When `sortMode` is `'az'`, `'date'` / `'dateAdded'`, or `'played'` / `'lastPlayed'`, pin child folders (`type === 'folder'`) at top (sorted alphabetically by name), followed by child game references (`type === 'game'`) partitioned below and sorted by the active preset. Defensively guard `games[child.gameKey]` lookups with optional chaining and fallback defaults (`(game?.name || child.gameKey).toLowerCase()`, `dateAdded: game?.dateAdded || 0`, `lastPlayed: game?.lastPlayed || 0`) to prevent runtime crashes if a referenced game is not present in the local lookup table.
- [ ] Author automated unit tests in `src/renderer/utils/folder-sort.test.ts` verifying custom mode preservation, canonical key aliases, sorting across presets, and empty collections.
- [ ] Execute automated unit tests via `npm run test:vitest -- src/renderer/utils/folder-sort.test.ts` with standard output containing `'✓ renderer/utils/folder-sort.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
