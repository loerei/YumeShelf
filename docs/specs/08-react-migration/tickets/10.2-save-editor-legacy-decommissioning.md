1. **Contract Save IPC Handlers & Shared Type Declarations (`engine.ts`, `save-editor.controller.ts`, `index.ts`, `preload.ts`, `ipc.d.ts`)**:
   - In [`src/main/save-editor/engine.ts`](file:///d:/Projects/YumeShelf/src/main/save-editor/engine.ts):
     - Retain internal compatibility facade on `SaveDataEngine` so existing Main Process test suites (`tests/save-data-engine.test.js`, `tests/save-editor-contracts.test.js`) continue passing without regressions:
       - `loadSave()` continues to return `{ ...normalizedDto, data: decodedData, metadata }`.
       - `writeSave()` continues to support positional legacy parameter handling `(gameKey, fileName, updatesOrData, options)` alongside modern `{ updates, options }` calls.
   - In [`src/main/ipc/controllers/save-editor.controller.ts`](file:///d:/Projects/YumeShelf/src/main/ipc/controllers/save-editor.controller.ts):
     - Enforce pure modern contracts across the IPC boundary:
       - In `save-editor:load-data`, strip legacy `data` and `metadata` envelopes before returning to the renderer, returning strictly `NormalizedSaveDto`.
       - In `save-editor:write-data`, retain strict ingress parameter validation for `gameKey` and `fileName` (non-empty strings, no path traversal sequences, no prototype pollution identifiers) and `updates` object, resolving exclusively `{ ok: false, error: 'invalid-payload' }` on malformed payloads, and delegating valid updates to `saveEditorService.writeSaveData` (which supports both single-object payload `{ gameKey, fileName, updates, options }` and 4-positional parameters `(gameKey, fileName, updates, options)`).
     - Decommission and permanently delete the dead IPC handler `save-editor:update-mapping`.
     - Persistent storage IPC channels `save-editor:load-translations` and `save-editor:save-translations` are active contracts retained for the React Save Editor, enforcing ingress bounds, prototype pollution defense, path-keyed write mutexing, and atomic persistence, not dead code.
   - In [`src/main/save-editor/index.ts`](file:///d:/Projects/YumeShelf/src/main/save-editor/index.ts):
     - Remove obsolete `updateMapping` method from `SaveEditorService`.
   - In [`src/preload.ts`](file:///d:/Projects/YumeShelf/src/preload.ts):
     - Remove obsolete `updateMapping` bridge from `ElectronAPI` while preserving `cancelLoadSaveData: (params: { gameKey: string; fileName: string }) => Promise<{ cancelled: boolean }>`.
   - In [`src/shared/types/ipc.d.ts`](file:///d:/Projects/YumeShelf/src/shared/types/ipc.d.ts):
     - Contract `loadSaveData` and `writeSaveData` on `ElectronAPI` to enforce pure contracts, preserving `cancelLoadSaveData`:
       ```typescript
       import type { NormalizedSaveDto, SaveCodecOptions, SaveSchemaOptions, SaveUpdatesPayload } from '@yumeshelf/engine/types';

       export interface ElectronAPI {
         // ...
         loadSaveData: (data: { gameKey: string; fileName: string; earlyExit?: boolean; stalenessTimeoutMs?: number; options?: SaveSchemaOptions }) => Promise<NormalizedSaveDto>;
         writeSaveData: (data: { gameKey: string; fileName: string; updates: SaveUpdatesPayload; options?: SaveCodecOptions & { isUpdates?: boolean; createBackup?: boolean; preserveBackup?: boolean; maxBackups?: number; maxBufferSizeBytes?: number } }) => Promise<{ ok: boolean; error?: string; code?: string }>;
         cancelLoadSaveData: (params: { gameKey: string; fileName: string }) => Promise<{ cancelled: boolean }>;
         loadTranslations: (lang: string) => Promise<Record<string, string>>;
         saveTranslations: (lang: string, translations: Record<string, string>) => Promise<{ ok: boolean; error?: string }>;
         // ...
       }
       ```
     - Remove obsolete `updateMapping` signature from `ElectronAPI`.
