## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Add a Settings panel toggle for "Legacy Grid Mode" (defaulting to enabled/checked). When toggled off, activate Virtual Folder Mode: toggle container visibility (`#legacy-grid-container` hidden, `#virtual-folder-container` visible), suppress the Category filter dropdown, and persist `legacyMode: false` via IPC `update-library-config`.
