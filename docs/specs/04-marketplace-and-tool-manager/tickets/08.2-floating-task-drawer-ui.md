# 08.2 — Floating Task Drawer UI & Adaptive Launch Actions

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The `FloatingTaskDrawer` component in the Renderer process (non-blocking bottom-right toast bar) displaying real-time animated progress %, active sub-step labels, Cancel button, queue status, auto-collapse transitions, initial state hydration via `addon:get-task-state`, and the adaptive Game Card Play button state (`⏳ Task in progress...`) with Cancel-to-Launch confirmation prompts.

## Explicit Assumptions & Boundaries
- Floating Task Drawer stays pinned at the bottom-right viewport without blocking user navigation across library grids or game detail modals.
- Adaptive UI: When a task is actively running on a game, the Game Card "Play" button displays a spinner state (`⏳ Task in progress (45%)...`). Clicking the button prompts the user to cancel the running task and launch immediately.
