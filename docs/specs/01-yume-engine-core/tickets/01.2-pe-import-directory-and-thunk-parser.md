# 01.2 — PE Import Directory & Thunk Table Parser

## Epic
PRD 01: YumeEngine Core Architecture & Headless Extraction

## What to build
The Import Directory and Import Lookup/Address Table (ILT/IAT) thunk parser in `@yumeshelf/engine` extracting imported DLL names, handling 32-bit and 64-bit thunks, supporting Borland/Delphi `FirstThunk` fallback heuristics, and populating normalized `Set<string>` imports for $O(1)$ query complexity.

## Attribution Requirement

## Status
ready-for-agent

## Acceptance criteria
- [x] Parse Import Directory: Traverse `IMAGE_IMPORT_DESCRIPTOR` array with iteration ceiling ($\le 2048$), aborting safely if descriptor offsets exceed buffer bounds.
- [x] Parse ILT/IAT thunks: Resolve 32-bit (uint32) and 64-bit (BigInt uint64) thunks, falling back to reading `FirstThunk` (IAT RVA) when `OriginalFirstThunk` is 0 (required for Borland C++ and Delphi binaries), skipping ordinal imports without names.
- [x] DLL Name Normalization: Normalize imported DLL names (lowercase, stripped `.dll` extension) into a pre-allocated `Set<string>` (`importsSet`), and implement symmetric query normalization in `PEInspector.hasImport(name: string)` (stripping whitespace, lowercasing, and stripping `.dll`) for guaranteed $O(1)$ lookup complexity.
- [x] Unit tests using `synthetic-pe-builder.ts` fixtures with mock Import Tables (including 32-bit vs 64-bit thunk layouts, Borland Delphi `FirstThunk` layouts, circular descriptor tables, and malformed name pointers).
- [x] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test -- tests/pe-imports.test.ts` verifying 100% passing tests.
