## What to build
Encapsulate unmanaged global document and window event listeners into reactive React providers and establish a strongly-typed modal overlay stack with focus trapping:

1. **Tooltip Provider (`TooltipProvider.tsx`)**:
   - Create [`src/renderer/providers/TooltipProvider.tsx`](file:///d:/Projects/YumeShelf/src/renderer/providers/TooltipProvider.tsx):
     - Replace the 7 permanent unmanaged listeners in [`src/renderer/tooltips.ts`](file:///d:/Projects/YumeShelf/src/renderer/tooltips.ts#L145-L197) (`document.mouseover`, `mousemove`, `mouseout`, `pointerdown`, `scroll`, `window.blur`, `resize`) with a single React Provider.
     - Single delegated listener pipeline bound on mount and cleanly removed on unmount, covering both pointer/window listeners (`mouseover`, `mousemove`, `mouseout`, `pointerdown`, `scroll`, `blur`, `resize`) and keyboard accessibility listeners (`focusin`, `focusout`, and `Escape` `keydown`):
       - **Element Boundary Narrowing & Native Tooltip Migration**: On `focusin` (matching pointer `mouseover` behavior), narrow `e.target` via `if (!(e.target instanceof Element)) return;` before calling `e.target.closest('[data-tooltip], [title]')` (preventing `TypeError` on `document`/`window` or non-`Element` targets). Migrate native `title` to `data-tooltip` / strip `title` (matching `src/renderer/tooltips.ts#L156-L162`) and honor the `.dropdown-menu.show` suppression guard (`src/renderer/tooltips.ts#L149-L153`) so keyboard focus never renders duplicate native OS and `.app-tooltip` overlays.
       - **Timer Overlap & Detachment Guard**: Clear any existing pending show timer (`clearTimeout`) before scheduling the `300ms` (`delayMs`) timer on `focusin`, track `currentTriggerRef.current = triggerEl`, and inside the delayed timer callback verify `if (!triggerEl.isConnected || currentTriggerRef.current !== triggerEl) return;` before calling `triggerEl.getBoundingClientRect()` (preventing tooltips from flashing at `{ top: 0, left: 0 }` if the trigger unmounts during the 300ms window).
       - **`focusout` Containment Check & Teardown**: On `focusout`, skip hiding when `e.relatedTarget instanceof Node && currentTriggerRef.current?.contains(e.relatedTarget)` (mirroring `src/renderer/tooltips.ts#L185-L188`); clear pending show timers and reset `currentTriggerRef.current = null` when hiding on external `focusout`, `Escape` `keydown`, or unmount. Clean up all delegated listeners (including `focusin`, `focusout`, `keydown`) and pending timers in the `useEffect` return callback.
     - Default tooltip show delay is calibrated to 300ms (with customizable `delayMs?: number` prop seam, defaulting to 300ms) to prevent visual tooltip flicker while rapidly scrolling through dense virtualized game cards, clearing pending show timers on mouseout/focusout/Escape/unmount.
     - Exposes `<Tooltip content="...">children</Tooltip>` wrapper and hook. When rendered outside of `<TooltipProvider>`, `<Tooltip>` gracefully degrades and renders `children` directly without throwing runtime exceptions, ensuring isolated presentational components remain hermetically testable in headless unit tests.
     - When a tooltip becomes active/visible, the portaled tooltip DOM node applies the `.show` class modifier (`className={`app-tooltip ${isVisible ? 'show' : ''} ${isCompact ? 'compact' : ''}`}`) to satisfy `src/styles/menus-tooltips.css#L128-L149` (`opacity: 1; transform: translateY(0) scale(1)`):
       ```tsx
       {activeTooltip && (
         <div
           ref={tooltipRef}
           role="tooltip"
           className={`app-tooltip ${isVisible ? 'show' : ''} ${activeTooltip.compact ? 'compact' : ''}`}
           style={{
             top: `${activeTooltip.top}px`,
             left: `${activeTooltip.left}px`,
             zIndex: 'var(--zIndex-tooltip)',
           }}
         >
           <div className="app-tooltip-title">{activeTooltip.title}</div>
           {activeTooltip.meta && <div className="app-tooltip-meta-line">{activeTooltip.meta}</div>}
           {activeTooltip.subtitle && <div className="app-tooltip-subtitle">{activeTooltip.subtitle}</div>}
         </div>
       )}
       ```

2. **Overlay Provider (`OverlayProvider.tsx`)**:
   - Create [`src/renderer/providers/OverlayProvider.tsx`](file:///d:/Projects/YumeShelf/src/renderer/providers/OverlayProvider.tsx):
     - Centralizes modal registry, z-index layering, and single global window `Escape` key listener (`window.addEventListener('keydown')`) (eliminating unmanaged listeners from [`src/renderer/events/global-events.ts`](file:///d:/Projects/YumeShelf/src/renderer/events/global-events.ts)). When `event.key === 'Escape'` and `modalStack.length > 0`, validates `if (event.defaultPrevented) return;` before invoking `closeModal()`, popping the topmost modal from `modalStack` and preserving child component event suppression. (Local dialog DOM focus trapping is encapsulated within `<Modal.tsx>`).
     - Enforces a tokenized elevation hierarchy across overlay layers consuming the design tokens established in `:root` of `src/styles/theme.css` in Ticket 01 (`--zIndex-dropdown: 1000` for flyouts and context menus, `--zIndex-widget: 1600` for floating widgets, `--zIndex-widget-overlay: 1700` for widget context menus and particles, `--zIndex-modal: 2000` for dialogs and modal backdrops, `--zIndex-overlay: 6000` for fullscreen startup and update blocking overlays, `--zIndex-tooltip: 10000` for tooltips, and `--zIndex-toast: 10005` for toast pills topmost), establishing local stacking context containment (`isolation: isolate`) on portaled overlay containers to prevent background z-index bleed-through. Overlay components, dropdown menus (`.dropdown-menu`, `.dropdown-submenu`), startup/update overlays (`.loading-overlay`), notification hosts (`.update-notification-host`), and floating mascot widgets/menus bind strictly to these declared tokens, eliminating arbitrary integer magic numbers in `menus-tooltips.css` (2000, 2010), `boot.css` (6000), `update-notifications.css` (1600), and `mascot.css` (1650, 1655, 2100).
     - Define strongly-typed overlay context contract modeling modal state as a deterministic LIFO modal navigation stack and discriminated union (`ActiveModalState`) alongside `ModalPayloadMap`:
       ```typescript
       export type ModalType = 'settings' | 'about' | 'language-pack' | 'duplicate-stack';

       export interface ModalPayloadMap {
         'settings': undefined;
         'about': undefined;
         'language-pack': undefined;
         'duplicate-stack': { groupKey: string };
       }

       export type ActiveModalEntry =
         | { readonly type: 'settings'; readonly payload?: undefined }
         | { readonly type: 'about'; readonly payload?: undefined }
         | { readonly type: 'language-pack'; readonly payload?: undefined }
         | { readonly type: 'duplicate-stack'; readonly payload: { groupKey: string } };

       export type ActiveModalState =
         | { readonly type: null; readonly payload?: undefined }
         | ActiveModalEntry;

       export type OpenModalFn = <T extends ModalType>(
         ...args: ModalPayloadMap[T] extends undefined
           ? [type: T]
           : [type: T, payload: ModalPayloadMap[T]]
       ) => void;

       export interface OverlayContextValue {
         readonly modalStack: readonly ActiveModalEntry[];
         readonly activeModalState: ActiveModalState;
         readonly activeModal: ModalType | null;
         readonly modalPayload: ModalPayloadMap[ModalType];
         isModalOpen(type: ModalType): boolean;
         getModalPayload<T extends ModalType>(type: T): ModalPayloadMap[T] | undefined;
         openModal: OpenModalFn;
         closeModal(type?: ModalType): void;
       }

       export function useOverlay(): OverlayContextValue;
       ```
     - Specify behavioral invariants in `OverlayProvider.tsx`:
       - `openModal(type, payload)`: Pushes `{ type, payload }` to `modalStack`. Enforces consecutive deduplication: if `modalStack[modalStack.length - 1]?.type === type`, updates the topmost modal's payload in-place if `JSON.stringify(top.payload) !== JSON.stringify(payload)`, or early returns without state modification if identical.
       - `closeModal(type?)`: If `type` is omitted, pops the topmost modal from `modalStack` via `modalStack.slice(0, -1)`. If `type` is specified, removes that modal entry from `modalStack`.
       - `activeModalState`: Derived selector returning `modalStack[modalStack.length - 1] ?? { type: null }`.
       - `activeModal`: Derived selector returning `activeModalState.type`.
       - `isModalOpen(type)`: Pure selector returning `modalStack.some(entry => entry.type === type)`.
       - `getModalPayload(type)`: Pure selector returning `modalStack.find(m => m.type === type)?.payload`.
       - Global `window` Escape listener: Pops the topmost modal from `modalStack` when `modalStack.length > 0` and `!event.defaultPrevented`.
