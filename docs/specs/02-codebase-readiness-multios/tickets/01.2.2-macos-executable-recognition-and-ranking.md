# 01.2.2 — macOS Executable Recognition & Priority Ranking ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement 6-tier Darwin candidate ranking in `pickPreferredExecutable` and recognize Darwin `.app` bundle directories (`typeof entry.isDirectory === 'function' && entry.isDirectory() && entry.name.endsWith('.app')`) along with POSIX executable mode check / Mach-O header verification in `isRecognizedExecutable` in `src/main/library-state/scanner.ts`. Ensure that `.app` bundle recognition occurs prior to `if (!entry.isFile())` checks and resolves executables via canonical `AppBundleInspector.fromPath(bundlePath, fs)`, returning `resolvedExePath?: string`. Ensure that when `fs` lacks both `open` and `readFile` methods, `isRecognizedExecutable` returns `{ isExecutable: false, platform: 'windows' }` without falling back to host filesystem I/O (`node:fs/promises`). Ensure that `.app` bundle directories collected during Step 1 are excluded from Step 2 direct candidate ranking to preserve accurate `folderPath` assignment and avoid duplicate I/O.

## Explicit Assumptions & Boundaries
- Behavioral expansion ($B$) consuming the structural traversal and inner binary resolution from `01.2.1` and bounded Mach-O reading from `01.1.1.2`.
- Uses injectable `targetPlatform` to enable 100% in-memory virtual cross-platform testing on CI.
