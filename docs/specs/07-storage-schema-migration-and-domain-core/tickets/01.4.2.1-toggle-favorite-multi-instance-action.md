## What to build
Implement parameterized `toggleFavorite` across the domain action, library state facade, preload bridge, and IPC controller:
1. Domain Action Signature (`src/main/library-state/actions.ts`):
   ```typescript
   export async function toggleFavorite(
     context: LibraryContextInternal,
     gameKey: string,
     targetFavorite?: boolean
   ): Promise<boolean>
   ```
2. Degraded database pre-condition guard & input validation:
   - Validates `gameKey` immediately at entry before snapshotting or logical group resolution: if `typeof gameKey !== 'string' || !gameKey.trim() || gameKey === '__proto__' || gameKey === 'constructor' || gameKey === 'prototype'`, throw `new Error(`Game not found: ${gameKey}`)` immediately.
   - Verifies `if (context.isDegraded?.() === true)` BOTH as an immediate pre-condition guard at function entry AND immediately following `await context.loadDB()`, emitting structured diagnostic warning `console.warn('[LIBRARY_STATE][TOGGLE_FAVORITE] Operation aborted: database is in DEGRADED state', { gameKey });` before throwing `new Error('Database is in degraded state')` before applying in-memory mutations to prevent stale in-memory corruption upon disk failure.
3. Scoped instance resolution:
   - Eliminate full-collection `buildLogicalGames(normalizedGames)` execution during single-game favorite toggles:
     1. Unify group target identification by computing `targetGameId` directly via `buildLogicalGameId`, handling both stored instance keys and logical identifiers:
        ```typescript
        const targetRecord = Object.prototype.hasOwnProperty.call(games, gameKey) ? games[gameKey] : undefined;
        const targetGameId = targetRecord
          ? buildLogicalGameId({ ...targetRecord, gameKey })
          : ((gameKey.startsWith('game:') || gameKey.startsWith('path:')) ? gameKey : undefined);

        if (!targetGameId) {
          throw new Error(`Game not found: ${gameKey}`);
        }
        ```
     2. Scan `Object.entries(games)` and collect all keys `k` where `buildLogicalGameId({ ...record, gameKey: k }) === targetGameId` into `matchedKeys`:
        ```typescript
        const matchedKeys = Object.entries(games)
          .filter(([k, record]) => buildLogicalGameId({ ...record, gameKey: k }) === targetGameId)
          .map(([k]) => k);

        if (matchedKeys.length === 0) {
          throw new Error(`Game not found: ${gameKey}`);
        }
        ```
     3. Eliminating the flawed assumption that `buildContinuitySignature === null` guarantees a unique singleton ensures symmetrical state propagation for multi-instance `path:` games across distinct library roots without full-collection `buildLogicalGames` instantiation overhead (~6ms for 5,000 games).
4. Group aggregate resolution, pre-mutation snapshot & instance key propagation:
   - Derive `const currentFavorite = matchedKeys.some(k => Boolean(games[k]?.favorite));`. Prohibit reading `games[gameKey]?.favorite` directly, which evaluates to `undefined` when `gameKey` is a logical identifier and corrupts toggle state inversion.
   - Determine `const nextFavorite = typeof targetFavorite === 'boolean' ? targetFavorite : !currentFavorite`.
   - Snapshot in-memory favorite states strictly BEFORE applying in-memory mutations across instances:
     ```typescript
     const previousFavorites = matchedKeys.map((k: string) => ({
       key: k,
       favorite: games[k]?.favorite
     }));
     ```
   - Assign `games[k].favorite = nextFavorite` across all keys in `matchedKeys` (for both single and multi-instance groups), preventing phantom records under logical `gameId` keys. Validate all keys in `matchedKeys` against prototype pollution (`__proto__`, `constructor`, `prototype`) and verify own-property existence before assignment:
     ```typescript
     matchedKeys.forEach((k: string) => {
       const isUnsafe = typeof k !== 'string' ||
         k === '__proto__' ||
         k === 'constructor' ||
         k === 'prototype';
       if (!isUnsafe && Object.prototype.hasOwnProperty.call(games, k) && games[k]) {
         games[k].favorite = nextFavorite;
       }
     });
     ```
5. Database persistence & Snapshot-and-Rollback Contract:
   - Explicitly assigns `db.games = games;` and triggers atomic persistence via `await (context.persistDbDirectly || context.saveDB)(db)` and returns the resolved boolean `nextFavorite`. Catch operational failures (degraded state or persistence errors), restore previous favorite states onto `games` using the pre-mutation snapshot `previousFavorites`, guarding the restore loop against prototype pollution:
     ```typescript
     previousFavorites.forEach(({ key, favorite }) => {
       if (
         typeof key === 'string' &&
         !['__proto__', 'constructor', 'prototype'].includes(key) &&
         Object.prototype.hasOwnProperty.call(games, key) &&
         games[key]
       ) {
         games[key].favorite = favorite;
       }
     });
     ```
     emit structured diagnostic error log:
     ```typescript
     console.error('[LIBRARY_STATE][TOGGLE_FAVORITE] Failed to persist favorite toggle:', {
       gameKey,
       targetFavorite,
       error: err
     });
     ```
     and re-throw the error across the IPC bridge to ensure caller transactional rollback triggers deterministically without leaving `cachedDb` desynchronized from disk.
6. Library State Facade Binding (`src/main/library-state/index.ts`):
   - Bind `toggleFavorite` on `createLibraryState`:
     ```typescript
     toggleFavorite: (gameKey: string, targetFavorite?: boolean) =>
       serializedQueue(() => toggleFavorite(context, gameKey, targetFavorite)),
     ```
6. Shared IPC Contract & Preload Bridge:
   - Update `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     toggleFavorite(gameKey: string, targetFavorite?: boolean): Promise<boolean>;
     ```
   - Update `src/preload.ts`:
     ```typescript
     toggleFavorite: (gameKey: string, targetFavorite?: boolean) =>
       ipcRenderer.invoke('toggle-favorite', gameKey, targetFavorite),
     ```
7. Main IPC Controller Registration (`src/main/ipc/controllers/library.controller.ts`):
   - Update `toggle-favorite` handler to accept and forward `targetFavorite`:
     ```typescript
     ipcMain.handle('toggle-favorite', async (_event, gameKey, targetFavorite) => {
       return libraryState.toggleFavorite(gameKey, targetFavorite);
     });
     ```

Author Vitest unit tests in `src/main/library-state/actions-favorite.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
