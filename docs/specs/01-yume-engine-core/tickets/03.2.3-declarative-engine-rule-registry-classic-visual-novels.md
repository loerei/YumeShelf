## Acceptance criteria
- [x] Implement declarative rules for Classic Japanese VN engines:
  1. **TyranoBuilder:** `tyrano/` directory, `data/scenario/`, `tyrano.js`.
  2. **GameMaker Studio:** `data.win` file marker.
  3. **KiriKiri 2 / KiriKiri Z:** `*.xp3` archive files or `tvpwin32.exe`.
  4. **BGI / Ethornell:** `SysGrp.arc`, `SysPrg.arc`, `BGI.exe`.
  5. **CatSystem 2:** `cs2.exe`, `scene.dat`.
  6. **SystemNNN / System39:** `system39.exe`, `n3n/`.
  7. **SiglusEngine / RealLive:** `SiglusEngine.exe`, `RealLive.exe`, `g00/`, `scene.pck`.
  8. **Majiro:** `MajiroObjX.dll`, `data.arc`, `scenario.arc`.
  9. **NScripter / ONScripter:** `nscript.dat`, `0.txt`, `default.ttf`.
  10. **Artemis:** `artemis.exe`, `root.pfs`.
  11. **Lilim:** `lilim.exe`, `*.aoi`.
  12. **LiveMaker:** `Live.exe`, `*.pyl`.
  13. **Native Win32 C++:** Fallback classification for standard compiled PE binaries without engine markers.
- [x] Comprehensive unit tests verifying each Visual Novel engine rule using synthetic mock PE inspectors and directory layouts.
- [x] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test -- tests/engine-rules-vn.test.ts` and verify detection accuracy with `node .devutil/inspect-game-engine.cjs` against test fixtures.
