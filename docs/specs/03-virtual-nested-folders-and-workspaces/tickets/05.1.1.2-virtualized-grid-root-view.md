## Acceptance criteria
- [ ] Mount grid rendering inside `#virtual-folder-container` (`08.2`), consuming `virtual-grid-windowing.ts` (`04.2`) across all item counts. Compute active mounted DOM card count dynamically: `activeCardCount = (Math.ceil(viewportHeight / (cardHeight + gapPx)) + overscanRows * 2) * columnCount`.
- [ ] Implement `createVirtualizedGridController` accepting optional parameter seams via `VirtualizedGridControllerOptions`:
  ```typescript
  export interface VirtualizedGridControllerOptions {
    windowingOptions?: WindowingOptions;
    resizeObserverClass?: any;
    cardActionMenuProviders?: Array<ICardActionMenuProvider>;
  }
  ```
  Forward `options?.cardActionMenuProviders` directly to the folder card renderer (`renderFolderCard`), permitting passing `cardActionMenuProviders` from `src/renderer/bootstrap/app-composition.ts`. Guard browser observer initialization via `if (typeof ResizeObserver !== 'undefined' || options?.resizeObserverClass)` for headless Node testability, disconnect observer on `dispose()`, and expose `dispose(): void` for clean teardown of resize listeners and DOM observers.
- [ ] Wire `createVirtualizedGridController` into `src/renderer/bootstrap/app-composition.ts`, binding to `refs.virtualFolderContainer`, propagating `windowingOptions`, and integrating with `UiRuntimeState`. Pass `UiRuntimeState.getGamesMap()` directly into `partitionSortChildren` and folder preview extractors to achieve $O(1)$ constant-time entity lookups without intermediate `Object.fromEntries` heap allocations on render loops. Subscribe to all relevant reactive state slices and retain all returned unsubscribe closures:
  ```typescript
  const unsubscribers = [
    state.onCurrentSortChange(() => this.reSortAndRender()),
    state.onCurrentPathChange(() => this.reSortAndRender()),
    state.onVirtualTreeChange(() => this.reSortAndRender()),
    state.onWorkspaceModeChange(() => this.reSortAndRender()),
    state.onFavoriteOrderChange(() => {
      if (state.getActiveWorkspaceMode() === 'favorites') this.reSortAndRender();
    }),
    state.onAllGamesChange(() => this.reSortAndRender())
  ];
  ```
  In `createVirtualizedGridController.dispose()`, iterate and invoke all unsubscribe closures (`unsubscribers.forEach((unsub) => unsub())`) to prevent memory leaks and zombie callback invocations across view toggles. In `reSortAndRender()`, add an early return guard: `if (!this.container || this.container.style.display === 'none' || !this.container.isConnected) return;` to avoid computing culling slices and virtual DOM operations when Legacy Grid Mode is active.
- [ ] Consume `partitionSortChildren` (`05.1.1.1`) to render root items with folders pinned top and games below.
- [ ] Render closed folder cards using the 2x2 preview card component (`04.1.2`) alongside standard game cards at root level.
- [ ] Author component unit tests in `src/renderer/views/folder-grid-view.test.ts` verifying root grid mounting, parameter seam injection, dynamic card recycling, re-sorting and re-rendering on `onCurrentSortChange`, `onCurrentPathChange`, `onVirtualTreeChange`, and `onWorkspaceModeChange`, and complete `dispose()` teardown (including unregistering all state subscriptions).
- [ ] Execute automated component tests via `npm run test:vitest -- src/renderer/views/folder-grid-view.test.ts` with standard output containing `'✓ renderer/views/folder-grid-view.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
