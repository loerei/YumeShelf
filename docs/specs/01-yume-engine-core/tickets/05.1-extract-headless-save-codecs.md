# 05.1 — Extract Headless Save Codecs into YumeEngine

## Epic
Epic 01: YumeEngine Core Extraction & 100% F95zone PE Binary Inspector

## What to build
Extract save format codecs into pure TypeScript modules inside `@yumeshelf/engine` and define `SaveCodecError` domain error hierarchy.

## Blocked by
- 00 — Monorepo Workspace & Package Scaffolding

## Status
completed

## Acceptance criteria
- [x] Define and export `SaveCodecError` class (`CHECKSUM_FAILED`, `DECOMPRESSION_FAILED`, `PARSE_FAILED`, `UNSUPPORTED_FORMAT`) in `packages/yume-engine/src/saves/errors.ts`.
- [x] Implement prototype pollution defenses in `YumeEngine.decodeSaveFile` across all decoders: sanitize all parsed object keys to reject or strip properties named `__proto__`, `constructor`, or `prototype`, and utilize `Object.create(null)` or safe dictionary abstractions during deserialization to prevent prototype tampering in the Node.js runtime.
- [x] Implement pure JSON and compressed text codecs (`pure-json`, `keyed-json`, `lz-string` for RPG Maker MV/MZ) in `YumeEngine.decodeSaveFile` / `encodeSaveFile` throwing typed `SaveCodecError`.
- [x] Implement binary save codecs (`wolf-sav` for Wolf RPG, pure TS pickle parser for Ren'Py, `bakin-sgs` for RPG Bakin) in `YumeEngine.decodeSaveFile` / `encodeSaveFile`. Follow Postel's Law during `decodeSaveFile`: do NOT throw `CHECKSUM_FAILED` on uninitialized/zero header checksum bytes (preserving backwards compatibility with legacy fixtures and relaxed inspectable data), but strictly compute and enforce valid checksums during `encodeSaveFile`.
- [x] Enforce strict sandboxing in Ren'Py pure TypeScript pickle parser:
  - Prohibit dynamic code evaluation (`eval`, `Function`, `new Function()`).
  - Restrict instantiable objects strictly to safe primitive data types (integers, floats, strings, booleans, null, arrays, plain dictionary objects, sets, tuples).
  - Explicitly reject execution of callable/reduction opcodes (`GLOBAL`, `REDUCE`, `BUILD`, `INST`, `OBJ`, `NEWOBJ`) that attempt to instantiate arbitrary JavaScript/Node classes or invoke functions, throwing a typed `SaveCodecError('PARSE_FAILED', 'Unsafe pickle opcode detected')`.
- [x] Comprehensive unit tests verifying decoding and encoding round-trips across all pure TypeScript save formats with synthetic fixtures (including prototype pollution rejection and malicious pickle opcode rejection).
- [x] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test -- tests/save-codecs.test.ts` verifying 100% roundtrip encoding/decoding fidelity.
