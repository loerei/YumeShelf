# 04.2 — Virtualized Grid Viewport Windowing Engine

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
A pure headless virtualized grid viewport windowing calculation engine in `[NEW] src/renderer/utils/virtual-grid-windowing.ts` providing viewport culling math, visible row/column index slicing, total scroll height calculations, coordinate-to-item mapping for drag-and-drop hit testing, and edge scroll velocity calculations without direct DOM coupling (DOM mounting and card recycling are handled in Ticket 05.1).

## Acceptance criteria
- [ ] Author `[NEW] src/renderer/utils/virtual-grid-windowing.ts` exporting pure calculation functions for grid windowing.
- [ ] Inject parameter seam `WindowingOptions`:
  ```typescript
  export interface WindowingOptions {
    cardWidth?: number;
    cardHeight?: number;
    gapPx?: number;
    overscanRows?: number;     // default: 1
  }
  ```
- [ ] Implement visible index window calculations `[startRow, endRow]` and `[startIndex, endIndex]` given container scroll offset, viewport dimensions, item dimensions, and grid column count.
- [ ] Calculate total virtual container height given total item count, row count, card dimensions, and grid gap.
- [ ] Expose coordinate-to-item mapping functions translating pointer client coordinates `(clientX, clientY)` and container scroll state into virtual collection data indices:
  ```typescript
  export interface VirtualGridHitResult {
    itemIndex: number;
    rowIndex: number;
    colIndex: number;
  }
  export function calculateVirtualGridHit(
    pointerX: number,
    pointerY: number,
    containerRect: { top: number; left: number; width: number; height: number },
    scrollTop: number,
    totalItems: number,
    options?: WindowingOptions
  ): VirtualGridHitResult | null;
  ```
- [ ] Export `AutoScrollOptions`:
  ```typescript
  export interface AutoScrollOptions {
    edgeThresholdPx?: number;       // default: 40
    maxVelocityPx?: number;         // default: 25
    scrollStepMultiplier?: number;  // default: 1.5
  }
  ```
- [ ] Implement pure edge proximity velocity calculation helper `calculateEdgeScrollVelocity(pointerY: number, containerRect: { top: number; bottom: number }, options?: AutoScrollOptions): number` without coupling to clocks or animation loops.
- [ ] Automated unit tests in `src/renderer/utils/virtual-grid-windowing.test.ts` verifying row/column index slicing, total scroll height calculations, coordinate-to-index mapping via `calculateVirtualGridHit`, and edge auto-scroll velocity formulas without DOM dependency.
- [ ] Execute automated unit tests via `npm run test:vitest -- src/renderer/utils/virtual-grid-windowing.test.ts` with standard output containing `'✓ renderer/utils/virtual-grid-windowing.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
