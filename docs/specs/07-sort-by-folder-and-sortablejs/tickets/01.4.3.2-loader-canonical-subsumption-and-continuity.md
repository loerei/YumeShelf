# 01.4.3.2 — Canonical Loader Subsumption Reconciliation & Continuity ($S$)

## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Enforce the Canonical Read Invariant in `src/main/library-state/loader.ts`: with storage guaranteed to be at `schemaVersion: 1` by prerequisite bootstrap migration runner `01.4.3.1`, ensure `loader.ts` operates strictly on canonical records without heuristic property sniffing, transient migration flags, or mid-scan category mutations.

### Canonical Loader Read Invariant (`src/main/library-state/loader.ts`)
- Canonical `gameKey` derivation: in `loadGamesForConfig`, pre-compute `canonicalActiveRoots = subsumeLibraryPaths(activePaths, targetPlatform)` once prior to iterating candidate games, and resolve `owningLibPath` for candidate games by evaluating `isSubsumedBy(candidate.folderPath, root, targetPlatform)` across `canonicalActiveRoots`. Guard all derived `gameKey` strings against prototype pollution keys (`__proto__`, `constructor`, `prototype`), safely skipping or rejecting unsafe keys before indexing into `nextGames`.
- Replace legacy private helper `isPathWithinDirectory` with cross-platform `isSubsumedBy(folderPath, libraryPath, targetPlatform)` from `src/shared/path-subsumption.ts`.
- Stored game retention across offline paths and manual additions:
  - Offline path retention: Retain all stored records (both regular scanned games and manual games) whose `folderPath` satisfies `isSubsumedBy(record.folderPath, ip, targetPlatform)` for any `ip` in `inactivePaths`, unconditionally without checking physical disk existence to protect offline storage against destructive data loss.
  - Stored manual game retention & deduplication on active paths:
    - Pre-index normalized folder paths of `nextGames` into a lookup Set (`const existingFolderPaths = new Set(Object.values(nextGames).map(g => normalizePathForPlatform(g.folderPath, targetPlatform)));`).
    - When iterating `latestStoredGames` where `record.manual === true`, skip any record if `existingFolderPaths.has(normalizePathForPlatform(record.folderPath, targetPlatform))`, achieving $O(N + M)$ deduplication.
    - Pre-compute `canonicalConfigRoots = subsumeLibraryPaths(latestDb.config?.libraryPaths || normalizedConfig.libraryPaths, targetPlatform)` once prior to iterating retained manual games, and re-derive canonical `gameKey` for retained manual games using `canonicalConfigRoots`, updating `gameKey = canonicalGameKey; relativePath = canonicalGameKey;`.
    - For active paths, retain stored manual game records not present in `nextGames` iff both `exePath` and `folderPath` are valid non-empty strings (`typeof record.exePath === 'string' && record.exePath.trim().length > 0 && typeof record.folderPath === 'string' && record.folderPath.trim().length > 0`) and both exist on physical disk via `context.fsSync.existsSync(record.exePath) && context.fsSync.existsSync(record.folderPath)`. If either path coordinate is invalid, missing, or non-string, emit a structured diagnostic warning (`console.warn('[LOADER][MANUAL_CORRUPT] Skipping corrupt stored manual game record with invalid filesystem coordinates:', { gameKey, exePath: record?.exePath, folderPath: record?.folderPath })`) and skip retention of the malformed record without calling `fsSync.existsSync`.
    - Purge manual games whose parent library path has been removed from `latestDb.config.libraryPaths`.
    - Preserve user-selected `exePath`, `engine`, `folderPath`, `platform`, and `manual: true` across both the primary scanned games overlay loop (when `latestStoredGames[gameKey]?.manual === true`, preserving `recordCopy.manual = true`, `latest.exePath`, `latest.engine`, and `latest.platform`) and the secondary un-scanned manual retention loop.
- Pure Canonical Read Invariant:
  - Completely eliminate helper functions `readLegacyGames` and `removeLegacyGames`, call-sites `const legacyGames = readLegacyGames(db)`, candidate fallback lookup `|| legacyMigrationMap.get(...)`, and envelope mutation `removeLegacyGames(latestDb)`.
  - Remove unused import `buildLegacyMigrationMap` from `./continuity`.
  - Completely eliminate `migratedFromGameKey` property and checks.
  - Completely eliminate fallback lookups (`latestStoredGames[scannedRecord.migratedFromGameKey]`).
  - Completely eliminate category migration and legacy ID cleanup loops from `persistPhase`.
  - All candidate reconciliation in `loader.ts` operates strictly against canonical `db.games`.
  - `persistPhase` executes a single, clean atomic persistence of `latestDb` to disk via `await (context.persistDbDirectly || saveDB)(latestDb);`.

Author Vitest unit tests in `src/main/library-state/loader.test.ts`.
