     export function normalizeSaveStrategy(strategy?: SupportedSaveStrategy | (string & {}) | string | null): CanonicalSaveStrategy | 'generic' {
       if (typeof strategy !== 'string' || !strategy.trim()) return 'generic';
       const clean = strategy.toLowerCase().trim();
       return Object.hasOwn(STRATEGY_CANONICAL_MAP, clean)
         ? (STRATEGY_CANONICAL_MAP[clean] as CanonicalSaveStrategy | 'generic')
         : 'generic';
     }

2. **Headless Schema Extraction (`extractSaveSchema`)**:
   - Implement `YumeEngine.extractSaveSchema(strategy: SupportedSaveStrategy | (string & {}), rawData: any, options?: SaveSchemaOptions): NormalizedSaveDto` in `packages/yume-engine/src/save-codecs/schema/`:
     - Invokes `const canonical = normalizeSaveStrategy(strategy)` on ingress and assigns `strategy: canonical` on the returned `NormalizedSaveDto`, guaranteeing all emitted DTOs contain canonical strategy identifiers.
     - Accepts typed `options?: SaveSchemaOptions` from `packages/yume-engine/src/types.ts` (propagating `shouldCancel`, `onProgress`, `stalenessTimeoutMs`, `gameKey`, `fileName`, and `metadata`).
     - **Ingress Boundary Guard**: If `rawData` is null, undefined, or a non-object primitive, return a safe empty schema DTO with canonical strategy:
       ```typescript
       const canonical = normalizeSaveStrategy(strategy);
       if (!rawData || typeof rawData !== 'object') {
         return {
           gameKey: options?.gameKey ?? '',
           fileName: options?.fileName ?? '',
           strategy: canonical,
           tabs: [],
           fields: []
         };
       }
       ```
     - **Metadata Ingress & Defensive Scalar Coercion**: Consumes `options.metadata` (alongside `rawData._userMappings`) to populate `SaveFieldDto.label`. Because `System.json` variable and switch arrays in RPG Maker MV/MZ and Wolf RPG are 1-based and sparse (where unnamed entries default to `""`, `null`, numbers, or `undefined` array holes), normalize variable and switch labels with defensive scalar coercion, newline normalization, and trimming:
       ```typescript
       const resolvedLabel = String(options?.metadata?.variables?.[key] ?? '').replace(/[\r\n]+/g, ' ').trim().normalize('NFC') || `Variable ${key}`;
       const resolvedSwitchLabel = String(options?.metadata?.switches?.[key] ?? '').replace(/[\r\n]+/g, ' ').trim().normalize('NFC') || `Switch ${key}`;
       ```
       This guarantees `extractSaveSchema` never throws `TypeError: ...trim is not a function` on non-string scalars, normalizes embedded newlines to match translation keys, normalizes labels to Unicode NFC ('NFC') to prevent decomposed MultiOS string mismatches across platforms, and never produces blank labels for unnamed variables or switches.
     - **Zero Stream Pollution & User Logger Exception Isolation (`OBS-LIBRARY-SDK` & `EDGE-LIBRARY-BOUNDARIES`)**:
       - Codecs in `@yumeshelf/engine` MUST NEVER call `console.log`, `console.warn`, `console.error`, `process.stdout.write`, or `process.stderr.write`.
       - Telemetry is emitted exclusively through `options.logger` wrapped in `safeLog` so external logger errors never abort valid schema extraction:
         ```typescript
         export function safeLog(
           logger: EngineLogger | undefined,
           level: 'debug' | 'info' | 'warn' | 'error',
           message: string,
           context?: Record<string, unknown>
         ): void {
           try {
             logger?.[level]?.(message, context);
           } catch {
             // Telemetry and external logger failures MUST NEVER abort core business logic
           }
         }
         ```
       - `SaveCodecError` accepts `ErrorOptions` (`{ cause?: unknown }`) to preserve root cause error stacks when rethrowing parser or decompression failures.
     - **Scalar Type Dispatch & Non-Scalar Exclusion Invariant**: Emits only scalar values (`number | string | boolean`) on `SaveFieldDto.value`. Normalizes uninitialized raw values (`null` or `undefined` in sparse arrays such as `variables._data[i]`) to default scalars (`0` for `type: 'number'`, `false` for `type: 'boolean'`, `""` for `type: 'string'`). Deterministically skips and excludes unclonable runtime references (functions, symbols, bigints, class instances, circular references) and non-scalar complex values (arrays, plain objects) stored in raw save variables:
       ```typescript
       // In YumeEngine.extractSaveSchema:
       if (typeof rawVal === 'number') {
         value = Number.isFinite(rawVal) ? rawVal : 0;
         type = 'number';
       } else if (typeof rawVal === 'string' || typeof rawVal === 'boolean') {
         value = rawVal;
         type = typeof rawVal;
       } else if (rawVal === null || rawVal === undefined) {
         value = defaultScalar; // Coerce to 0, false, or "" per uninitialized value normalization
         type = defaultType;
       } else {
         // Skip non-scalar complex variables (arrays, objects) and unclonable references (functions, symbols, bigints)
         continue;
       }
       ```
       This prevents V8 serialization failures (`DataCloneError`) across the Electron `contextBridge` / IPC boundary, and guarantees via `applySaveUpdates` zero-data-loss invariant that unrepresented complex structures remain 100% intact and uncorrupted in the binary save file.
     - RPG Maker MV/MZ: Extract variables (`variables._data`), switches (`switches._data`), party gold, and playtime into structured tabs.
     - Ren'Py: Extract global variables from pickle store dictionary, gold/money variables, and persistent flags.
     - Wolf RPG: Extract numerical and string variable tables from `.sav` data chunks, emitting `variables:sys_<N>` for `sys_*` system variables and `variables:<N>` for numeric matrix keys under scalar normalization rules.
     - TINC: Extract decrypted JSON `data_*` properties.
     - Unity Mono / Pure JSON: Extract key-value fields.
     - **Codec Format & Compression Preservation**: Codec format and compression parameters (e.g. distinguishing LZ-String base64 compressed RPG Maker MV/MZ saves from raw uncompressed JSON, or Wolf RPG binary headers) are determined statelessly by inspectable buffer characteristics in `YumeEngine.applySaveUpdates(strategy, rawBuffer, updates, options)`, ensuring surgical re-encoding symmetrically retains the original file encoding without relying on stateful facade caches across process boundaries. Save codecs enforce an explicit 64MB decompressed payload ceiling (`maxDecompressedBytes = 64 * 1024 * 1024`) during decompression to prevent memory exhaustion and zip-bomb denial of service.
