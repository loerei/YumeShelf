# 01.4.2.3.2 — Add Manual Game Dialog, IPC Controller & Preload Wiring ($B$)

## Epic
[PRD: Storage Schema Migration & Library Domain Core](file:///d:/Projects/YumeShelf/docs/specs/07-storage-schema-migration-and-domain-core/PRD.md)

## What to build
Implement native Electron file picker dialog orchestration outside the serialization queue, default folder path validation, IPC contracts, preload bridge, and controller delegation for manual game additions:
1. Default path validation & Dialog orchestration in `src/main/library-state/actions.ts`:
   - Signature:
     ```typescript
     export async function addManualGame(
       context: LibraryContextInternal,
       options?: { folderPath?: string; targetPlatform?: PlatformInput } | string
     ): Promise<{ ok: boolean; game?: LogicalGame; canceled?: boolean; error?: string }>
     ```
   - Normalizes input parameters at entry: `const normalizedOpts = typeof options === 'string' ? { folderPath: options.trim() } : (options ?? {});`.
   - Checks `if (context.isDegraded?.() === true) { console.warn('[LIBRARY_STATE][ADD_MANUAL_GAME] Operation aborted: database is in DEGRADED state'); return { ok: false, error: 'degraded-database' }; }` immediately at function entry prior to invoking file dialogs. Loads the database snapshot via `const db = await context.loadDB();` and verifies the dual degraded database guard post-load (`if (context.isDegraded?.() === true) { console.warn('[LIBRARY_STATE][ADD_MANUAL_GAME] Operation aborted: database is in DEGRADED state'); return { ok: false, error: 'degraded-database' }; }`). Resolves `const targetPlatform = normalizedOpts.targetPlatform || context.targetPlatform;` and derives canonical configuration via `const config = normalizeLibraryConfigShape(db.config, targetPlatform);`. Fails fast immediately if `!config.libraryPaths || config.libraryPaths.length === 0`, logging `console.warn('[LIBRARY_STATE][ADD_MANUAL_GAME] Aborted: no library paths configured in library.', { configuredRoots: config.libraryPaths });` and returning `{ ok: false, error: 'outside-library' }`. Consumes `dialog` from injected `context` (`const { dialog } = context;`). If `dialog?.showOpenDialog` is omitted or unavailable, log structured diagnostic warning `console.warn('[LIBRARY_STATE][ADD_MANUAL_GAME] Native directory open dialog is unavailable in current runtime context.', { targetPlatform });` and defensively return `{ ok: false, error: 'dialog-unavailable' }` to ensure 100% in-memory virtual testability without requiring live Electron instances.
   - Extracts explicit folder path: validates `rawFolderPath = normalizedOpts.folderPath;` to ensure it is a string without control characters, null bytes, or prototype keys (`const explicitFolderPath = typeof rawFolderPath === 'string' && rawFolderPath.trim().length > 0 && !/\0|\r|\n/.test(rawFolderPath) && !['__proto__', 'constructor', 'prototype'].includes(rawFolderPath.trim()) ? rawFolderPath.trim() : undefined;`). Before passing to `dialog.showOpenDialog({ defaultPath })`, validates that if `explicitFolderPath` is provided and resides within `config.libraryPaths` (via `isSubsumedBy`), storing the validated path as `const validatedEnclosing = (explicitFolderPath && config.libraryPaths.some(r => isSubsumedBy(explicitFolderPath, r, targetPlatform))) ? explicitFolderPath : undefined;`. If `explicitFolderPath` is missing, invalid, or outside `config.libraryPaths`, safely computes `const fallbackDefault = (await resolveLibraryFolderToOpen(context)) || config.libraryPaths[0];` and sets `const defaultPath = validatedEnclosing || fallbackDefault;`, while `validatedEnclosing` remains `undefined`.
   - Wraps `dialog.showOpenDialog` in a `try ... catch` error boundary:
     ```typescript
     let result;
     try {
       result = await dialog.showOpenDialog({ defaultPath, filters, properties: ['openFile'] });
     } catch (err) {
       console.error('[ADD_MANUAL_GAME] Open dialog failed:', { error: err, defaultPath });
       return { ok: false, error: err instanceof Error ? err.message : String(err) };
     }
     ```
     logging structured diagnostics and returning `{ ok: false, error }` upon dialog failure or rejection.
   - Opens file dialog with platform-specific executable filters branched on `targetPlatform` (`.exe` on Windows, `.app` on macOS, all/binaries on Linux) asynchronously outside the serialization queue.
   - If dialog is canceled or no files are selected (`result.canceled === true || !result.filePaths || result.filePaths.length === 0 || !result.filePaths[0]`), returns `{ ok: false, canceled: true }` immediately without invoking `addManualGameCore`.
   - If a file is selected (`const selectedPath = result.filePaths[0];`), invokes `addManualGameCore(context, selectedPath, { enclosingFolderPath: validatedEnclosing, targetPlatform })`, decoupling `defaultPath` from `enclosingFolderPath` so generic dialog invocations or fallbacks validate against any configured library root while valid scoped prompts enforce folder containment.
2. Facade Binding in `src/main/library-state/index.ts`:
   - Re-export `addManualGame` from `./actions`.
   - Bind `addManualGame` on `createLibraryState`:
     ```typescript
      addManualGame: (options?: { folderPath?: string; targetPlatform?: PlatformInput } | string) => {
        const normalizedOpts = typeof options === 'string' ? { folderPath: options.trim() } : (options ?? {});
        return addManualGame(context, { ...normalizedOpts, targetPlatform: normalizedOpts.targetPlatform || context.targetPlatform });
      },
     ```
3. IPC Contract & Preload Bridge:
   - Declare on `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     addManualGame(data?: { folderPath?: string } | string): Promise<{ ok: boolean; game?: any; canceled?: boolean; error?: string }>;
     ```
   - Expose in `src/preload.ts`:
     ```typescript
     addManualGame: (data) => ipcRenderer.invoke('library:add-manual-game', data),
     ```
4. IPC Controller Handler in `src/main/ipc/controllers/library.controller.ts`:
   - Register `library:add-manual-game` normalizing the incoming transport payload at the membrane boundary before delegating to domain actions:
      ```typescript
      const rawPath = typeof payload === 'string'
        ? payload.trim()
        : (payload && typeof payload === 'object' && typeof (payload as any).folderPath === 'string'
          ? (payload as any).folderPath.trim()
          : undefined);
      const folderPath = rawPath && !/\0|\r|\n/.test(rawPath) && !['__proto__', 'constructor', 'prototype'].includes(rawPath)
        ? rawPath
        : undefined;
      const options: { folderPath?: string } = folderPath ? { folderPath } : {};
      return libraryState.addManualGame(options);
      ```

Author Vitest unit tests in `src/main/library-state/actions-manual-game.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
