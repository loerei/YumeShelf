# 02.2.1 — Main Process Extraction Cascade Consolidation ($B$)

## Epic
PRD: Move Headless Icon Extraction to @yumeshelf/engine

## What to build
Consolidate the icon extraction cascade in the Electron Main process in `src/main/icon-pipeline/service.ts`. Extract internal helper `processIconExtraction(targetPath: string, signal?: AbortSignal, options?: Partial<ExtractIconOptions>): Promise<ProcessedIconResult | null>` that unifies the 5-stage cascade across `handleProtocolRequest` and `resolveIconDataUrl`. Consolidate disk cache hit check, headless engine extraction via `YumeEngine.extractIcon`, client abort checking, Chromium `nativeImage` transcoding for synthesized DIB ICOs and macOS Apple `.icns` with strict PNG fallback to `app.getFileIcon`, alpha-channel padding cropping, and asynchronous disk cache writing via `storeHighResIconInCache`. Use canonical source identifiers across the pipeline: `'cached-high-res' | 'local-image' | 'desktop-entry' | 'pe-rsrc-extracted' | 'pe-rsrc-ico-converted' | 'pe-rsrc-ico' | 'app-bundle-extracted' | 'extracted-high-res' | 'app-file-icon-fallback'`. Extend `IconPipelineOptions` to include `extractIconOptions?: Partial<ExtractIconOptions>;` parameter seam.

  ```typescript
  async function processIconExtraction(
    targetPath: string,

  ```
  - Stage 1: Disk Cache Lookup:
    - Query `tryGetCachedIconBuffer(app, targetPath)`.
    - If cache hit: return immediately with `{ buffer: cachedBuffer, mimeType: 'image/png', source: 'cached-high-res' }`.
  - Stage 2 & 3: Headless Engine Delegation:
    - Invoke `YumeEngine.extractIcon` forwarding caller options inside a `try...catch` block to ensure unexpected engine exceptions (e.g. corrupt binary structures or filesystem read errors) log a diagnostic warning and cleanly fall through to Stage 4 and Stage 5:
      ```typescript
      let extracted: ExtractedIconResult | null = null;
      try {
        const extractOptions: ExtractIconOptions = {
          ...pipelineOptions.extractIconOptions,
          ...options,
          signal: signal ?? options?.signal ?? pipelineOptions.extractIconOptions?.signal
        };
        extracted = await YumeEngine.extractIcon(targetPath, extractOptions);
      } catch {
        extracted = null;
      }
      ```
    - Check abort signal: if `signal?.aborted`, return `null`.
    - If `extracted !== null`, handle extracted result:
      - `'local-image'` | `'desktop-entry'`:
        - Return `{ buffer: extracted.buffer, mimeType: extracted.mimeType, source: extracted.source as any }`.
      - `'pe-rsrc'` | `'pe-resource'`:
        - If `extracted.isPng`: crop transparent padding via `cropTransparentPaddingFromBuffer(extracted.buffer, { nativeImage: nativeImageFactory })`, fire-and-forget store in cache via `storeHighResIconInCache(app, targetPath, croppedBuffer, { source: 'pe-rsrc', width: extracted.width, height: extracted.height }).catch(() => {})`, and return `{ buffer: croppedBuffer, mimeType: 'image/png', source: 'pe-rsrc-extracted', width: extracted.width, height: extracted.height, crop: cropSummary }`.
        - If `!extracted.isPng`: transcode synthesized ICO to PNG via `convertIcoBufferToPng(extracted.buffer, nativeImageFactory)`. If transcoding succeeds: crop transparent padding via `cropTransparentPaddingFromBuffer(transcodedBuffer, { nativeImage: nativeImageFactory })`, store in cache fire-and-forget with `source: 'pe-rsrc-ico-converted'` via `storeHighResIconInCache(app, targetPath, croppedBuffer, { source: 'pe-rsrc-ico-converted', width: extracted.width, height: extracted.height }).catch(() => {})`, and return `{ buffer: croppedBuffer, mimeType: 'image/png', source: 'pe-rsrc-ico-converted', width: extracted.width, height: extracted.height, crop: cropSummary }`. If transcoding fails: return raw synthesized ICO buffer with `{ buffer: extracted.buffer, mimeType: 'image/x-icon', source: 'pe-rsrc-ico', width: extracted.width, height: extracted.height }`.
      - `'app-bundle'`:
        - If `extracted.isPng`: crop transparent padding via `cropTransparentPaddingFromBuffer(extracted.buffer, { nativeImage: nativeImageFactory })`, store in cache fire-and-forget via `storeHighResIconInCache(app, targetPath, croppedBuffer, { source: 'app-bundle' }).catch(() => {})`, and return `{ buffer: croppedBuffer, mimeType: 'image/png', source: 'app-bundle-extracted', crop: cropSummary }`.
        - If `!extracted.isPng`: transcode Apple `.icns` buffer to PNG if `nativeImageFactory && typeof nativeImageFactory.createFromBuffer === 'function'`:
          - Wrap transcoding in `try...catch`:
            - Create native image: `const img = nativeImageFactory.createFromBuffer(extracted.buffer)`.
            - If image is valid and non-empty (`img && !img.isEmpty() && typeof img.toPNG === 'function'`):
              - Convert to PNG buffer via `img.toPNG()`.
              - Crop transparent padding via `cropTransparentPaddingFromBuffer(pngBuffer, { nativeImage: nativeImageFactory })`.
              - Store in cache fire-and-forget via `storeHighResIconInCache(app, targetPath, croppedBuffer, { source: 'app-bundle' }).catch(() => {})`.
              - Return `{ buffer: croppedBuffer, mimeType: 'image/png', source: 'app-bundle-extracted', crop: cropSummary }`.
          - Strict PNG egress: if `nativeImageFactory` is omitted, throws, or produces an empty/invalid image, DO NOT return raw `.icns` bytes (unrenderable in Chromium); fall through to Stage 5 (`app.getFileIcon`).
  - Stage 4: Windows Native Worker Pool Fallback (PE binaries only):
    - Disqualify macOS bundles: `const isMacBundle = targetPath.toLowerCase().endsWith('.app') || !!resolveBundleRoot(targetPath);`
    - Evaluate target platform seam: `const currentPlatform = options?.targetPlatform ?? pipelineOptions.extractIconOptions?.targetPlatform ?? process.platform;`
    - If `currentPlatform === 'win32' && !isMacBundle && !signal?.aborted`:
      - Call `await pool.enqueueExtraction(targetPath)`.
      - If valid base64 returned: crop padding via `cropTransparentPaddingFromBuffer(buffer, { nativeImage: nativeImageFactory })`, store in cache, and return `{ buffer: croppedBuffer, mimeType: 'image/png', source: 'extracted-high-res', debug: { extractor: result.meta || null } }`.
  - Stage 5: App Native File Icon Fallback:
    - Check abort signal immediately before shell fallback:
      ```typescript
      if (signal?.aborted) {
        return null;
      }
      ```
    - Call `await app.getFileIcon(targetPath, { size: 'large' })` enclosed in a `try...catch` block returning `null` on shell failure:
      ```typescript
      try {
        const icon = await app.getFileIcon(targetPath, { size: 'large' });
        if (!icon || icon.isEmpty()) return null;
        const fallbackBuffer = icon.toPNG();
        const { buffer: croppedFallback, cropSummary } = cropTransparentPaddingFromBuffer(
          fallbackBuffer,
          { nativeImage: nativeImageFactory }
        );
        storeHighResIconInCache(app, targetPath, croppedFallback, { source: 'app-file-icon-fallback' }).catch(() => {});
        return {
          buffer: croppedFallback,
          mimeType: 'image/png',
          source: 'app-file-icon-fallback',
          crop: cropSummary
        };
      } catch {
        return null;
      }
      ```
