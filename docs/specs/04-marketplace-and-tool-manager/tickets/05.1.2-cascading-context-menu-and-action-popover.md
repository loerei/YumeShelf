# 05.1.2 — 3-Tier Cascading Context Menu & Action Popover

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The **3-Tier Cascading Context Menu** on Game Cards (`🧩 Add-ons ▶` $\to$ compatible tool list $\to$ action flyout) with hover debounce, boundary collision clamping, optimistic launch toggles, dynamic input popover form rendering for actions declaring `inputSchema`, and adaptive disabled states when game is running.

## Explicit Assumptions & Boundaries
- Actions without `inputSchema` execute immediately upon click (1-click simplicity).
- Actions declaring `inputSchema` open a native popover modal for parameter input prior to task dispatch.
- Adaptive UI: When target game is actively running, task action menu items are grayed out (disabled) with an informative tooltip (`⚠️ Game is currently running. Please close the game before running tasks.`).

- [ ] Handle 1-click vs interactive action execution:
  - If `action.inputSchema` exists, render interactive popover modal with default values.
