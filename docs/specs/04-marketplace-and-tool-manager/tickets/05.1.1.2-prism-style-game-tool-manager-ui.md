# 05.1.1.2 — Prism-Style Game Tool Manager UI (Behavioral Feature $B$)

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The Prism-style "Tools / Add-ons" tab inside the Game Details modal (table view of assigned tools, active switches, action execution triggers, and adaptive grayed-out UI states when game is running).

## Explicit Assumptions & Boundaries
- Toggling a tool stores state via `05.1.1.1` IPC without touching the base game directory until launch time.
- Adaptive UI: When the game is actively running (`playtimeSessionManager.isGameActive(gameKey)`), action buttons are grayed out (disabled) with an explanatory tooltip (`⚠️ Game is currently running. Please close the game before running tasks.`).
