## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Visual folder cards rendered in the game grid matching standard card dimensions, featuring an automated 2x2 thumbnail preview grid of up to 4 child game icons (consuming `extractFolderPreviewThumbnails` from `04.1.1`), folder title display with HTML entity escaping, inline renaming on double-click or F2, and a 3-dot context menu for folder actions.

## Acceptance criteria
- [ ] Render closed folder cards with uniform dimensions matching regular game cards in the library grid with accessibility labels set via `element.setAttribute('aria-label', ...)` or with `folderName` sanitized via `escapeHtml(folderName)` before template interpolation (`"Folder: ${escapedName}, ${itemCount} items"`) to prevent DOM attribute injection.
- [ ] Display an automated 2x2 preview grid inside the folder card showing thumbnail icons (with `alt=""` decorative attribute) of the first 1–4 child games, enforcing fixed `1/1` aspect ratio and `contain-intrinsic-size` on thumbnail cells to prevent CLS.
- [ ] Consume thumbnail references from `extractFolderPreviewThumbnails` (`04.1.1`).
- [ ] Support inline renaming of the folder upon double-clicking the folder title or pressing `F2` shortcut (trimmed $\le 100$ characters with `"New Folder"` fallback). Ensure visible folder names rendered on folder cards, inline renaming inputs, and folder action menus are assigned via `element.textContent = folderName` or sanitized via `escapeHtml(folderName)` prior to HTML template interpolation to prevent stored DOM XSS.
- [ ] Provide a 3-dot context menu button (`aria-haspopup="menu"`, `aria-expanded`) on folder cards with "Rename" and "Dissolve Folder" options. Support pluggable downstream action items via `cardActionMenuProviders?: Array<ICardActionMenuProvider>` extension seam.
- [ ] Clicking "Dissolve Folder" emits an `onDissolve(folderId)` callback / event with the targeted folder ID; inline rename emits an `onRename(folderId, newName)` callback, keeping leaf card presentation decoupled from container state orchestration.
- [ ] Unit/integration tests verifying folder card rendering, preview aspect ratio CLS containment, safe accessibility attribute setting, HTML entity escaping, context menu actions, and `cardActionMenuProviders` extension item rendering in `src/renderer/ui-components/folder-card.test.ts`.
- [ ] Execute automated component tests via `npm run test:vitest -- src/renderer/ui-components/folder-card.test.ts` with standard output containing `'✓ renderer/ui-components/folder-card.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
