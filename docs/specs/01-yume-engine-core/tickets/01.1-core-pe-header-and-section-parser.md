# 01.1 — Core PE Header & Section Table Parser

## Epic
PRD 01: YumeEngine Core Architecture & Headless Extraction

## What to build
A pure TypeScript Portable Executable header and section table parser in `@yumeshelf/engine` implementing bounds-checked buffer reads, DOS/PE/COFF headers, Section Table mapping, safe `rvaToOffset` bounds checking, and two-stage asynchronous file streaming.

## Attribution Requirement
- Include MIT attribution header for `horsicq (Detect-It-Easy / XPEViewer)`.

## Blocked by
- 00 — Monorepo Workspace & Package Scaffolding

## Status
ready-for-agent

## Acceptance criteria
- [x] Implement bounds-checked buffer read helpers (`safeReadUInt16LE`, `safeReadUInt32LE`, `safeReadBytes`) validating `offset + byteLength <= buffer.length` on every chunk read, returning safe fallback profiles without throwing unhandled `RangeError` on damaged/truncated binaries.
- [x] Parse DOS Header (`e_magic == 0x5A4D`, `e_lfanew` at `0x3C`) and validate PE signature (`PE\0\0`).
- [x] Parse COFF File Header (`Machine` type `0x014C` for x86 vs `0x8664` for x64, `NumberOfSections`, `SizeOfOptionalHeader`), enforcing boundary limits (`sizeOfOptionalHeader <= 4096`, `numberOfSections <= 96`).
- [x] Parse Section Table (40-byte `IMAGE_SECTION_HEADER` array) and implement safe `rvaToOffset(rva: number): number | null` (verifying `sec.rawOffset > 0 && sec.rawSize > 0 && rva >= sec.virtualAddress && (rva - sec.virtualAddress) < sec.rawSize`, returning `null` for unmapped disk space or RVAs below the section base).
- [x] Implement `PEInspector.fromBuffer(buf)` (synchronous in-memory parsing for full buffers & synthetic unit tests) and `PEInspector.fromPath(path, fs: IFileSystem)` (asynchronous 2-stage lazy streaming using `await fs.open(path)` $\to$ `IFileHandle.read(offset, length)`).
- [x] Implement two-stage header parsing with lazy RVA chunk reading via `IFileHandle.read` (initial 4KB header slice, on-demand 4KB–16KB chunk reads at resolved offsets for large multi-MB binaries, bounded $\le 64\text{KB}$ RAM).
- [x] Ensure deterministic file handle disposal in `PEInspector.fromPath` via `await handle.close()` in `try...finally` block.
- [x] Unit tests using `synthetic-pe-builder.ts` minimal PE32 and PE32+ fixture buffers (including large binary layouts with high section offsets, zero-raw data sections, and truncated byte buffers) verifying fast, error-free parsing (< 500ms).
- [x] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test -- tests/pe-headers.test.ts` verifying 100% passing tests.
- [x] Verify that `pnpm --filter @yumeshelf/engine build` compiles TypeScript declarations and bundle artifacts into `packages/yume-engine/dist/` cleanly in isolation.
