1. **Windows-Resilient Filesystem Helpers (`src/main/save-editor/fs-utils.ts`)**:
   - `ensureWritable(targetPath: string, fsPromises: typeof fs.promises)` & `ensureWritableSync(targetPath: string, customFs: typeof fs)`:
     - Checks file permissions via `stat` and if `(stat.mode & 0o222) === 0`, clears read-only attributes via `chmod(targetPath, stat.mode | 0o666)`.
   - `resilientRename(src, dest, maxRetries = 5, initialBackoffMs = 50, customFs = fs, jitterFn = () => Math.floor(Math.random() * 25))`:
     - Retries up to 5 times with exponential backoff and random jitter (`delay + jitterFn()`) on transient Windows lock errors (`EBUSY`, `EPERM`, `EACCES`), clearing destination read-only permissions via `ensureWritable` upon encountering `EPERM`.
     - Falls back to atomic two-stage cross-device staging on `EXDEV` error (staging to `${dest}.tmp.${Date.now()}_${process.pid}_exdev_${salt}`, ensuring write permissions on staging before opening descriptor with `'r+'` for Windows `handle.sync()`, executing atomic intra-filesystem rename to `dest` with destination permission clearance, unlinking `src` only after `dest` is safely replaced with source permission clearance, and executing non-swallowing sanitized error recovery):
       ```typescript
       export async function ensureWritable(targetPath: string, fsPromises: typeof fs.promises): Promise<void> {
         try {
           const stat = await fsPromises.stat(targetPath);
           if ((stat.mode & 0o222) === 0) {
             await fsPromises.chmod(targetPath, stat.mode | 0o666);
           }
         } catch {
           // Ignore ENOENT or stat errors; rename/unlink will handle accordingly
         }
       }

       export async function resilientRename(
         src: string,
         dest: string,
         maxRetries = 5,
         initialBackoffMs = 50,
         customFs: typeof fs = fs,
         jitterFn: () => number = () => Math.floor(Math.random() * 25)
       ): Promise<void> {
         const safeMax = Number.isFinite(maxRetries) ? Math.trunc(maxRetries) : 5;
         const boundedMaxRetries = Math.max(1, safeMax);
         const safeBackoff = Number.isFinite(initialBackoffMs) ? Math.trunc(initialBackoffMs) : 50;
         const clampedInitialDelay = Math.max(1, safeBackoff);
         let delay = clampedInitialDelay;
         for (let attempt = 1; attempt <= boundedMaxRetries; attempt++) {
           try {
             await customFs.promises.rename(src, dest);
             return;
           } catch (err: unknown) {
             const code = (err as NodeJS.ErrnoException).code;
             if (code === 'EXDEV') {
               const stagingPath = `${dest}.tmp.${Date.now()}_${process.pid}_exdev_${Math.random().toString(36).slice(2, 8)}`;
               let handle: fs.promises.FileHandle | null = null;
               try {
                 await customFs.promises.copyFile(src, stagingPath);
                 await ensureWritable(stagingPath, customFs.promises);
                 handle = await customFs.promises.open(stagingPath, 'r+');
                 await handle.sync();
                 await handle.close();
                 handle = null;

                 let destRenameDelay = clampedInitialDelay;
                 let destRenameSuccess = false;
                 let destRenameErr: unknown;

                 for (let destAttempt = 1; destAttempt <= boundedMaxRetries; destAttempt++) {
                   try {
                     await customFs.promises.rename(stagingPath, dest);
                     destRenameSuccess = true;
                     break;
                   } catch (subErr: unknown) {
                     destRenameErr = subErr;
                     const subCode = (subErr as NodeJS.ErrnoException).code;
                     if (subCode === 'EPERM') {
                       await ensureWritable(dest, customFs.promises);
                     }
                     const isLock = subCode === 'EBUSY' || subCode === 'EPERM' || subCode === 'EACCES';
                     if (isLock && destAttempt < boundedMaxRetries) {
                       const jitter = jitterFn();
                       await new Promise((res) => setTimeout(res, destRenameDelay + jitter));
                       destRenameDelay *= 2;
                       continue;
                     }
                     break;
                   }
                 }

                 if (!destRenameSuccess) {
                   throw destRenameErr;
                 }

                 await ensureWritable(src, customFs.promises);
                 await customFs.promises.unlink(src).catch((unlinkErr: any) => {
                   if (unlinkErr?.code !== 'ENOENT') {
                     console.warn('[fs-utils:resilientRename] Failed to unlink source file after EXDEV copy:', {
                       src: sanitizeUserPaths(src),
                       error: sanitizeUserPaths(unlinkErr?.message || String(unlinkErr)),
                       code: unlinkErr?.code,
                     });
                   }
                 });
                 return;
               } catch (copyErr) {
                 if (handle !== null) {
                   try {
                     await handle.close();
                   } catch (closeErr) {
                     console.warn('[fs-utils:resilientRename] Failed to close staging handle during error recovery:', {
                       stagingPath: sanitizeUserPaths(stagingPath),
                       error: sanitizeUserPaths((closeErr as Error)?.message || String(closeErr)),
                     });
                   }
                 }
                 await ensureWritable(stagingPath, customFs.promises);
                 await customFs.promises.unlink(stagingPath).catch((unlinkErr: any) => {
                   if (unlinkErr?.code !== 'ENOENT') {
                     console.warn('[fs-utils:resilientRename] Failed to unlink staging temp file during error recovery:', {
                       stagingPath: sanitizeUserPaths(stagingPath),
                       error: sanitizeUserPaths(unlinkErr?.message || String(unlinkErr)),
                     });
                   }
                 });
                 throw copyErr;
               }
             }
             if (code === 'EPERM') {
               await ensureWritable(dest, customFs.promises);
             }
             const isLockError = code === 'EBUSY' || code === 'EPERM' || code === 'EACCES';
             if (isLockError && attempt < boundedMaxRetries) {
               const jitter = jitterFn();
               await new Promise((res) => setTimeout(res, delay + jitter));
               delay *= 2;
               continue;
             }
             throw err;
           }
         }
       }
       ```
   - `syncSleep(ms: number)`:
     - Non-spinning synchronous sleep helper using `Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms)` with defensive early return on `!Number.isFinite(ms) || ms <= 0`.
   - `resilientRenameSync`:
     - Commits renames synchronously with defensive parameter clamping (`Math.min(3, Math.max(1, safeMaxRetries))`, `Math.min(25, Math.max(1, safeInitialBackoff))`), unified total stall budget enforcement ($\le 75$ms) across primary and `EXDEV` staging retry loops, optional `syncSleepFn: (ms: number) => void = syncSleep` injection seam, and symmetric atomic `EXDEV` staging fallback with `'r+'` handle sync, closing open handles and unlinking staging files on failure:
       ```typescript
       export function syncSleep(ms: number): void {
         if (!Number.isFinite(ms) || ms <= 0) return;
         const sab = new SharedArrayBuffer(4);
         const int32 = new Int32Array(sab);
         Atomics.wait(int32, 0, 0, ms);
       }

       export function ensureWritableSync(targetPath: string, customFs: typeof fs): void {

           if ((stat.mode & 0o222) === 0) {
             customFs.chmodSync(targetPath, stat.mode | 0o666);

       export function resilientRenameSync(
         src: string,
         dest: string,
         maxRetries = 3,
         initialBackoffMs = 25,
         customFs: typeof fs = fs,
         syncSleepFn: (ms: number) => void = syncSleep
       ): void {
         const safeMaxRetries = Number.isFinite(maxRetries) ? maxRetries : 3;
         const boundedMaxRetries = Math.min(3, Math.max(1, safeMaxRetries));
         const safeInitialBackoff = Number.isFinite(initialBackoffMs) ? initialBackoffMs : 25;
         let delay = Math.min(25, Math.max(1, safeInitialBackoff));
         let totalStall = 0;

         for (let attempt = 1; attempt <= boundedMaxRetries; attempt++) {
           try {
             customFs.renameSync(src, dest);
             return;
           } catch (err: unknown) {
             const code = (err as NodeJS.ErrnoException)?.code;
             if (code === 'EXDEV') {
               const stagingPath = `${dest}.tmp.${Date.now()}_${process.pid}_exdev_${Math.random().toString(36).slice(2, 8)}`;
               let fd: number | null = null;
               try {
                 customFs.copyFileSync(src, stagingPath);
                 ensureWritableSync(stagingPath, customFs);
                 fd = customFs.openSync(stagingPath, 'r+');
                 customFs.fsyncSync(fd);
                 customFs.closeSync(fd);
                 fd = null;

                 let destRenameSuccess = false;
                 let destRenameErr: unknown;
                 let destDelay = Math.min(25, Math.max(1, safeInitialBackoff));

                 for (let destAttempt = 1; destAttempt <= boundedMaxRetries; destAttempt++) {
                   try {
                     customFs.renameSync(stagingPath, dest);
                     destRenameSuccess = true;
                     break;
                   } catch (subErr: unknown) {
                     destRenameErr = subErr;
                     const subCode = (subErr as NodeJS.ErrnoException)?.code;
                     if (subCode === 'EPERM') {
                       ensureWritableSync(dest, customFs);
                     }
                     const isLock = subCode === 'EBUSY' || subCode === 'EPERM' || subCode === 'EACCES';
                     const sleepMs = Math.min(25, destDelay);
                     if (isLock && destAttempt < boundedMaxRetries && totalStall + sleepMs <= 75) {
                       totalStall += sleepMs;
                       syncSleepFn(sleepMs);
                       destDelay = Math.min(25, destDelay * 2);
                       continue;
                     }
                     break;
                   }
                 }

                 if (!destRenameSuccess) {
                   throw destRenameErr;
                 }

                 try {
                   ensureWritableSync(src, customFs);
                   customFs.unlinkSync(src);
                 } catch (unlinkErr: any) {
                   if (unlinkErr?.code !== 'ENOENT') {
                     console.warn('[fs-utils:resilientRenameSync] Failed to unlink source file after EXDEV copy:', {
                       src: sanitizeUserPaths(src),
                       error: sanitizeUserPaths(unlinkErr?.message || String(unlinkErr)),
                       code: unlinkErr?.code,
                     });
                   }
                 }
                 return;
               } catch (copyErr) {
                 if (fd !== null) {
                   try {
                     customFs.closeSync(fd);
                   } catch (closeErr: any) {
                     console.warn('[fs-utils:resilientRenameSync] Failed to close staging handle during error recovery:', {
                       stagingPath: sanitizeUserPaths(stagingPath),
                       error: sanitizeUserPaths(closeErr?.message || String(closeErr)),
                     });
                   }
                 }
                 try {
                   if (customFs.existsSync(stagingPath)) {
                     ensureWritableSync(stagingPath, customFs);
                     customFs.unlinkSync(stagingPath);
                   }
                 } catch (unlinkErr: any) {
                   if (unlinkErr?.code !== 'ENOENT') {
                     console.warn('[fs-utils:resilientRenameSync] Failed to unlink staging temp file during error recovery:', {
                       stagingPath: sanitizeUserPaths(stagingPath),
                       error: sanitizeUserPaths(unlinkErr?.message || String(unlinkErr)),
                     });
                   }
                 }
                 throw copyErr;
               }
             }

             if (code === 'EPERM') {
               ensureWritableSync(dest, customFs);
             }
             const isLockError = code === 'EBUSY' || code === 'EPERM' || code === 'EACCES';
             const sleepMs = Math.min(25, delay);
             if (isLockError && attempt < boundedMaxRetries && totalStall + sleepMs <= 75) {
               totalStall += sleepMs;
               syncSleepFn(sleepMs);
               delay = Math.min(25, delay * 2);
               continue;
             }

             if (isLockError && totalStall > 0) {
               console.warn('[fs-utils:resilientRenameSync] File lock contention exceeded budget:', {
                 dest: sanitizeUserPaths(dest),
                 totalStallMs: totalStall,
                 error: sanitizeUserPaths((err as Error)?.message || String(err)),
               });
             }
             throw err;
           }
         }
       }
       ```

   - `sweepOrphanedSaveTmpFiles(saveDir, maxAgeMs = 24 * 60 * 60 * 1000, now = Date.now, customFs = fs)`:
     - Unlinks orphaned temporary files older than 24 hours matching `/\.tmp\./i` or `f.includes('.tmp.')` (matching both standard atomic temporary siblings and cross-device `EXDEV` staging temp files `${dest}.tmp.<timestamp>_${pid}_exdev_${salt}`) in user save directories, logging non-fatal sanitized warning diagnostics; defensively verifies `(await fs.promises.stat(entryPath)).isFile()` prior to calling `unlink` to avoid `EISDIR`/`EPERM` errors on subdirectories matching the pattern. Resolves effective clock provider via `const nowFn = typeof now === 'function' ? now : Date.now;` before invocation to defend against explicit nullish arguments. Wraps directory reading (`readdir`) in a `try/catch` block that catches `err?.code === 'ENOENT'` and resolves cleanly as a no-op (`Promise.resolve()`) without throwing, rejecting, or emitting diagnostic warnings when the save folder does not exist on disk. Wraps both per-entry `stat` and `unlink` in individual `try/catch` blocks that catch and ignore `ENOENT` (defending against concurrent unlinking or atomic renaming by active save pipelines during directory enumeration without rejecting or crashing `SaveDataEngine.listSaveFiles`).
      ```typescript
      export async function sweepOrphanedSaveTmpFiles(
        saveDir: string,
        maxAgeMs = 24 * 60 * 60 * 1000,
        now = Date.now,
        customFs: typeof fs = fs
      ): Promise<void> {
        const nowFn = typeof now === 'function' ? now : Date.now;
        let entries: string[];
        try {
          entries = await customFs.promises.readdir(saveDir);
        } catch (err: any) {
          if (err?.code === 'ENOENT') return;
          throw err;
        }

        const nowMs = nowFn();
        for (const file of entries) {
          if (!file.includes('.tmp.')) continue;
          const entryPath = path.join(saveDir, file);
          try {
            const stat = await customFs.promises.stat(entryPath);
            if (stat.isFile() && nowMs - stat.mtimeMs > maxAgeMs) {
              try {
                await customFs.promises.unlink(entryPath);
              } catch (unlinkErr: any) {
                if (unlinkErr?.code !== 'ENOENT') {
                  console.warn('[fs-utils:sweepOrphanedSaveTmpFiles] Failed to unlink expired temp file:', {
                    path: sanitizeUserPaths(entryPath),
                    error: sanitizeUserPaths(unlinkErr?.message || String(unlinkErr)),
                  });
                }
              }
            }
          } catch (statErr: any) {
            // Ignore ENOENT if file was concurrently removed or renamed by active save pipeline
            if (statErr?.code !== 'ENOENT') {
              console.warn('[fs-utils:sweepOrphanedSaveTmpFiles] Failed to stat temp file entry:', {
                path: sanitizeUserPaths(entryPath),
                error: sanitizeUserPaths(statErr?.message || String(statErr)),
              });
            }
          }
        }
      }
      ```

       ```typescript
       // src/main/save-editor/mapping-manager.ts
       const SAFE_FILENAME_REGEX = /^(?!(?:CON|PRN|AUX|NUL|COM[0-9]|LPT[0-9])(?:\..*)?$)[^\\/:*?"<>|\x00-\x1f]+(?<![. ])$/i;
       const DANGEROUS_KEYS = new Set(['__proto__', 'constructor', 'prototype']);
       const ALLOWED_DATA_TYPES = new Set(['int32', 'int16', 'int8', 'uint32', 'uint16', 'uint8', 'float32', 'float64', 'string', 'boolean']);

       function sanitizeMappingEntries(raw: unknown): MappingEntry[] {
         if (!raw || typeof raw !== 'object') return [];
         const entries: unknown[] = Array.isArray((raw as any).variables)
           ? (raw as any).variables
           : Array.isArray(raw)
           ? (raw as unknown[])
           : [];

         const sanitized: MappingEntry[] = [];
         for (const item of entries.slice(0, 5000)) {
           if (!item || typeof item !== 'object') continue;
           const entry = item as Record<string, unknown>;
           const rawName = typeof entry.name === 'string' ? entry.name.trim().normalize('NFC') : '';
           if (!rawName || DANGEROUS_KEYS.has(rawName)) continue;

           const offset = typeof entry.offset === 'number' && Number.isFinite(entry.offset) && entry.offset >= 0
             ? Math.trunc(entry.offset)
             : null;
           if (offset === null) continue;

           const rawType = typeof entry.dataType === 'string' ? entry.dataType.toLowerCase().trim() : 'int32';
           const dataType = ALLOWED_DATA_TYPES.has(rawType) ? rawType : 'int32';

           sanitized.push({ name: rawName, offset, dataType });
         }
         return sanitized;
       }

       // Inside SaveMappingManager.load() Phase 1: Legacy migration
       const isSafeLegacyName = SAFE_FILENAME_REGEX.test(this.gameId);
       const resolvedMappingDir = path.resolve(this.mappingDir);
       const resolvedLegacyPath = path.resolve(this.mappingDir, `${this.gameId}.json`);
       const relPath = path.relative(resolvedMappingDir, resolvedLegacyPath);
       const isContained = !relPath.startsWith('..') && !path.isAbsolute(relPath);

       if (isSafeLegacyName && isContained && this.customFs.existsSync(resolvedLegacyPath)) {
         try {
           const legacyRaw = this.customFs.readFileSync(resolvedLegacyPath, 'utf-8');
           const parsed = JSON.parse(legacyRaw);
           const sanitizedEntries = sanitizeMappingEntries(parsed);

           // Modern mapping preservation invariant: DO NOT overwrite modern file if already present on disk
           if (!this.customFs.existsSync(this.mappingPath)) {
             this.mappings = { schemaVersion: 1, variables: sanitizedEntries };
             this.save();
           }

           // Commit rename of legacy file to .migrated using resilient locking
           resilientRenameSync(resolvedLegacyPath, `${resolvedLegacyPath}.migrated`, 3, 25, this.customFs);
         } catch (err) {
           console.warn('[SaveMappingManager] Legacy mapping migration skipped:', {
             gameId: sanitizeUserPaths(this.gameId),
             error: sanitizeUserPaths((err as Error)?.message || String(err)),
           });
         }
       }
       ```

- [ ] `SaveMappingManager` wraps mapping payloads in `{ schemaVersion: 1, variables: MappingEntry[] }`, enforces a 5000-entry memory cap, exposes `addMapping(name, offset, dataType)` and `addMappingAsync(name, offset, dataType)` with ingress validation (evaluating pre-mutation guard `if (this.isReadOnlyFutureVersion) throw new Error('SaveMappingManager: Cannot modify read-only future version')` prior to memory mutation or validation, deduplicating existing variable names via in-place upsert without increasing array length, normalizing `name` via NFC and trimming, rejecting empty names and prototype-polluting keys `__proto__`, `constructor`, `prototype`, rejecting non-finite or negative offsets, truncating valid offsets to integers via `Math.trunc`, normalizing `dataType` to lowercase, validating against allowed types, and defaulting omitted `dataType` to `'int32'`, throwing descriptive errors on violation).
- [ ] `SaveMappingManager` commits synchronous writes atomically via sibling replacement (`fsyncSync`, `resilientRenameSync` clamping parameters and retrying up to 3 times with bounded backoff capped at 25ms per attempt and total stall time $\le 75$ms on transient Windows lock errors, emitting `console.warn` with paths and usernames scrubbed via `sanitizeUserPaths`), preserving future schema files (`schemaVersion > 1`) intact without `.corrupt` quarantine setting `isReadOnlyFutureVersion = true` (resetting on `load()` entry and guarding `save()`/`saveAsync()` and `addMapping()`/`addMappingAsync()` against overwrites), and quarantines malformed JSON files to `.corrupt.<timestamp>` using `nowProvider` without throwing, routing all paths and error details through `sanitizeUserPaths`, verified in `mapping-manager.test.ts` with deterministic mock clock `() => 1700000000000`.
- [ ] `SaveMappingManager.saveAsync()` serializes concurrent write operations via a path-keyed mutex matching `SaveDataEngine` and `SaveEditorService`, commits writes atomically via asynchronous `resilientRename` with exponential backoff and jitter without blocking the Node.js event loop, and cleanly unlinks temporary files and closes handles on write rejections, verified in `mapping-manager.test.ts` via concurrent `Promise.all` invocations and fake timers (`vi.useFakeTimers()`).
- [ ] Assert legacy mapping migration verifies `SAFE_FILENAME_REGEX` and path containment within `mappingDir`, strips prototype-polluting keys, enforces 5,000-entry memory cap and allowlisted types, preserves existing modern mapping files without overwriting, and renames legacy files via `resilientRenameSync`, preventing path traversal, DOS reserved device hangs, and NTFS ADS errors, verified in `mapping-manager.test.ts` (including tests verifying that `gameId = '../traversal'`, `gameId = 'CON'`, and `gameId = 'steam:12345'` bypass legacy file probing and write safely to modern SHA-256 filenames without throwing `EINVAL` or escaping `mappingDir`).
- [ ] `fs-utils.ts` implements and exports `resilientRename(src, dest, maxRetries = 5, initialBackoffMs = 50, customFs = fs, jitterFn)` (with defensive parameter clamping against `NaN`, negative bounds, and zero attempts applied consistently to both primary and `EXDEV` destination rename retry loops via `clampedInitialDelay = Math.max(1, safeBackoff)`, atomic `EXDEV` cross-device staging fallback to `${dest}.tmp.<timestamp>_${process.pid}_exdev_${salt}`, `'r+'` file handle sync, atomic intra-filesystem rename, non-swallowing sanitized error recovery, and post-rename source unlinking), `resilientRenameSync` (with defensive parameter clamping against `NaN` and negative bounds, unified total stall budget $\le 75$ms across primary and `EXDEV` staging retry loops, testable `syncSleepFn` injection seam, and symmetric atomic `EXDEV` staging fallback with `'r+'` file descriptor open), `syncSleep(ms: number)` non-spinning sleep via `Atomics.wait`, `ensureWritable`, `ensureWritableSync`, and `sweepOrphanedSaveTmpFiles(saveDir, maxAgeMs, now, customFs)` (safely catching `ENOENT` on non-existent directories and wrapping per-entry `stat` and `unlink` in individual `try/catch` blocks ignoring `ENOENT` to prevent unhandled rejections during concurrent file deletion, resolving as a clean no-op without unhandled promise rejections), verified in `fs-utils.test.ts`.
- [ ] `resilientRename` and `resilientRenameSync` detect `EPERM` on pre-existing read-only destination files (mode `0o444` / `+R` on Windows), clear read-only permissions via `chmod(dest, stat.mode | 0o666)` / `chmodSync`, and atomically replace the destination without exhausting retry delay budgets, verified in `fs-utils.test.ts` using the `customFs` dependency injection seam simulating Windows `EPERM` semantics across both sync and async APIs.
- [ ] In the cross-device `EXDEV` fallback path, `resilientRename` and `resilientRenameSync` ensure write permissions on staging and source files before `open('r+')` and `unlink`, preventing `EPERM` exceptions when operating on read-only source files, verified in `fs-utils.test.ts` using the `customFs` injection seam.
- [ ] `pnpm typecheck` passes with zero errors.
