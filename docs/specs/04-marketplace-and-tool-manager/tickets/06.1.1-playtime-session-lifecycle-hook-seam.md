# 06.1.1 — Playtime Session Lifecycle Hook Seam & Concurrency Lock

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
Preparatory refactoring ($S$) in `src/main/playtime-session-manager.ts` defining the `SessionLifecycleHook` interface, implementing the asynchronous hook pipeline (`onBeforeLaunch`, `onSessionTerminated`), adding the 2-tier `inFlightLaunches` `Set<string>` transient concurrency lock and active session exclusivity per `gameKey`, exporting `isGameActive(gameKey)`, enforcing cross-subsystem mutual exclusion against `TaskRunnerService`, and decoupling legacy inline translation calls from `src/main/ipc/controllers/library.controller.ts`.

## Explicit Assumptions & Boundaries
- Establishes the decoupled structural seam required for both `AddonLifecycleService` (Ticket 06.1.2) and `CompanionSupervisor` (Ticket 07) without modifying existing session tracking behavior.
- Mutual exclusion: `launchTrackedGame(gameKey)` rejects game launch if `taskRunnerService.isTaskActive(gameKey)` with typed `TaskRunningConflictError`.

## Acceptance criteria
- [ ] Define `SessionLifecycleHook` interface and `PlaytimeSessionManagerOptions` in `src/main/playtime-session-manager.ts` (`onBeforeLaunch(sessionContext: SessionLaunchContext): Promise<void>`, `onSessionTerminated(sessionContext: SessionTerminatedContext): Promise<void>`) supporting `isTaskActive?: (gameKey: string) => boolean` for isolated testing.
- [ ] Implement `registerSessionLifecycleHook` registry and execution pipeline in `PlaytimeSessionManager`:
  - `onBeforeLaunch`: Executed sequentially in registration order (FIFO: $H_1 \to H_2 \dots \to H_n$).
  - `onSessionTerminated`: Executed sequentially in reverse registration order (LIFO: $H_n \dots \to H_2 \to H_1$).
- [ ] Implement and export `isGameActive(gameKey: string): boolean` method on `PlaytimeSessionManager` returning true if `gameKey` has an active session in `currentGameState`.
- [ ] Implement 2-tier concurrency lock lifecycle:
  - Transient launch lock `inFlightLaunches: Set<string>` acquired during asynchronous launch sequence and released in `finally` / launch failure rollback.
  - Active session exclusivity rejecting concurrent launches while game process is actively tracked.
- [ ] Enforce mutual exclusion check in `launchTrackedGame(gameKey)`: if `taskRunnerService.isTaskActive(gameKey)`, throw typed `TaskRunningConflictError`.
- [ ] Decouple and remove legacy inline translation calls (`prepareTranslator` / `removeTranslator`) from `src/main/ipc/controllers/library.controller.ts`, redirecting lifecycle management through `SessionLifecycleHook`.
- [ ] Unit tests verifying clean execution of launch/termination flows with FIFO/LIFO hook ordering, `isGameActive` state inspection, transient lock acquisition/release, task conflict rejection, and concurrency guard rejection.
