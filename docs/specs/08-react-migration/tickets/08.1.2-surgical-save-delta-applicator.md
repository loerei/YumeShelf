## What to build
Implement surgical binary delta application and re-encoding inside `@yumeshelf/engine`, guaranteeing zero data loss when persisting user-edited save variables:

1. **Surgical Save Delta Applicator (`applySaveUpdates`)**:
   - Define and export `SaveFieldScalar` (`number | string | boolean | null`) and `SaveUpdatesPayload = Record<string, SaveFieldScalar>` directly in `packages/yume-engine/src/types.ts` (establishing the `@yumeshelf/engine/types` path for type-only consumption) and re-export them from `packages/yume-engine/src/index.ts`.
   - Implement and export `YumeEngine.applySaveUpdates(strategy: SupportedSaveStrategy | (string & {}), rawBuffer: Buffer, updates: SaveUpdatesPayload, options?: SaveCodecOptions): Promise<Buffer>` in `packages/yume-engine/src/save-codecs/`:
     - Invokes `const canonical = normalizeSaveStrategy(strategy)` on ingress prior to format-specific dispatch branching, safely normalizing shorthand aliases, case variations, and whitespace variants to their canonical codec handlers.
     - Accepts original raw binary save buffer, updates record, and typed `options?: SaveCodecOptions` from `packages/yume-engine/src/types.ts`.
     - **Ingress Boundary Guard**: If `updates` is null, undefined, non-object, or contains zero keys, return `rawBuffer` immediately without modification:
       ```typescript
       if (!updates || typeof updates !== 'object' || Object.keys(updates).length === 0) {
         return rawBuffer;
       }
       ```
     - **Path Context Propagation**: Consumes `options` containing `paths` (`exeDir`, `saveDir`, `dataDir`, `langDataDir`), `fileName`, and `savePath` (merged server-authoritatively by `SaveDataEngine`) so format-specific codecs (e.g., Wolf RPG, Ren'Py, TINC) locate external encryption keys (such as `Game.exe` or `.pro` metadata files) and determine format-specific encoding strategies.
     - **Qualified Key Routing, Delimiter Verification & Prototype Pollution Defense**: Parses each key in `updates` formatted as `${tabId}:${key}` (e.g. `{"variables:1": 500, "switches:1": true}`). Imports and calls `isDangerousKey` from `packages/yume-engine/src/save-codecs/sanitize.js`, safely verifying delimiter presence and guarding against prototype pollution before mutating in-memory object graphs:
       ```typescript
       const colonIdx = qualifiedKey.indexOf(':');
       if (colonIdx === -1) {
         safeLog(options?.logger, 'warn', '[applySaveUpdates] Skipping malformed qualified key without delimiter', { qualifiedKey });
         continue;
       }
       // Note: Splitting strictly on the first colon intentionally preserves any subsequent colons in key (e.g. "store:namespace:var")
       const tabId = qualifiedKey.slice(0, colonIdx);
       const key = qualifiedKey.slice(colonIdx + 1);

       if (
         !tabId ||
         !key ||
         isDangerousKey(tabId) ||
         isDangerousKey(key) ||
         key.split('.').some((seg) => isDangerousKey(seg))
       ) {
         safeLog(options?.logger, 'warn', '[applySaveUpdates] Prototype pollution attempt or dangerous key rejected', { qualifiedKey });
         continue;
       }
       ```
       Routes variable values into variable arrays/tables and switch values into switch arrays/tables, preventing cross-tab corruption between identical numerical indices.
     - **Type Coercion & Integer Bounds Clamping**: Coerces and clamps update values to engine-safe boundaries before invoking binary serializers:
       - Preserves string keys at top-level ingress without global numeric coercion or integer bounds checks; enforces only delimiter presence (`tabId:key`) and prototype pollution filtering (`isDangerousKey`).
       - Indexed binary codecs (e.g. `wolf-sav`, `wolf`):
         - Explicitly guards `if (tabId !== 'variables')` skipping non-variable tabs with warning telemetry before evaluating keys.
         - Implements dual key routing matching system variables (`sys_<N>`) and numeric matrix indices (`<N>`), mutating the single flat dictionary `wolfData.variables` (`Record<string, number>`):
           ```typescript
           if (tabId !== 'variables') {
             safeLog(options?.logger, 'warn', '[applySaveUpdates:wolf] Skipping non-variable tab for Wolf RPG save', { qualifiedKey });
             continue;
           }

           const sysMatch = /^sys_(\d+)$/.exec(key);
           const numMatch = /^\d+$/.test(key);

           if (!sysMatch && !numMatch) {
             safeLog(options?.logger, 'warn', '[applySaveUpdates:wolf] Skipping non-variable key for Wolf RPG save', { qualifiedKey });
             continue;
           }

           const clampedVal = Math.max(-2147483648, Math.min(2147483647, Math.trunc(Number(val) || 0)));

           if (sysMatch) {
             const sysIndex = Number.parseInt(sysMatch[1], 10);
             const maxSysVars = typeof wolfData._sysVarCount === 'number' && wolfData._sysVarCount > 0 ? wolfData._sysVarCount : 5000;
             if (sysIndex >= maxSysVars) {
               safeLog(options?.logger, 'warn', '[applySaveUpdates:wolf] Out-of-bounds sys variable index', { sysIndex, max: maxSysVars });
               continue;
             }
             wolfData.variables[key] = clampedVal;
           } else {
             const numericIndex = Number.parseInt(key, 10);
             const maxNumVars = typeof wolfData._numTables === 'number' && wolfData._numTables > 0
               ? wolfData._numTables * 100
               : (typeof wolfData._sysVarCount === 'number' && wolfData._sysVarCount > 0 ? wolfData._sysVarCount : 5000);
             if (numericIndex >= maxNumVars) {
               safeLog(options?.logger, 'warn', '[applySaveUpdates:wolf] Out-of-bounds numeric variable index', { numericIndex, max: maxNumVars });
               continue;
             }
             wolfData.variables[key] = clampedVal;
           }
           ```
       - Formats supporting floating-point scalars, strings, and large numbers (`rpg-maker-mv`, `rpg-maker-mz`, `renpy`, `pure-json`, `keyed-json`, `tinc`): retains string keys intact and preserves finite floating-point scalars (`typeof val === 'number' && Number.isFinite(val)`), large integers up to $2^{53}-1$, and string variables (`typeof val === 'string'`) without truncation or clamping.
       - Switch fields across all formats: coerces values via `Boolean(val)`.
       - Null / uninitialized / non-finite normalization: coerces non-finite numbers (`typeof val === 'number' && !Number.isFinite(val)`), `null`, or `undefined` update values to default scalars (`0` for `type: 'number'`, `false` for `type: 'boolean'`, `""` for `type: 'string'`).
       - Prevents low-level binary encoders from throwing `RangeError` / `TypeError` buffer exceptions on edge-case inputs while preserving floating-point fidelity and string variables for non-integer formats.
     - Decodes the complete game data structure from `rawBuffer`.
     - Surgically applies field deltas from `updates` (e.g., updating target indices in `variables._data`, Ren'Py `store` variables via `surgicalEncode`, Wolf RPG variable tables, or TINC fields).
     - Re-encodes the entire updated game state graph back into a valid binary buffer matching the engine format specification.
     - **Zero Data Loss Guarantee**: Non-modified fields (party members, map location, actor equipment, inventory) remain completely preserved. Save codecs and `applySaveUpdates` enforce an explicit 64MB decompressed payload ceiling (`maxDecompressedBytes = 64 * 1024 * 1024`) during decompression to prevent memory exhaustion and zip-bomb denial of service.
     - **Zero Stream Pollution & User Logger Exception Isolation (`OBS-LIBRARY-SDK` & `EDGE-LIBRARY-BOUNDARIES`)**:
       - Codecs and delta applicators in `@yumeshelf/engine` MUST NEVER call `console.log`, `console.warn`, `console.error`, `process.stdout.write`, or `process.stderr.write`.
       - Telemetry and diagnostics are emitted exclusively through `options.logger` wrapped in `safeLog` so external logger errors never abort valid delta application or binary serialization:
         ```typescript
         export function safeLog(
           logger: EngineLogger | undefined,
           level: 'debug' | 'info' | 'warn' | 'error',
           message: string,
           context?: Record<string, unknown>
         ): void {
           try {
             logger?.[level]?.(message, context);
           } catch {
             // Telemetry and external logger failures MUST NEVER abort core business logic
           }
         }
         ```
       - `SaveCodecError` accepts `ErrorOptions` (`{ cause?: unknown }`) to preserve root cause error stacks when rethrowing serialization or compression failures.
