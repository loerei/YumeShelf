## What to build
Implement pure, cross-process headless module `src/shared/path-subsumption.ts` consumed by both Main and Renderer processes with zero `node:path` built-in imports or ambient Node globals. Define explicit cross-process platform input type `type PlatformInput = 'win32' | 'linux' | 'darwin' | 'windows' | 'macos'` accepting both Node platform strings (`'win32' | 'linux' | 'darwin'`) and Engine platform strings (`'windows' | 'linux' | 'macos'`), normalizing them internally to canonical behavior. Implement runtime environment platform fallback:
```typescript
const resolvedPlatform = targetPlatform
  ? normalizePlatformInput(targetPlatform)
  : typeof process !== 'undefined' && process?.platform
    ? normalizePlatformInput(process.platform)
    : typeof navigator !== 'undefined' && navigator.userAgent.includes('Mac')
      ? 'darwin'
      : typeof navigator !== 'undefined' && navigator.userAgent.includes('Linux')
        ? 'linux'
        : 'win32';
```
Implement `normalizePathForPlatform(p: string, targetPlatform?: PlatformInput)`: reject or strip null bytes (`\0`), normalize all directory separators (`\\` and `/`) to canonical forward slashes before segment evaluation, resolve `.` and `..` segments defensively using a tokenized segment stack disallowing any `..` sequence from escaping above the root boundary, strip trailing slashes from all non-root paths (preserving only root drive `C:/` or POSIX `/`), map bare Windows root drive inputs matching `^[A-Za-z]:$` to include a trailing root slash (`C:/`), and apply case-insensitive normalization on Windows and macOS (`win32`, `windows`, `darwin`, `macos`) while preserving case sensitivity on Linux (`linux`). Implement `subsumeLibraryPaths(paths: string[], targetPlatform?: PlatformInput)`: discover topmost ancestor directories while preserving relative order of top ancestors using order-independent topological ancestor filtering. Input paths are first sanitized by filtering out empty, non-string, or whitespace-only elements (and any paths whose canonical representation via `normalizePathForPlatform` evaluates to empty string `""`), and deduplicated by their canonical normalized representation via `normalizePathForPlatform(p, targetPlatform)`. A path `p` in the deduplicated collection is retained if and only if no distinct path `other` subsumes `p` (evaluating `normalizePathForPlatform(p, targetPlatform) !== normalizePathForPlatform(other, targetPlatform) && isSubsumedBy(p, other, targetPlatform)`), preventing identical canonical paths with case or slash variations from mutually eliminating each other, and ensuring inverted input orderings (e.g. `['D:/Games/VN', 'D:/Games']`) strictly resolve to topmost ancestors (`['D:/Games']`). Implement `isSubsumedBy(childPath: string, parentPath: string, targetPlatform?: PlatformInput)` passing both `childPath` and `parentPath` through `normalizePathForPlatform`, returning strictly `false` if either normalized input is empty (`!normalizedChild || !normalizedParent`), and enforcing containment strictly at path segment boundaries (rejecting partial directory prefix matches like `/Games` matching `/Games2`). Implement pure-string helper `getFolderBaseName(folderPath: string): string` extracting leaf folder names without Node `path.basename`. Implement `reorderLibraryPathsWithSubsumption(allConfiguredPaths: string[], reorderedRootPaths: string[], targetPlatform?: PlatformInput): string[]` clustering subsumed child paths immediately beneath parent roots: strictly matches each root in `reorderedRootPaths` against `allConfiguredPaths` (via `normalizePathForPlatform`), emitting the authentic configured path string from `allConfiguredPaths` and ignoring any root that does not match any entry in `allConfiguredPaths`, while maintaining a `seen` set tracking canonical paths normalized via `normalizePathForPlatform(p, targetPlatform)`, and appending any remaining configured paths from `allConfiguredPaths` whose normalized representations are not present in `seen` to the end to guarantee a bijective permutation with zero data loss. Provide comprehensive Vitest unit tests in `src/shared/path-subsumption.test.ts`.

### [NEW] [`src/shared/path-subsumption.ts`](file:///d:/Projects/YumeShelf/src/shared/path-subsumption.ts)
- Pure, cross-process headless module:
  - **Pure String Path Invariant & Decoupled Platform Type**:
    ```typescript
    export type PlatformInput = 'win32' | 'linux' | 'darwin' | 'windows' | 'macos';

    export function normalizePlatformInput(platform: PlatformInput): 'win32' | 'linux' | 'darwin' {
      if (platform === 'windows') return 'win32';
      if (platform === 'macos') return 'darwin';
      return platform;
    }
    ```
  - **Runtime Environment Platform Fallback**:
    ```typescript
    export function resolvePlatform(targetPlatform?: PlatformInput): 'win32' | 'linux' | 'darwin' {
      if (targetPlatform) return normalizePlatformInput(targetPlatform);
      if (typeof process !== 'undefined' && process?.platform) {
        return normalizePlatformInput(process.platform as PlatformInput);
      }
      if (typeof navigator !== 'undefined') {
        if (navigator.userAgent.includes('Mac')) return 'darwin';
        if (navigator.userAgent.includes('Linux')) return 'linux';
      }
      return 'win32';
    }
    ```
  - `normalizePathForPlatform(p: string, targetPlatform?: PlatformInput): string`:
    - Trims leading and trailing whitespace (`p.trim()`) before separator normalization and segment stack evaluation, returning strictly an empty string `""` if the input is empty or whitespace-only.
    - Strips or rejects null bytes (`\0`).
    - Converts all backslashes (`\\`) to canonical forward slashes (`/`).
    - Removes duplicate slashes while preserving root drive or leading slash (e.g. `C:/` or `/`).
    - Resolves relative segments (`.` and `..`) using an array stack; prevents `..` from escaping the root boundary.
    - Strips trailing slashes from all non-root paths (preserving only root drive `C:/` or POSIX `/`), mapping bare Windows drive roots matching `^[A-Za-z]:$` to include a trailing root slash (e.g. `C:` -> `C:/`).
    - Applies lowercase normalization on Windows (`win32`, `windows`) and macOS (`darwin`, `macos`); preserves case on Linux (`linux`).
  - `subsumeLibraryPaths(paths: string[], targetPlatform?: PlatformInput): string[]`:
    - First sanitizes input `paths` by filtering out empty, non-string, or whitespace-only elements (and any paths whose canonical normalized representation via `normalizePathForPlatform` evaluates to `""`), and deduplicates by canonical normalized form via `normalizePathForPlatform(p, targetPlatform)`.
    - Filters deduplicated paths using order-independent topological ancestor filtering: retains path `p` if and only if no distinct path `other` subsumes `p` (`normalizePathForPlatform(p, targetPlatform) !== normalizePathForPlatform(other, targetPlatform) && isSubsumedBy(p, other, targetPlatform)`).
    - Preserves relative order of top ancestors while absorbing child paths regardless of whether child paths precede or follow ancestor paths in the input array.
  - `isSubsumedBy(childPath: string, parentPath: string, targetPlatform?: PlatformInput): boolean`:
    - Normalizes both `childPath` and `parentPath` via `normalizePathForPlatform(..., targetPlatform)`.
    - Returns strictly `false` if `!normalizedChild || !normalizedParent` (including empty strings produced from whitespace-only inputs) to prevent empty parent traversal bypasses.
    - Strips trailing slashes from non-root paths while preserving root drive or root slashes (`C:/`, `/`).
    - Evaluates boundary segment delimiter matching by checking if `normalizedParent` ends with `/` before appending a delimiter:
      ```typescript
      const prefix = normalizedParent.endsWith('/') ? normalizedParent : normalizedParent + '/';
      return normalizedChild === normalizedParent || normalizedChild.startsWith(prefix);
      ```
    - Prevents partial prefix matches (`/Games` matching `/Games2`) and correctly authorizes children under root drives (`C:/Games` under `C:/`) and trailing-slash paths (`D:/Games/Sub` under `D:/Games/`). While `isSubsumedBy` mathematically evaluates containment beneath root drives, configuration of root boundaries as library paths is strictly rejected at the configuration ingress boundary in `addLibraryPath` and `setupLibrary` (Ticket 01.4.1.2.2) to protect against systemic scanner exhaustion.
  - `getFolderBaseName(folderPath: string): string`:
    - Pure string leaf extraction handling both `/` and `\\` separators without importing Node `path`.
    - Strips trailing slashes from non-root paths before segment extraction, handles root drive boundaries cleanly (returning `C:` for `C:/` and `/` for `/`), and provides a safe non-empty fallback for empty or whitespace-only inputs.
  - `reorderLibraryPathsWithSubsumption(allConfiguredPaths: string[], reorderedRootPaths: string[], targetPlatform?: PlatformInput): string[]`:
    - Maps `reorderedRootPaths` against `allConfiguredPaths`, clustering subsumed child paths immediately beneath their respective parent root.
    - Tracks emitted paths in `seen: Set<string>` using canonical normalized representations (`normalizePathForPlatform(p, targetPlatform)`).
    - For each `root` in `reorderedRootPaths`:
      1. Checks `if (seen.has(normalizePathForPlatform(root, targetPlatform))) continue;` at the start of iteration, skipping any root path already emitted or subsumed.
      2. Strictly matches `root` against `allConfiguredPaths` via `normalizePathForPlatform(p, targetPlatform) === normalizePathForPlatform(root, targetPlatform)`. If no match exists, skips the root (rejecting alien paths). Otherwise, emits the authentic configured path string from `allConfiguredPaths` and adds it to `seen`.
      3. Sweeps `allConfiguredPaths` not yet in `seen`: for each `candidate` where `isSubsumedBy(candidate, root, targetPlatform)` evaluates to `true`, verifies `!seen.has(normalizePathForPlatform(candidate, targetPlatform))` before pushing `candidate` to `result` and adding it to `seen` (clustering subsumed children immediately beneath their respective parent root without duplicate entries).
    - After processing all roots, sweeps `allConfiguredPaths` and appends any remaining unmentioned or offline paths whose normalized representations are not yet in `seen` to the end of the returned array, guaranteeing a strictly bijective permutation of `allConfiguredPaths` with zero data loss.
  - **Orphaned Folder Alias Lifecycle Invariant**:
    - Folder alias mappings (`config.folderAliases`) operate as persistent bookmarks/tombstones keyed by platform-normalized folder path.
    - Pure domain path subsumption functions (`subsumeLibraryPaths`, `isSubsumedBy`) evaluate path containment independently of alias presence, and alias dictionaries retain entries for disconnected or removed library paths across path mutations to preserve user customizations upon folder re-addition or path migration.
