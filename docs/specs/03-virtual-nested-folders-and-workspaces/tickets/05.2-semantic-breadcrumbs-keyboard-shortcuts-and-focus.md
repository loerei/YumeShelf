## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build

A semantic breadcrumb navigation bar rendered directly below the header when inside a folder, supporting 1-click ancestor navigation, keyboard shortcuts (`Escape`, `Backspace`), and automatic focus restoration to exited folder cards.

## Acceptance criteria

- [ ] Mount breadcrumb items into the pre-mounted `refs.breadcrumbsBar` container (`08.1`), rendering semantic breadcrumb navigation (`<ol><li>...</li></ol>`, marking active crumb with `aria-current="page"`) directly below the header bar ONLY when `activeWorkspaceMode === 'library'` AND `currentPath.length > 0`. Ensure breadcrumb item labels are set via `textContent` or HTML entity escaping to prevent XSS injection. When switching to "Favorite Desk", hide the breadcrumb bar container (`display: none`), preserving `currentPath` in memory.
- [ ] Clicking any ancestor item in the breadcrumb bar immediately navigates the grid in-place to that ancestor level.
- [ ] Pressing `Escape` or `Backspace` while inside a folder navigates up one level in the hierarchy (`pop()` active path).
- [ ] Implement keyboard focus restoration: upon drilling up via breadcrumb click or keyboard shortcut, automatically focus the exited folder card element in the parent grid.
- [ ] Implement `createFolderNavigationController` accepting optional parameter seam `target?: EventTarget` (defaulting to `document`) for keydown listener binding, exposing `dispose(): void` to clean up global keyboard listeners (`Escape`, `Backspace`), click handlers, and DOM observers.
- [ ] Hide the breadcrumb bar completely when at `root` level (`currentPath.length === 0`).
- [ ] Unit and component tests in `src/renderer/controllers/folder-navigation.test.ts` verifying semantic breadcrumb accessibility markup, HTML entity escaping, click navigation, keyboard shortcut handling, focus restoration to parent cards, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated navigation tests via `npm run test:vitest -- src/renderer/controllers/folder-navigation.test.ts` with standard output containing `'✓ renderer/controllers/folder-navigation.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
