# 08.1 — DOM Dual-Container Shell Isolation

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Restructure the main DOM hierarchy in `src/index.html` and `src/renderer/bootstrap/dom-refs.ts` to establish isolated dual containers: wrap the existing flat dual-grid containers (`#fav-grid`, `#favorites-separator`, `#unfav-grid`) inside `#legacy-grid-container`, and introduce an empty `#virtual-folder-container` placeholder. Ensure legacy grid styles and rendering continue to function with 100% backward compatibility.

## Acceptance criteria
- [ ] In `src/index.html`, wrap `#fav-grid`, `#favorites-separator`, and `#unfav-grid` within `<div id="legacy-grid-container"></div>`.
- [ ] In `src/index.html`, add `<div id="virtual-folder-container" style="display: none;"></div>` alongside the legacy container.
- [ ] In `src/index.html`, mount `<button class="header-icon-btn workspace-mode-toggle-btn" id="workspace-mode-toggle-btn" style="display: none;" type="button" aria-label="Toggle Workspace Mode"></button>` inside `.controls` adjacent to `#sort-btn`.
- [ ] In `src/index.html`, mount `<nav id="breadcrumbs-bar" class="breadcrumbs-bar" style="display: none;" aria-label="Breadcrumb"></nav>` directly between the header and `#game-grid-wrapper`.
- [ ] In `src/renderer/bootstrap/dom-refs.ts`, register DOM element references for `legacyGridContainer`, `virtualFolderContainer`, `workspaceToggleBtn` (`documentRef.getElementById('workspace-mode-toggle-btn')`), and `breadcrumbsBar` (`documentRef.getElementById('breadcrumbs-bar')`) in `RendererRefs`.
- [ ] Author automated unit test in `src/renderer/bootstrap/dom-shell-isolation.test.ts` verifying that `src/index.html` contains `#legacy-grid-container`, `#virtual-folder-container`, `#workspace-mode-toggle-btn`, and `#breadcrumbs-bar`, and that `dom-refs.ts` correctly binds all references.
- [ ] Execute automated DOM shell tests via `npm run test:vitest -- src/renderer/bootstrap/dom-shell-isolation.test.ts` with standard output containing `'✓ renderer/bootstrap/dom-shell-isolation.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
