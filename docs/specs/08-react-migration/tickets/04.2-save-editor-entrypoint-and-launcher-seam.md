Augment `Window` with `declare global { interface Window { __IS_STANDALONE_SAVE_EDITOR__?: boolean; } }` and set `window.__IS_STANDALONE_SAVE_EDITOR__ = true;` before dynamically loading the controller using top-level `await import()` to guarantee window flags execute before the module graph evaluates, preventing recursive window launcher loops. Export `StandaloneMountOptions` and `mountStandaloneSaveEditor` as a testable seam, routing caught rejection diagnostics and DOM fallback text through `sanitizeUserPaths`. During Phase 1 coexistence, extract and sanitize `gameKey` from URL search parameters, directly instantiate `SaveEditorViewController`, and mount into `#save-editor-root`:
     ```typescript
     import { registerGlobalErrorSanitizer, sanitizeUserPaths } from './shared/path-sanitizer';

     declare global {
       interface Window {
         __IS_STANDALONE_SAVE_EDITOR__?: boolean;
       }
     }

     export interface StandaloneMountOptions {
       controllerFactory?: () => {
         open: (gameKey: string, options: { isStandaloneWindow: boolean }) => Promise<unknown>;
         destroy: () => void;
       };
     }

     export async function mountStandaloneSaveEditor(
       root: HTMLElement | null = document.getElementById('save-editor-root'),
       search: string = window.location.search,
       options: StandaloneMountOptions = {}
     ): Promise<() => void> {
       window.__IS_STANDALONE_SAVE_EDITOR__ = true;
       const unbindSanitizer = registerGlobalErrorSanitizer(window, '[SaveEditor]');

       const urlParams = new URLSearchParams(search);
       const gameKey = urlParams.get('gameKey')?.trim();

       let controller: ReturnType<NonNullable<StandaloneMountOptions['controllerFactory']>> | null = null;
       let disposed = false;

       const cleanup = () => {
         if (disposed) return;
         disposed = true;
         window.removeEventListener('beforeunload', cleanup);
         unbindSanitizer();
         if (controller) {
           controller.destroy();
           controller = null;
         }
       };

       window.addEventListener('beforeunload', cleanup);

       if (!gameKey) {
         console.error('[SaveEditor] Missing or empty gameKey parameter in standalone window.');
         if (root) {
           const errorDiv = document.createElement('div');
           errorDiv.className = 'save-editor-error';
           errorDiv.textContent = 'Missing required gameKey parameter.';
           root.replaceChildren(errorDiv);
         }
         return cleanup;
       }

       // Top-level await dynamic import ensures window flag is initialized before controller evaluates
       const { SaveEditorViewController } = await import('./renderer/save-editor/view-controller');
       controller = options.controllerFactory ? options.controllerFactory() : new SaveEditorViewController();

       try {
         await controller.open(gameKey, { isStandaloneWindow: true });
       } catch (err: unknown) {
         const rawMessage = err instanceof Error ? err.message : String(err || 'Unknown error');
         const sanitizedMessage = sanitizeUserPaths(rawMessage);
         const sanitizedStack = err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined;

         console.error('[SaveEditor] Failed to mount standalone view controller:', {
           gameKey: sanitizeUserPaths(gameKey),
           error: sanitizedMessage,
           stack: sanitizedStack,
         });
         controller.destroy();
         controller = null;
         if (root) {
           const errorDiv = document.createElement('div');
           errorDiv.className = 'save-editor-error';
           errorDiv.textContent = `Failed to load save editor: ${sanitizedMessage}`;
           root.replaceChildren(errorDiv);
         }
       }

       return cleanup;
     }

     // Auto-bootstrap in browser/standalone window environment (skip under Vitest/test runner)
     if (typeof process === 'undefined' || process.env.NODE_ENV !== 'test') {
       mountStandaloneSaveEditor().catch((err) => {
         console.error('[SaveEditor] Bootstrap failed unexpectedly:', {
           error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
         });
       });
     }
     ```
     (In Ticket 10.1, `save-editor.tsx` is updated to mount `<SaveEditorApp />` within the React root).

3. **Establish `ISaveEditorLauncher` Seam & Coexistence Shim**:
   - Create [`src/renderer/services/save-editor-launcher.ts`](file:///d:/Projects/YumeShelf/src/renderer/services/save-editor-launcher.ts):
     - Define `interface ISaveEditorLauncher`:
       ```typescript
       export interface ISaveEditorLauncher {
         open(gameKey: string, options?: { standalone?: boolean }): Promise<void>;
       }

       export class ElectronSaveEditorLauncher implements ISaveEditorLauncher {
         constructor(
           private readonly api: Pick<ElectronAPI, 'openSaveEditorWindow'> | undefined = typeof window !== 'undefined' ? window.electronAPI : undefined
         ) {}

         async open(gameKey: string, options?: { standalone?: boolean }): Promise<void> {
           if (!this.api?.openSaveEditorWindow) {
             throw new Error('Save editor IPC bridge is unavailable');
           }
           await this.api.openSaveEditorWindow(gameKey);
         }
       }
       ```
     - Provide `ElectronSaveEditorLauncher` implementing `ISaveEditorLauncher` by dispatching IPC `'save-editor:open-window'` with constructor dependency injection.
   - In [`src/renderer/save-editor-ui.ts`](file:///d:/Projects/YumeShelf/src/renderer/save-editor-ui.ts):
     - Encapsulate shim registration inside `export function initSaveEditorUI(launcher: ISaveEditorLauncher = new ElectronSaveEditorLauncher()): void`, eliminating unmanaged module-load side effects and adding dual-factor standalone detection:
       ```typescript
       import { ISaveEditorLauncher, ElectronSaveEditorLauncher } from './services/save-editor-launcher';

       declare global {
         interface Window {
           __IS_STANDALONE_SAVE_EDITOR__?: boolean;
           showSaveEditor?: (gameKey: string) => Promise<void>;
         }
       }

       export function initSaveEditorUI(launcher: ISaveEditorLauncher = new ElectronSaveEditorLauncher()): void {
         const isStandaloneWindow =
           typeof window !== 'undefined' &&
           (window.__IS_STANDALONE_SAVE_EDITOR__ === true ||
            window.location.pathname.includes('save-editor') ||
            window.location.search.includes('gameKey='));

         if (typeof window !== 'undefined' && !isStandaloneWindow) {
           window.showSaveEditor = async (gameKey: string) => {
             await launcher.open(gameKey);
           };
         }
       }
       ```
     - (Note: `window.showSaveEditor`, `initSaveEditorUI()`, and `save-editor-ui.ts` will be permanently decommissioned in Ticket 10.2 when legacy save editor files are removed).
