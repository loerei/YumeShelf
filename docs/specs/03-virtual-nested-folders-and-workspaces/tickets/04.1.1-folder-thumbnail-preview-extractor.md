# 04.1.1 — Headless Folder Thumbnail Preview Extractor

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
A headless utility function in `[NEW] src/renderer/utils/folder-preview.ts` that extracts thumbnail icon references for closed folder preview cards. It accepts `PreviewOptions { maxThumbnails?: number; maxDepth?: number }` as an operational parameter seam, performs a bounded depth-first recursive walk through child nodes, and short-circuits immediately upon collecting 4 valid thumbnail references to eliminate unbounded tree walks during virtualized grid scrolling.

## Acceptance criteria
- [ ] Export `extractFolderPreviewThumbnails(node: VirtualFolderNode, games: Record<string, any> | any[], options?: PreviewOptions): string[]` in `[NEW] src/renderer/utils/folder-preview.ts`. Defensively normalize `games` if an array is passed (`Array.isArray(games) ? Object.fromEntries(games.map(g => [g.gameKey || g.id, g])) : games`).
- [ ] Accept parameter seam `PreviewOptions { maxThumbnails?: number; maxDepth?: number }` defaulting to `maxThumbnails: 4` and `maxDepth: 2`.
- [ ] Short-circuit tree traversal as soon as `maxThumbnails` (4) valid game icon paths are accumulated.
- [ ] Traverse child folder nodes recursively up to `maxDepth` (2) levels deep, preventing unbounded recursion on deeply nested hierarchies.
- [ ] Return an empty array if the folder has zero games or if child games have no icon paths.
- [ ] Author automated unit tests in `src/renderer/utils/folder-preview.test.ts` verifying bounded extraction, short-circuit termination, empty folder handling, and custom options.
- [ ] Execute automated unit tests via `npm run test:vitest -- src/renderer/utils/folder-preview.test.ts` with standard output containing `'✓ renderer/utils/folder-preview.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
