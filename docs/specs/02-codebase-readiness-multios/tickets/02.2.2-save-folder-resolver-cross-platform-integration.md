# 02.2.2 — SaveFolderResolver Cross-Platform Integration ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Integrate macOS save strategies into `SaveFolderResolver` (`src/main/save-folder-resolver/index.ts`), updating `mapEngineType` to support `'unity-appsupport-playerprefs'`, `'rpgmaker-bundle-data'`, `'renpy-appsupport-saves'`, and `'godot-appsupport-user'`. Add diagnostic warning logging (`console.warn('[SAVE-RESOLVER][ERROR]', error)`) capturing the failing `exePath` and error stack in catch blocks before returning graceful fallback responses. Update `tests/save-folder-resolver-cross-platform.test.js` to validate end-to-end save directory resolution for synthetic macOS games across all engine families.

## Explicit Assumptions & Boundaries
- Behavioral expansion ($B$) consuming the environment path provider from `02.1` and headless save resolvers from `02.2.1.2.1` and `02.2.1.2.2`.
- Retains full backward compatibility with Windows and Linux save resolution.
