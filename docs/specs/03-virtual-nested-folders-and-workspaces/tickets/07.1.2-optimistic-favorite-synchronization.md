# 07.1.2 — Global Optimistic Favorite Star Synchronization and Rollback

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Implement global optimistic favorite star state updates (<100ms) across all UI surfaces (card dropdowns, folder views, Favorite Desk), with asynchronous IPC persistence and rollback error handling on failure.

## Acceptance criteria
- [ ] Implement `createFavoriteSyncController` accepting optional parameter seams `toggleFavoriteFn?: (gameKey: string) => Promise<boolean>` and `showToastPillFn?: (message: string) => void` (defaulting to `showToastPill`), with an explicit `dispose(): void` method to remove event listeners and prevent memory/listener leaks across view changes and test cycles.
- [ ] Intercept favorite star clicks across all UI surfaces, applying optimistic UI updates in `<100ms>`. Expose optional parameter seam `toggleFavoriteFn?: (gameKey: string) => Promise<boolean>` for headless testing.
- [ ] Dispatch IPC `electronAPI.toggleFavorite(gameKey)` returning `Promise<boolean>` (`true` if favorited, `false` if un-favorited), symmetrically updating `db.favoriteOrder` via `AtomicWriteCoordinator`. Invalid `gameKey` inputs or unresolvable game records reject with explicit errors (`'invalid-game-key'`, `'game-not-found'`) rather than resolving `false`.
- [ ] In the controller, treat any boolean return value (`typeof res === 'boolean'`) as successful persistence (`true` indicating favorited, `false` indicating un-favorited). If the IPC call rejects or throws an error, immediately roll back optimistic UI state to the previous favorite status and display error toast notification via `(options?.showToastPillFn || showToastPill)('Failed to update favorite status')`.
- [ ] Author automated unit tests in `src/renderer/state/favorite-sync.test.ts` verifying optimistic update on both favorite (`true`) and un-favorite (`false`), rollback on rejection/failure, toast display, `toggleFavoriteFn` seam injection, and lifecycle teardown via `afterEach(() => controller.dispose())`.
- [ ] Execute automated tests via `npm run test:vitest -- src/renderer/state/favorite-sync.test.ts` with standard output containing `'✓ renderer/state/favorite-sync.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
