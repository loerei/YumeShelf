## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Mount the 1-click header SVG toggle between Favorite Desk and Library mode, persist `activeWorkspaceMode` in `db.config` via IPC, and render Favorite Desk as a flat grid showing only favorited games with independent sort presets and an onboarding empty state.

## Acceptance criteria
- [ ] Mount 1-click SVG toggle icon in the header bar binding to `refs.workspaceToggleBtn` (`08.1`) to switch between Favorite Desk and Library mode, respecting legacy mode visibility toggling (`08.2`).
- [ ] Persist `activeWorkspaceMode: 'favorites' | 'library'` in `db.config` via `electronAPI.updateLibraryConfig`.
- [ ] Render Favorite Desk as a flat grid displaying only games where `favorite === true`, sorted by canonical physical keys in `favoriteOrder` (`primaryInstance?.gameKey || game.gameKey`) when sort preset is `'custom'`.
- [ ] Implement independent sort presets on Favorite Desk without affecting Library folder structures.
- [ ] Synchronize client-side `UiRuntimeState.favoriteOrder` immediately in-memory using canonical physical game keys (appending on favorite, removing on un-favorite) upon optimistic favorite toggles so Favorite Desk updates ordering instantaneously without requiring application reload.
- [ ] Implement `createWorkspaceViewsController` exposing `dispose(): void` to unbind toggle button listeners and clean up workspace observers.
- [ ] Author component unit tests in `src/renderer/controllers/workspace-views.test.ts` verifying workspace mode toggling, independent sorting presets, empty state rendering, in-memory `UiRuntimeState.favoriteOrder` synchronization, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated unit tests via `npm run test:vitest -- src/renderer/controllers/workspace-views.test.ts` with standard output containing `'✓ renderer/controllers/workspace-views.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
