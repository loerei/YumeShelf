Author the centralized drag orchestration layer in `[NEW] src/renderer/controllers/drag-orchestrator.ts` (`createVirtualGridDragCoordinator`) and implement pointer drag start, move, and drop on the virtualized grid container using coordinate-to-item mapping from `04.2` to support baseline 1D reordering. ## Acceptance criteria

- [ ] Author `[NEW] src/renderer/controllers/drag-orchestrator.ts` establishing `createVirtualGridDragCoordinator` to coordinate drag gestures and eliminate multi-controller listener collisions:
  ```typescript
  export interface DragContext {
    sourceKey: string;
    sourceType: 'folder' | 'game';
    pointerId?: number;
    targetElement: HTMLElement | null;
    targetNodeId?: string | null;
    targetFolderId?: string | null;
    targetIndex?: number | null;
    isHoldDwellMet?: boolean;
    activeWorkspaceMode: 'favorites' | 'library';
    currentPath: string[];
  }

  export interface DragIntentHandler {
    intentType: 'breadcrumb-reparent' | 'folder-insert' | 'card-group' | 'reorder';
    priority: number; // 1 = highest, 4 = lowest
    canHandle(event: PointerEvent, context: DragContext): boolean;
    execute(event: PointerEvent, context: DragContext): Promise<boolean>;
  }

  export interface VirtualGridDragCoordinator {
    registerIntentHandler(handler: DragIntentHandler): () => void;
    onDragStart(listener: (context: DragContext) => void): () => void;
    onDragMove(listener: (event: PointerEvent, context: DragContext) => void): () => void;
    onDragEnd(listener: (event?: Event) => void): () => void;
    attach(container: HTMLElement, auxiliaryDropZones?: HTMLElement[]): void;
    dispose(): void;
  }
  ```
  In Ticket `06.1.1`, the coordinator registers only its own baseline `reorder` handler (Priority 4) and binds pointer lifecycle listeners (`pointerdown`, `pointermove`, `pointerup`, `pointercancel`) to `#virtual-folder-container` and auxiliary drop zones (`#breadcrumbs-bar` from `refs.breadcrumbsBar`). In `createVirtualGridDragCoordinator.onDragStart`, capture `event.pointerId` and populate `context.pointerId = event.pointerId` to facilitate pointer capture coordination across DOM redraws. The coordinator subscribes to `state.onCurrentPathChange((nextPath) => { if (this.activeDragContext) { this.activeDragContext.currentPath = nextPath; } })` so that `context.currentPath` stays synchronized during composite drag navigation gestures. Explicitly prohibit applying native HTML5 `draggable="true"` attributes to virtualized grid cards in `folder-card.ts` and `folder-grid-view.ts`, as native HTML5 drag suppresses browser Pointer Events and breaks `setPointerCapture`. On drop, registered intent handlers are evaluated ascending by priority (1 to 4); only the winning handler executes.
