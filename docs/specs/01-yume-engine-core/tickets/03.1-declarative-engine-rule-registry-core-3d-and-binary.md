# 03.1 — Declarative Engine Rule Registry (Core 3D & Binary Engines)

## Epic
PRD 01: YumeEngine Core Architecture & Headless Extraction

## What to build
Create `EngineRuleRegistry` core infrastructure with scan context indexing and declarative classification rules for major 3D and binary VM engines (Unity, Unreal Engine, Godot, Flash, Java).

## Attribution Requirement
- Include MIT attribution header for `horsicq (Detect-It-Easy / XPEViewer)`.

## Blocked by
- 02 — PE Version Info Resource Tree Parser

## Status
ready-for-agent

## Acceptance criteria
- [x] Create `EngineRuleRegistry` skeleton, classification interfaces, and pre-compute an extension index `Set<string>` and normalized filename `Set<string>` once per candidate scan context in `EngineRuleRegistry.resolve()` to eliminate temporary array allocations and linear searches across rule evaluations.
- [x] Implement declarative rules for major binary 3D engines:
  1. **Unity:** IL2CPP (`GameAssembly.dll` / `global-metadata.dat` magic `0xFAB11BAF`) vs Mono (`UnityPlayer.dll` / `mono-2.0-bdwgc.dll`), architecture x86 vs x64.
  2. **Unreal Engine:** `Engine/Binaries/`, `*.uproject`, UE PAK magic (`0x5A6F12E1` / `0x9E2A83C1`).
  3. **Godot:** Embedded / Standalone `.pck` magic `GDPC` (`0x43504447`) / `project.godot`.
- [x] Implement declarative rules for VM & Container engines:
  4. **Flash / Adobe AIR:** `*.swf` (`FWS`/`CWS`/`ZWS`) / `Adobe AIR/` / `FlashPlayer.exe`.
  5. **Java:** `*.jar` / `javaw.exe` / `jvm.dll`.
- [x] Expose public `registerRule(rule: EngineClassificationRule): void` method on `EngineRuleRegistry` for dynamic/plugin engine tag registration.
- [x] Comprehensive unit tests verifying binary 3D and VM engine tag rules using synthetic mock PE inspectors.
- [x] Execute automated unit tests via `pnpm --filter @yumeshelf/engine test -- tests/engine-rules-3d.test.ts`.
