## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
A global search query engine in `[NEW] src/renderer/search/global-search.ts` operating across all nested virtual folders in the library (preserving legacy `src/renderer/search.ts` for Legacy Mode), featuring regex query sanitization, parent ancestry path badges, dedicated zero-match empty state banner, and drill-down location restoration upon clearing search.

## Acceptance criteria
- [ ] Implement search input query engine in `[NEW] src/renderer/search/global-search.ts` operating globally across all games in the library regardless of current folder depth, leaving legacy `src/renderer/search.ts` intact for Legacy Mode.
- [ ] Sanitize search queries and match highlighting by escaping regex metacharacters (`query.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) or utilizing case-insensitive substring searching (`String.prototype.includes` / `indexOf`) and safe string splitting to prevent unhandled `SyntaxError` crashes when queries contain regex special characters. Construct match highlighting DOM nodes safely using `document.createElement('mark')` and `document.createTextNode()`, or pass all non-matching string segments through `escapeHtml(...)` before template assembly to prevent DOM-based XSS.
- [ ] Display parent ancestry path badges on search result cards (e.g. `In: Visual Novels / Key`) indicating the containing virtual folder path, escaping folder names via `textContent` or HTML entity encoding to prevent XSS injection.
- [ ] Render a dedicated empty state banner when 0 results match ("No games found matching '{query}'. Press Escape to clear search"), setting the query string via `textContent` or HTML entity encoding to prevent reflected XSS.
- [ ] Implement `createGlobalSearchController` accepting optional parameter seams `clock?: IClock` and `debounceMs?: number` (default: 150ms, 0 in test harnesses) for deterministic testing, and exposing `dispose(): void` to unbind search input listeners and clear active debounce timers.
- [ ] Clearing search (via Escape key or clear button) restores the user's active workspace view mode and previous folder drill-down location.
- [ ] Unit and component tests in `src/renderer/search/global-search.test.ts` verifying search query regex sanitization, match highlighting safe DOM/HTML entity escaping, zero-result banner rendering, ancestry path badge formatting, drill-down location restoration, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated search ancestry tests via `npm run test:vitest -- src/renderer/search/global-search.test.ts` with standard output containing `'✓ renderer/search/global-search.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
