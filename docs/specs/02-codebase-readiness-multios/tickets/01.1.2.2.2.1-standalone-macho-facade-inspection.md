# 01.1.2.2.2.1 — Standalone Mach-O Binary Facade Inspection in YumeEngine ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Wire standalone Mach-O binary inspection into `YumeEngine.inspectExecutable(targetPath: string, fs?: IFileSystem)` when initial header bytes match Mach-O magic (`0xFEEDFACE`, `0xFEEDFACF`, `0xCEFAEDFE`, `0xCFFAEDFE`, `0xCAFEBABE`, `0xBEBAFECA`, `0xCAFEBABF`, `0xBFBAFECA`). Dispatch to `MachOInspector.fromPath` and return a valid `GameEngineProfile` with `family: 'native'`, `tag: 'Others'`, `runtime: 'native'`, `variant: 'standard'`, `arch: macho.arch`, `saveStrategy: 'unknown'`, and `detectedBy: 'Mach-O Binary'`. Guard against null inspection results on truncated or unreadable binaries by safely constructing a fallback profile.

## Explicit Assumptions & Boundaries
- Behavioral expansion ($B$) enabling standalone Darwin binary profiling.
- Bundle-level classification is handled downstream in `01.1.2.2.2.2`.

## Blocked by
- 01.1.1.2 — Bounded Mach-O Slice Reader & Facade in YumeEngine ($S$)

completed
