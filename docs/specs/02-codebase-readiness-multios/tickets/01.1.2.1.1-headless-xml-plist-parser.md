# 01.1.2.1.1 — Headless XML Info.plist Parser in YumeEngine ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement an in-memory XML property list parser (`packages/yume-engine/src/bundle/xml-plist-parser.ts`) in `@yumeshelf/engine` supporting Apple's standard plist DTD (dictionaries, arrays, strings, integers, reals, booleans, dates, and base64 data) with UTF-8 BOM stripping (`\uFEFF`), robust defense against XML External Entity (XXE) attacks, entity expansion Denial of Service, buffer exhaustion (5 MB limit), comments/CDATA parsing, and prototype pollution. Adhere strictly to the headless architecture required by `AGENTS.md`.

## Explicit Assumptions & Boundaries
- Pure structural refactoring ($S$) introducing XML plist parsing logic.
- Implemented in `@yumeshelf/engine` without Electron or DOM parser dependencies.

## Blocked by
None — can start immediately.

## Status
complete

## Acceptance criteria
- [x] Create `packages/yume-engine/src/bundle/xml-plist-parser.ts` exporting `parseXmlPlist(xmlString: string): any`.
- [x] Strip leading UTF-8 Byte Order Marks (`\uFEFF`) before token stream processing.
- [x] Support plist tags: `<plist>`, `<dict>`, `<key>`, `<array>`, `<string>`, `<integer>`, `<real>`, `<true/>`, `<false/>`, `<date>`, `<data>`.
- [x] Parse nested structures into corresponding JavaScript objects, arrays, and primitive values.
- [x] Prohibit external DTD loading and external entity expansion (`<!ENTITY ...>`), restricting entity decoding strictly to standard predefined XML entities (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`).
- [x] Enforce a maximum input buffer size threshold of 5 MB for `Info.plist` files prior to XML parsing to guard against memory exhaustion DoS.
- [x] Enforce a maximum recursion depth limit of 64 levels and input size validation in `parseXmlPlist` to prevent entity expansion Denial of Service.
- [x] Gracefully handle XML comments (`<!-- ... -->`) and CDATA blocks (`<![CDATA[...]]>`) during plist tokenization.
- [x] Construct `<dict>` objects using `Object.create(null)` or sanitize/strip unsafe prototype keys (`__proto__`, `constructor`, `prototype`) to prevent prototype pollution.
- [x] Handle self-closing tags safely.
- [x] Add unit tests in `packages/yume-engine/tests/xml-plist-parser.test.ts` validating typical Apple `Info.plist` files, UTF-8 BOM stripping, nested structures, empty dicts/arrays, malformed XML, entity explosion payloads, XML comments/CDATA, 5 MB buffer limit, and prototype key stripping.
- [x] Execute automated tests via `pnpm --filter @yumeshelf/engine test` (or `node --experimental-strip-types --test packages/yume-engine/tests/xml-plist-parser.test.ts`).
