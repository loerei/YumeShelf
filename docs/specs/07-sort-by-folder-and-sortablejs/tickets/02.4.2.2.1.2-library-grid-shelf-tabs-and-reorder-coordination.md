## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement shelf tabs lifecycle integration, concurrency re-entrancy locks, section reorder coordinator orchestration, deferred sort queueing, rollback handling, and controller teardown in `src/renderer/library-grid.ts`:
1. Parameter Seams on `createLibraryGridController`:
   - Accept injected `refs.shelfTabsWrapper` (joining `refs.gameGridWrapper` established in `02.4.2.2.1.1`).
   - Accept injected seams: `getCurrentSort?: () => string`, `targetPlatform?: PlatformInput`, `onConfigUpdated?: (config: any) => void`, `shelfTabsOptions?: ShelfTabsControllerOptions` (accepting `sortableFactory?: { create: (element: HTMLElement, options?: any) => any; get?: (element: HTMLElement) => any; }`), `reorderAnimationTiming?: { collapseMs?: number; glideMs?: number; expandMs?: number; watchdogPaddingMs?: number }`, `shelfTabsController?: ShelfTabsController`, and `animateFolderSectionReorder?: typeof animateFolderSectionReorder` (with `getLibraryConfig` provided by prerequisite `02.4.2.2.1.1`). Forward `options.targetPlatform` to `projectLibrarySections` and into `shelfTabsOptions`.
2. Concurrency & Deferred Render Queueing:
   - Maintain in-memory `isReordering: boolean = false` tracking active section transitions. The reordering lock encompasses BOTH UI animation and configuration persistence (`updateLibraryConfig` IPC roundtrip). Guard `renderLibraryGrid` against executing synchronous DOM clearing (`refs.favGrid.innerHTML = ''`, `.library-section` removal) while `isReordering === true` to prevent animation crash, race conditions, and DOM thrashing. Accordion section toggle triggers, `.folder-accordion-toolbar` action buttons (Expand All, Collapse All), and shelf tabs keyboard navigation must check `isReordering` (`if (options.isReordering?.() || isReordering) return;`) and temporarily block interactions (`pointer-events: none` and `aria-disabled="true"`) throughout the in-flight reordering lifecycle, preventing container dimension mutations and layout distortion mid-glide.
   - Maintain `pendingRenderPass: { type: string } | null` whenever `renderLibraryGrid` is invoked while `isReordering === true`. `pendingRenderPass` must NOT be flushed when UI animation finishes if IPC persistence is still in-flight; it executes strictly after `state.currentLibraryConfig` has received and committed the updated configuration (or on rollback in `onReorderFailed`).
3. Shelf Tabs Lifecycle Management:
   - Active Tab Desynchronization Guard: In `renderLibraryGrid`, if `activeTabId !== 'all' && activeTabId !== 'fav'` and not present in `canonicalRoots` (evaluated via `canonicalRoots = subsumeLibraryPaths(rootPaths, options.targetPlatform)` and normalized comparison `!canonicalRoots.some(r => normalizePathForPlatform(r, options.targetPlatform) === normalizePathForPlatform(activeTabId, options.targetPlatform))`, such as when a child path is subsumed by an ancestor root or removed in Settings), check whether keyboard focus currently resides on or within the unmounted folder tab element; if so, anchor and restore focus to `#shelf-tab-all` before unmounting the tab DOM node. Automatically reset internal `activeTabId = 'all'`, ensuring controller state, shelf tabs active highlights, and grid projection remain synchronized.
   - Instantiate `shelfTabsController` once using `refs.shelfTabsWrapper` (mounted full-width directly beneath `<div class="header">`), forwarding `electronAPI`, `getLibraryConfig`, `onConfigUpdated`, `options.shelfTabsOptions`, and wiring `showToastPill: options.showToastPill`, `i18n: options.i18n`:
      - Maintain `activeGridKeydownHandler: ((e: KeyboardEvent) => void) | null = null;` at controller instance scope to enable symmetrical detachment across sibling lifecycle callbacks and teardown.
      - `onTabReorder: async (oldOrder, newOrder, movedPath) => { isReordering = true; refs.gameGridWrapper.style.pointerEvents = 'none'; refs.gameGridWrapper.setAttribute('aria-busy', 'true'); if (activeGridKeydownHandler) { refs.gameGridWrapper.removeEventListener('keydown', activeGridKeydownHandler, true); } activeGridKeydownHandler = (e: KeyboardEvent) => { if (isReordering) { e.preventDefault(); } }; refs.gameGridWrapper.addEventListener('keydown', activeGridKeydownHandler, true); const animFn = options.animateFolderSectionReorder ?? animateFolderSectionReorder; try { await animFn(oldOrder, newOrder, { container: refs.gameGridWrapper, tabsWrapper: refs.shelfTabsWrapper, activeTabId, isCollapsed: (path: string) => collapsedSections.has(path), movedPath, timing: options.reorderAnimationTiming }); } catch (err) { isReordering = false; refs.gameGridWrapper.style.pointerEvents = ''; refs.gameGridWrapper.removeAttribute('aria-busy'); if (activeGridKeydownHandler) { refs.gameGridWrapper.removeEventListener('keydown', activeGridKeydownHandler, true); activeGridKeydownHandler = null; } console.error('[LIBRARY_GRID] Section reorder animation failed in onTabReorder:', { movedPath, error: err }); throw err; } }`, ensuring focus continuity and anchoring are maintained throughout section collapse, glide, and tab reordering, and guaranteeing interaction lock release on animation rejection.
      - Mascot card drag collision & serialization defense: Configure SortableJS grid instances with `onMove: (evt) => !evt.related.classList.contains('mascot-card')` to prevent dragging cards past or displacing pinned mascot cards. When serializing reordered card keys from container DOM in `onEnd`, query `.game-card[data-game-key]:not(.mascot-card)` and filter out null or empty keys to prevent injecting `undefined` into `customOrder`.
      - `onConfigUpdated: (nextConfig) => { options.onConfigUpdated?.(nextConfig); isReordering = false; refs.gameGridWrapper.style.pointerEvents = ''; refs.gameGridWrapper.removeAttribute('aria-busy'); if (activeGridKeydownHandler) { refs.gameGridWrapper.removeEventListener('keydown', activeGridKeydownHandler, true); activeGridKeydownHandler = null; } if (pendingRenderPass) { const queued = pendingRenderPass; pendingRenderPass = null; renderLibraryGrid(queued.type); } }`
      - `onReorderFailed: (_oldOrder) => { isReordering = false; refs.gameGridWrapper.style.pointerEvents = ''; refs.gameGridWrapper.removeAttribute('aria-busy'); if (activeGridKeydownHandler) { refs.gameGridWrapper.removeEventListener('keydown', activeGridKeydownHandler, true); activeGridKeydownHandler = null; } const nextSort = pendingRenderPass ? pendingRenderPass.type : 'folder'; pendingRenderPass = null; renderLibraryGrid(nextSort); }`, relying on in-place section reconciliation to sequentially re-append and re-sequence `.library-section` DOM containers to match `_oldOrder` after Step 2 physical DOM moves when restoring `'folder'` view.
      - `onTabSelect: (tabId) => { activeTabId = tabId; renderLibraryGrid('folder'); }`
    - Update tabs via `shelfTabsController.updateTabs(allSections, activeTabId, favoritesCount)` during render, passing all canonical folder sections (e.g. projecting full sections via `projectLibrarySections({ ... activeTabId: 'all' }).folderSections` or passing the full canonical sections collection with per-folder game counts) so that the shelf tabs bar always represents the entire configured library inventory and is never filtered or collapsed by `activeTabId`. Automatically switch from `'fav'` to `'all'` when favorites count drops to 0, anchoring and restoring keyboard focus to `#shelf-tab-all` when `#shelf-tab-fav` had focus to prevent focus eviction to `document.body`.
    - Show/hide shelf tabs bar (`refs.shelfTabsWrapper.style.display`) based on sort mode: `(options.getCurrentSort ? options.getCurrentSort() : currentSortType) === 'folder'` (with local fallback caching from `renderLibraryGrid(type)`).
    - Expose public seams on controller return interface: `shelfTabs?: ShelfTabsController`, `isReordering(): boolean`, and `destroy(): void`. `destroy()` MUST invoke `options.bindGrids?.([])` to destroy all active card grid SortableJS instances across `refs.favGrid`, `refs.unfavGrid`, and all dynamic `.library-section .game-grid` containers before teardown, cleanly unmount all dynamic `.library-section` DOM containers from `refs.gameGridWrapper` via `refs.gameGridWrapper.querySelectorAll('.library-section').forEach((el) => el.remove())`, symmetrically detach `activeGridKeydownHandler` if non-null via `if (activeGridKeydownHandler) { refs.gameGridWrapper.removeEventListener('keydown', activeGridKeydownHandler, true); activeGridKeydownHandler = null; }`, reset `isReordering = false;`, clear queued `pendingRenderPass = null;`, and safely delegate to `shelfTabsController?.destroy()` (safeguarded with optional chaining or null check for partial test harnesses where `refs.shelfTabsWrapper` is omitted).
4. App Composition Wiring in `src/renderer/bootstrap/app-composition.ts`:
   - Forward `shelfTabsOptions` and `reorderAnimationTiming` from composition options into `createLibraryGridController`.
5. Headless Safety:
   - Fall back to `queueMicrotask` or `options.scheduleAnimation` when `requestAnimationFrame` is undefined.
   - Guard `localStorage` access behind `typeof localStorage !== 'undefined'` and wrap in `try ... catch` error boundary logging structured diagnostics (`[LIBRARY_GRID] Failed to persist sort preference to localStorage:`) upon storage failure.
   - Guard `window.matchMedia` behind `typeof window !== 'undefined' && typeof window.matchMedia === 'function' ? window.matchMedia('(prefers-reduced-motion: reduce)').matches : false` in `animateReorderedCards`.

Provide comprehensive Vitest unit tests in `src/renderer/library-grid.test.ts`.
