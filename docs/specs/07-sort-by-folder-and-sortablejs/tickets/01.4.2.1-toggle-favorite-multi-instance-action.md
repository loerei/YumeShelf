## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement parameterized `toggleFavorite` across the domain action, library state facade, preload bridge, and IPC controller:
1. Domain Action Signature (`src/main/library-state/actions.ts`):
   ```typescript
   export async function toggleFavorite(
     context: LibraryContextInternal,
     gameKey: string,
     targetFavorite?: boolean
   ): Promise<boolean>
   ```
2. Degraded database pre-condition guard:
   - Verifies `if (context.isDegraded?.() === true)` BOTH as an immediate pre-condition guard at function entry AND immediately following `await context.loadDB()`, throwing `new Error('Database is in degraded state')` before applying in-memory mutations to prevent stale in-memory corruption upon disk failure.
3. Multi-instance and single-instance logical group resolution:
   - Queries and builds logical games via `buildLogicalGames(normalizedGames)` to locate the logical group matching `gameKey` (`record.gameId === gameKey || record.instances.some((inst: any) => inst.gameKey === gameKey)`).
4. Instance key propagation:
   - If `targetGroup` is resolved, determines `nextFavorite = typeof targetFavorite === 'boolean' ? targetFavorite : !targetGroup.favorite` and assigns `games[instance.gameKey].favorite = nextFavorite` across ALL instances in `targetGroup.instances` (for both single and multi-instance groups), preventing phantom records under logical `gameId` keys. Validates all instance keys against prototype pollution and verifies own-property existence before assignment:
     ```typescript
     targetGroup.instances.forEach((instance: any) => {
       const instKey = instance?.gameKey;
       const isUnsafe = typeof instKey !== 'string' ||
         instKey === '__proto__' ||
         instKey === 'constructor' ||
         instKey === 'prototype';
       if (!isUnsafe && Object.prototype.hasOwnProperty.call(games, instKey) && games[instKey]) {
         games[instKey].favorite = nextFavorite;
       }
     });
     ```
   - If `targetGroup` is not found, guards the direct key fallback against prototype pollution and missing keys:
     ```typescript
     const isUnsafeKey = typeof gameKey !== 'string' ||
       gameKey === '__proto__' ||
       gameKey === 'constructor' ||
       gameKey === 'prototype';

     if (!isUnsafeKey && Object.prototype.hasOwnProperty.call(games, gameKey) && games[gameKey]) {
       games[gameKey].favorite = typeof targetFavorite === 'boolean' ? targetFavorite : !games[gameKey].favorite;
     } else {
       throw new Error(`Game not found: ${gameKey}`);
     }
     ```
5. Database persistence:
   - Triggers atomic persistence via `await (context.persistDbDirectly || context.saveDB)(db)` and returns the resolved boolean `nextFavorite`. Catch operational failures (degraded state or persistence errors), emit structured diagnostic error log:
     ```typescript
     console.error('[LIBRARY_STATE][TOGGLE_FAVORITE] Failed to persist favorite toggle:', {
       gameKey,
       targetFavorite,
       error: err
     });
     ```
     and re-throw the error across the IPC bridge to ensure caller transactional rollback triggers deterministically.
6. Library State Facade Binding (`src/main/library-state/index.ts`):
   - Bind `toggleFavorite` on `createLibraryState`:
     ```typescript
     toggleFavorite: (gameKey: string, targetFavorite?: boolean) =>
       serializedQueue(() => toggleFavorite(context, gameKey, targetFavorite)),
     ```
6. Shared IPC Contract & Preload Bridge:
   - Update `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     toggleFavorite(gameKey: string, targetFavorite?: boolean): Promise<boolean>;
     ```
   - Update `src/preload.ts`:
     ```typescript
     toggleFavorite: (gameKey: string, targetFavorite?: boolean) =>
       ipcRenderer.invoke('toggle-favorite', gameKey, targetFavorite),
     ```
7. Main IPC Controller Registration (`src/main/ipc/controllers/library.controller.ts`):
   - Update `toggle-favorite` handler to accept and forward `targetFavorite`:
     ```typescript
     ipcMain.handle('toggle-favorite', async (_event, gameKey, targetFavorite) => {
       return libraryState.toggleFavorite(gameKey, targetFavorite);
     });
     ```

Author Vitest unit tests in `src/main/library-state/actions.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
