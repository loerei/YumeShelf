## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build

A spring-loaded hover navigation state machine allowing continuous drag across deep hierarchies: hovering over a closed folder card for 2000ms automatically drills down into it, and hovering over a breadcrumb link for 2000ms drills up, preserving active pointer capture and drag session.

## Acceptance criteria

- [ ] Consume gesture timing adapter (`02`) in `src/renderer/utils/gesture-timer.ts`, accepting optional parameter seams `dragGestureOptions?: DragGestureOptions` and `clock?: IClock` to manage 2000ms hover dwell timers (`dwellDelayMs`) with deterministic time simulation.
- [ ] Hovering a dragged card over a closed folder card for >= 2000ms renders an immediate visual highlight (<100ms) and an animated radial/circular progress indicator over the 2000ms duration, then triggers an in-place grid drill-down into that folder while preserving the ongoing drag session.
- [ ] Hovering a dragged card over a parent link in the breadcrumb bar for >= 2000ms renders an animated progress indicator, then triggers an in-place drill-up to that ancestor level while preserving the active drag session.
- [ ] Cancel dwell timers immediately on pointer leave, target switch (`onTargetChange`), or pointer velocity exceeding 500px/s.
- [ ] Implement `createDragSpringNavigationController` exposing `dispose(): void` to clear pending dwell timers and active animation frames. Resolve animation frame providers via:
  ```typescript
  const rAF = clock?.requestAnimationFrame
    ? ((cb: (timestamp: number) => void) => clock.requestAnimationFrame!(cb))
    : (typeof requestAnimationFrame === 'function'
      ? requestAnimationFrame
      : ((cb: (timestamp: number) => void) => (clock ? clock.setTimeout(() => cb(clock.now()), 16) : (setTimeout(() => cb(Date.now()), 16) as unknown as number))));
  const cAF = clock?.cancelAnimationFrame
    ? ((id: number) => clock.cancelAnimationFrame!(id))
    : (typeof cancelAnimationFrame === 'function'
      ? cancelAnimationFrame
      : ((id: number) => (clock ? clock.clearTimeout(id) : clearTimeout(id as unknown as ReturnType<typeof setTimeout>))));
  ```
- [ ] Preserve active HTML5 pointer capture and drag ghost rendering seamlessly across grid DOM rebuilds during drill-down / drill-up transitions by binding `setPointerCapture` and drag session listeners to the persistent outer container element (`#virtual-folder-container` or `window`) rather than the ephemeral dragged card element that gets recycled.
- [ ] Unit and UI interaction tests in `src/renderer/controllers/drag-spring-navigation.test.ts` verifying spring-loaded dwell timers, radial progress animations, target transition cancellations, drag session continuity across in-place transitions, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated spring navigation tests via `npm run test:vitest -- src/renderer/controllers/drag-spring-navigation.test.ts` with standard output containing `'✓ renderer/controllers/drag-spring-navigation.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
