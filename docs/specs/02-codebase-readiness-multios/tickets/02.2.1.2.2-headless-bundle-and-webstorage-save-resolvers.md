# 02.2.1.2.2 — Headless In-Bundle & WebStorage Save Resolvers in YumeEngine ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Update `resolveUnitySave` and `resolveRpgMakerSave` in `packages/yume-engine/src/save-resolvers/engine-save-resolvers.ts` to inspect bundle resources (`Contents/Resources/Data/app.info` and `Contents/Resources/app.nw/package.json`) resolving macOS Unity PlayerPrefs and RPG Maker MV/MZ in-bundle or WebStorage save paths (`~/Library/Application Support/<company>/<product>` and `~/Library/Application Support/app.nw/save/`). Sanitize extracted names, require non-zero length for company, product, and bundle name tokens, and assert directory containment strictly within expected base roots.

## Explicit Assumptions & Boundaries
- Behavioral expansion ($B$) completing macOS save resolution for games with internal metadata configs.
- Consumes headless plist/bundle inspection primitives from `01.1.2.2.1`.

ready-for-agent
