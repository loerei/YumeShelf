   - **Referential Stability & Notification Invariant**: Cache the `currentSnapshot` reference in closure scope. Invalidate and recompute `currentSnapshot` ONLY when a state setter or action mutates values. Every state mutator in `ObservableUiRuntimeStore` (`setAllGames`, `updateGame`, `setGameRunning`, `updateGamePlaytime`, `setCategoryTree`, `setActiveCategoryId`, `setCurrentSort`, `setCurrentLibraryConfig`) MUST explicitly invoke `invalidateSnapshot()` to construct the next immutable snapshot and notify registered listeners. In `setAllGames(games: GameEntry[])`, collect active running game states (`isRunning === true` and `basePlaytime`) from existing `allGames` records prior to replacement and merge them into incoming matching records (both top-level and child instances), preventing active running status from dropping during database reload reconciliation. Maintain an internal `Map<string, number>` (`allGamesIndexMap = new Map<string, number>()`) via `rebuildAllGamesIndexMap(games: GameEntry[])` invoked in `setAllGames` (and any structural mutation of `allGames`). `rebuildAllGamesIndexMap(games)` MUST call `allGamesIndexMap.clear()` first, and MUST guard every key (`game.gameKey`, `game.gameId`, `game.instanceId`, `inst.gameKey`, `inst.gameId`, `inst.instanceId`) with `typeof key === 'string' && key.length > 0` before setting `key` or `'game:' + key` in `allGamesIndexMap` mapped to its `allGames` array index:
     ```typescript
     const allGamesIndexMap = new Map<string, number>();

     function setIndexKey(key: unknown, idx: number): void {
       if (typeof key === 'string' && key.length > 0) {
         allGamesIndexMap.set(key, idx);
       }
     }

     function rebuildAllGamesIndexMap(games: readonly GameEntry[]): void {
       allGamesIndexMap.clear();
       for (let idx = 0; idx < games.length; idx++) {
         const game = games[idx];
         setIndexKey(game.gameKey, idx);
         setIndexKey(game.gameId, idx);
         setIndexKey(game.instanceId, idx);
         if (typeof game.gameKey === 'string' && game.gameKey.length > 0) {
           allGamesIndexMap.set('game:' + game.gameKey, idx);
         }
         if (typeof game.gameId === 'string' && game.gameId.length > 0) {
           allGamesIndexMap.set('game:' + game.gameId, idx);
         }
         if (Array.isArray(game.instances)) {
           for (const inst of game.instances) {
             setIndexKey(inst.gameKey, idx);
             setIndexKey(inst.gameId, idx);
             setIndexKey(inst.instanceId, idx);
           }
         }
       }
     }
     ```
     so `updateGame`, `setGameRunning`, and `updateGamePlaytime` perform $O(1)$ target lookup and targeted shallow array copy (`const nextGames = allGames.slice(); nextGames[idx] = updatedGame`) instead of scanning `allGames` linearly on periodic playtime ticks. `getSnapshot()` returns `currentSnapshot` directly without allocating a new object literal on read, satisfying `Object.is(store.getSnapshot(), store.getSnapshot()) === true` to prevent infinite re-rendering loops in React 19's `useSyncExternalStore`.

   - **Immutable Entity Mutation Seam (`updateGame`)**:
     Implement `updateGame(gameKey, patch)` to guard against non-matching keys (preserving `currentSnapshot` referential identity and suppressing subscriber notifications) and synchronously maintain invariant consistency across top-level `game`, `game.instances`, and `game.primaryInstance`:
     ```typescript
     updateGame(gameKey: string, patch: Partial<GameEntry>): void {
       // Ingress boundary guard: drop falsy, non-string keys or invalid patch objects immediately
       if (!gameKey || typeof gameKey !== 'string' || !patch || typeof patch !== 'object') {
         return;
       }

       const idx = allGamesIndexMap.get(gameKey);
       if (idx === undefined) return;
       const game = allGames[idx];
       if (!game) return;

       const isDomainGroupProperty = 'favorite' in patch;
       const isGroupWideMetadata = 'name' in patch || 'title' in patch;
       const isMultiInstance = Array.isArray(game.instances) && game.instances.length > 1;

       // For multi-instance stacks, top-level group is targeted via gameId or synthetic group key 'game:...'
       // When instances <= 1 (single games), game.gameKey also targets top level.
       const matchesTopLevel =
         (!isMultiInstance && Boolean(game.gameKey) && game.gameKey === gameKey) ||
         (Boolean(game.gameId) && game.gameId === gameKey) ||
         (Boolean(game.gameKey) && 'game:' + game.gameKey === gameKey) ||
         (Boolean(game.gameId) && 'game:' + game.gameId === gameKey);

       const matchesInstance = Array.isArray(game.instances) && game.instances.some(
         (inst) => inst.gameKey === gameKey || inst.gameId === gameKey || inst.instanceId === gameKey
       );

       if (!matchesTopLevel && !matchesInstance) {
         return;
       }

       // Domain Invariant: 'favorite' applies across all instances of a logical group.
       // Instance Metadata: 'name'/'title' only apply to all instances when explicitly targeting top-level group.
       const applyToAllInstances = isDomainGroupProperty || (matchesTopLevel && isGroupWideMetadata);

       const nextInstances = Array.isArray(game.instances)
         ? game.instances.map((inst) =>
             applyToAllInstances || inst.gameKey === gameKey || inst.gameId === gameKey || inst.instanceId === gameKey
               ? { ...inst, ...patch }
               : inst
           )
         : game.instances;

       const nextPrimaryInstance = game.primaryInstance
         ? (applyToAllInstances ||
            (matchesTopLevel && !game.primaryInstance.gameKey) ||
            game.primaryInstance.gameKey === gameKey ||
            game.primaryInstance.gameId === gameKey ||
            game.primaryInstance.instanceId === gameKey
             ? { ...game.primaryInstance, ...patch }
             : game.primaryInstance)
         : game.primaryInstance;

       const nextTopLevel = matchesTopLevel || isDomainGroupProperty
         ? { ...game, ...patch }
         : {
             ...game,
             ...(Array.isArray(nextInstances)
               ? {
                   favorite: nextInstances.some((i) => Boolean(i.favorite)),
                   playtime: nextInstances.reduce((sum, i) => sum + (i.playtime || 0), 0),
                   isRunning: nextInstances.some((i) => Boolean(i.isRunning)),
                   // If primary instance was updated, keep top-level display fields in sync if applicable
                   ...(nextPrimaryInstance && (nextPrimaryInstance.gameKey === gameKey || nextPrimaryInstance.instanceId === gameKey)
                     ? {
                         name: nextPrimaryInstance.name ?? game.name,
                         title: nextPrimaryInstance.title ?? game.title,
                         iconUrl: nextPrimaryInstance.iconUrl ?? game.iconUrl,
                       }
                     : {})
                 }
               : {})
           };

       const updatedGame: GameEntry = {
         ...nextTopLevel,
         instances: nextInstances,
         primaryInstance: nextPrimaryInstance
       };

       const nextGames = allGames.slice();
       nextGames[idx] = updatedGame;
       allGames = nextGames;

       invalidateSnapshot();
     }
     ```

     - Synchronously reconcile matching records and multi-instance parent aggregates via $O(1)$ `allGamesIndexMap.get(gameKey)` lookup, targeted shallow copy `const nextGames = allGames.slice(); nextGames[idx] = updatedGame;`, and `invalidateSnapshot()`:
       ```typescript
       setGameRunning(gameKey: string, isRunning: boolean): void {
         if (!gameKey || typeof gameKey !== 'string') return;

         const idx = allGamesIndexMap.get(gameKey);
         if (idx === undefined) return;
         const game = allGames[idx];
         if (!game) return;

         const isMultiInstance = Array.isArray(game.instances) && game.instances.length > 1;
         const matchesTopLevel = !isMultiInstance && (
           (Boolean(game.gameKey) && game.gameKey === gameKey) ||
           (Boolean(game.gameId) && game.gameId === gameKey) ||
           (Boolean(game.gameKey) && 'game:' + game.gameKey === gameKey) ||
           (Boolean(game.gameId) && 'game:' + game.gameId === gameKey)
         );
         const matchesInstance = Array.isArray(game.instances) && game.instances.some(
           (inst) => inst.gameKey === gameKey || inst.instanceId === gameKey
         );
         if (!matchesTopLevel && !matchesInstance) {
           return;
         }

         const patch = {
           isRunning,
           ...(isRunning ? {} : { basePlaytime: undefined })
         };
         const nextInstances = Array.isArray(game.instances)
           ? game.instances.map((inst) =>
               (!isMultiInstance && matchesTopLevel) ||
               inst.gameKey === gameKey ||
               inst.instanceId === gameKey
                 ? { ...inst, ...patch }
                 : inst
             )
           : game.instances;

         const nextPrimaryInstance = game.primaryInstance
           ? (isMultiInstance
               ? (nextInstances?.find((inst) =>
                   game.primaryInstance ? (inst.gameKey === game.primaryInstance.gameKey || inst.instanceId === game.primaryInstance.instanceId) : false
                 ) ?? game.primaryInstance)
               : (matchesTopLevel ||
                  game.primaryInstance.gameKey === gameKey ||
                  game.primaryInstance.instanceId === gameKey
                   ? { ...game.primaryInstance, ...patch }
                   : game.primaryInstance))
           : game.primaryInstance;

         const anyChildRunning = Array.isArray(nextInstances) && nextInstances.some((i) => Boolean(i.isRunning));
         const aggregateRunning = isMultiInstance ? anyChildRunning : isRunning;

         const nextTopLevel = {
           ...game,
           ...(matchesTopLevel ? patch : {}),
           ...(Array.isArray(nextInstances) ? { isRunning: aggregateRunning } : {}),
           ...(aggregateRunning ? {} : { basePlaytime: undefined })
         };

         const updatedGame: GameEntry = {
           ...nextTopLevel,
           instances: nextInstances,
           primaryInstance: nextPrimaryInstance
         };

         const nextGames = allGames.slice();
         nextGames[idx] = updatedGame;
         allGames = nextGames;
         invalidateSnapshot();
       }
       ```
   - In `updateGamePlaytime(gameKey: string, accruedMs: number)`:
     - Ingress Validation & Non-negative Normalization:
       - If `!gameKey || typeof gameKey !== 'string'`, return early.
       - If `!Number.isFinite(accruedMs) || accruedMs < 0`, return early.
       - Normalize session duration via `const validAccruedMs = Math.max(0, accruedMs);`.
     - Locate target record:
       - For single-instance games (`game.instances.length === 1`), matching against `inst.gameKey === gameKey || inst.gameId === gameKey || inst.instanceId === gameKey` is supported.
       - For multi-instance stacks (`game.instances.length > 1`), child instances must be matched strictly by unique identifiers (`inst.gameKey === gameKey || inst.instanceId === gameKey`). If `gameKey` matches stack-level `game.gameId` or `game.gameKey`, target the primary instance key safely via `const targetPrimaryInstKey = game.primaryInstance?.gameKey ??      - Immutably update matching record using the non-drifting baseline formula:
       ```typescript
       const base = matchingRecord.basePlaytime ?? matchingRecord.playtime ?? 0;
       const updatedPlaytime = base + validAccruedMs;
       ```
       (Note: Do NOT mutate or synthesize `lastPlayed` during periodic playtime ticks; authoritative timestamp reconciliation is deferred to `onGameStopped`).

2. **Isolated Storage Migration Helper (`src/renderer/state/ui-storage-migrations.ts`)**:
   - Define and export `CURRENT_UI_STORAGE_VERSION = 1` and `migrateUiPreferences(storage: UiStorageAdapter, nowProvider: () => number = Date.now): void` utilizing a monotonic version register (`yumeshelf_storage_version`) to sequence local storage schema migrations:
     ```typescript
     import { sanitizeUserPaths } from '../../shared/path-sanitizer';

     export const CURRENT_UI_STORAGE_VERSION = 1;

     export function migrateUiPreferences(
       storage: UiStorageAdapter,
       nowProvider: () => number = Date.now
     ): void {
       try {
         const rawVersion = storage.getItem('yumeshelf_storage_version');
         let version = rawVersion ? parseInt(rawVersion, 10) : 0;
         if (isNaN(version)) version = 0;

         if (version < 1) {
           // 1. Sort preference canonicalization
           const sortPref = storage.getItem('yumeshelf_sort_pref');
           if (sortPref === 'rj') {
             storage.setItem('yumeshelf_sort_pref', 'date');
           } else if (sortPref === 'title') {
             storage.setItem('yumeshelf_sort_pref', 'az');
           } else if (sortPref === 'playtime') {
             storage.setItem('yumeshelf_sort_pref', 'played');
           }

           // 2. Language synonym migration and dirty key pruning
           const rawCanonical = storage.getItem('yumeshelf_lang');
           const trimmedCanonical = rawCanonical?.trim() || '';
           const rawLegacy = storage.getItem('yumeshelf_language');
           const trimmedLegacy = rawLegacy?.trim() || '';

           if (!trimmedCanonical && trimmedLegacy) {
             storage.setItem('yumeshelf_lang', trimmedLegacy);
           } else if (!trimmedCanonical && rawCanonical !== null) {
             storage.removeItem('yumeshelf_lang');
           }
           if (rawLegacy !== null) {
             storage.removeItem('yumeshelf_language');
           }

           // 3. Category ID dirty key pruning
           const activeCat = storage.getItem('yumeshelf_active_category_id');
           if (activeCat !== null && activeCat.trim() === '') {
             storage.removeItem('yumeshelf_active_category_id');
           }

           // 4. Prune orphaned legacy keys authoritatively owned by LibraryDatabase (library.json)
           storage.removeItem('yumeshelf_title_display_mode');
           storage.removeItem('yumeshelf_display_product_codes');
           storage.removeItem('yumeshelf_translation_cache');

           // 5. Migrate yumeshelf_custom_order to versioned envelope
           const rawCustomOrder = storage.getItem('yumeshelf_custom_order');
       if (rawCustomOrder !== null) {
         const purgeCorruptCustomOrder = (raw: string) => {
           try {
             const quarantineKey = `yumeshelf_custom_order_corrupt_${nowProvider()}`;
             storage.setItem(quarantineKey, raw);
             console.warn('[UI-STORAGE-MIGRATIONS] Quarantined corrupted custom order payload to', quarantineKey);
           } catch (quarantineErr) {
             console.warn('[UI-STORAGE-MIGRATIONS] Failed to quarantine corrupt custom order payload (storage quota exceeded):', {
               error: sanitizeUserPaths(quarantineErr instanceof Error ? quarantineErr.message : quarantineErr),
               stack: quarantineErr instanceof Error && quarantineErr.stack ? sanitizeUserPaths(quarantineErr.stack) : undefined,
             });
           } finally {
             storage.removeItem('yumeshelf_custom_order');
           }
         };

         try {
           const parsed = JSON.parse(rawCustomOrder);
           if (Array.isArray(parsed)) {
             // Legacy raw string[]: wrap in versioned envelope
             const sanitized = parsed.filter((id): id is string => typeof id === 'string' && id.trim().length > 0);
             storage.setItem('yumeshelf_custom_order', JSON.stringify({ schemaVersion: 1, order: sanitized }));
           } else if (parsed && typeof parsed === 'object') {
             if (typeof (parsed as any).schemaVersion === 'number' && (parsed as any).schemaVersion >= 1) {
               if ((parsed as any).schemaVersion === 1 && !Array.isArray((parsed as any).order)) {
                 // Malformed v1 payload: quarantine and purge key to prevent render flooding
                 purgeCorruptCustomOrder(rawCustomOrder);
               }
               // Valid v1 or forward schema (schemaVersion > 1): preserve intact
             } else {
               // Non-versioned object: quarantine and purge key
               purgeCorruptCustomOrder(rawCustomOrder);
             }
           } else {
             // Primitive non-array (e.g. number, boolean, null string): quarantine and purge key
             purgeCorruptCustomOrder(rawCustomOrder);
           }
          } catch {
            // SyntaxError on JSON parse: quarantine and purge key immediately to halt storage flooding
            purgeCorruptCustomOrder(rawCustomOrder);
          }
        }
        storage.setItem('yumeshelf_storage_version', String(CURRENT_UI_STORAGE_VERSION));
      }
    } catch (err) {
      console.warn('[UI-STORAGE-MIGRATIONS] Failed to migrate UI preferences from localStorage:', {
        error: sanitizeUserPaths(err instanceof Error ? err.message : err),
        stack: err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined,
      });
    }
  }
     ```
   - Invoked during application startup bootstrap before store instantiation to migrate legacy identifiers with sequential monotonic version tracking.

3. **Headless Store & Migration Unit Tests**:
   - Author tests in `src/renderer/state/ui-runtime-state.test.ts` verifying:
     - Snapshot referential stability is preserved across consecutive `getSnapshot()` calls without state mutations (including no-op `updateGame` calls on non-matching keys).
     - State mutations construct fresh immutable snapshots and notify registered subscribers across every mutator.
     - `updateGame` synchronously updates top-level `game`, `game.instances`, and `game.primaryInstance` (propagating group-wide patches like `favorite`, `name`, and `title` across all instances and recomputing parent aggregates when patching individual instances).
      - Calling `store.updateGame(gameKey, patch)` preserves referential invariance for untouched snapshot fields, and pure projection `selectSearchableGames(store.getSnapshot())` reflects patched metadata without maintaining denormalized state on `UiRuntimeSnapshot`.
     - `updateGamePlaytime` computes `basePlaytime + accruedMs` without runaway drift across successive broadcasts, and synchronously updates top-level `game`, child `instances`, and `primaryInstance` across both single-instance games (`instances.length === 1`) and multi-instance stacks (`instances.length > 1`).
     - `setGameRunning(childKey, true)` on a child instance updates both the matching child instance and parent stack to `isRunning: true`, producing a referentially distinct snapshot (`Object.is(s1, s2) === false`).
