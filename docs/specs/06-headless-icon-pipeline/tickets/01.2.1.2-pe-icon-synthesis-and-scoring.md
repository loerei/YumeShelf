# 01.2.1.2 — PE Frame Scoring & ICO Binary Synthesis ($S$)

## Epic
PRD: Move Headless Icon Extraction to @yumeshelf/engine

## What to build
Implement PE icon extraction, frame resolution scoring, and synthetic Windows `.ico` binary synthesis in `packages/yume-engine/src/pe/resource-decoder.ts`.
1. Implement `GRPICONDIR` directory header decoding capped at `idCount <= 64` frames.
2. Implement frame scoring hierarchy: prefer 256px PNG > 256px DIB > highest resolution frame. Frame scoring formula: `score = width * height * (bitCount >= 24 ? 2 : 1) + (isPng ? 100000 : 0)`.
3. Enforce DIB frame header length validation (`rawFrameBuffer.length >= 40 && biSize >= 40 && rawFrameBuffer.length >= biSize`) before synthesizing `.ico` container, rejecting malformed DIB streams.
4. Implement synthetic 22-byte `.ico` binary assembly prepending a 6-byte `ICONDIR` and 16-byte `ICONDIRENTRY` to the raw DIB bitmap frame buffer.
5. Implement `PeResourceDecoder.prototype.extractIcon(): ExtractedPeIcon | null`.
6. Implement top-level entry points: `extractPeIcon` (strictly synchronous accepting Buffer or file path string) and `extractPeIconAsync` (asynchronous, accepting `options?: PeResourceDecoderOptions | IFileSystem`).
7. Re-export `extractPeIcon` and `extractPeIconAsync` from `packages/yume-engine/src/pe/index.ts`.
8. Add unit tests for icon frame scoring, DIB-to-ICO synthesis, GRPICONDIR frame count capping ($\le 64$), and PNG passthrough in `packages/yume-engine/tests/pe-resource-decoder.test.ts`.

- Frame scoring and selection:
  - Identify PNG magic (`0x89504E470D0A1A0A`).
  - Score frames: `score = width * height * (bitCount >= 24 ? 2 : 1) + (isPng ? 100000 : 0)`.
  - Prefer 256px PNG > 256px DIB > highest resolution frame.
- Frame validation and `.ico` synthesis:
  - In `extractIcon()`: query `this.getResourceDataEntry(RT_GROUP_ICON)` without a name filter to discover the root group icon entry, and slice the descriptor directly from `this.rsrcSection.buffer` via `entry.offset`. Assert `groupData.length >= 6` before reading `idType` (`groupData.readUInt16LE(2)`) and `idCount` (`groupData.readUInt16LE(4)`), returning `null` if truncated or smaller than 6 bytes. Validate `idType === 1 && idCount > 0` (where `idType = 1` specifies icons and `idType = 2` specifies cursors per Windows PE specification), returning `null` for non-icon resource types or zero frames.
  - `GRPICONDIR` header decoding: `idCount` capped at $\le$ `this.options?.maxIconFrames ?? DEFAULT_MAX_GROUP_ICON_FRAMES` (default 64) frames, preventing CPU exhaustion from crafted icon directories.
  - DIB frame check: validate `rawFrameBuffer.length >= 40 && biSize >= 40 && rawFrameBuffer.length >= biSize` (`BITMAPINFOHEADER` bounds) before synthesizing `.ico` header, rejecting malformed DIB streams where `biSize` exceeds available buffer length.
  - For DIB frames, synthesize standard Windows `.ico` file structure: `ICONDIR` (6 bytes) + `ICONDIRENTRY` (16 bytes) + DIB buffer.
  - For PNG frames, return raw PNG buffer directly with `isPng: true` and `mimeType: 'image/png'`.
