# 01.1.2.2.1 — macOS .app Bundle Metadata Inspector & resolveBundleRoot in YumeEngine ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement `AppBundleInspector` in `packages/yume-engine/src/bundle/app-bundle-inspector.ts` that inspects a macOS `.app` bundle directory, parses its `Contents/Info.plist` (using the unified plist parser from `01.1.2.1.2`), sanitizes `CFBundleExecutable` (ensuring `path.basename(CFBundleExecutable) === CFBundleExecutable`, `CFBundleExecutable !== '.' && CFBundleExecutable !== '..'`, and containment within `Contents/MacOS/`), and returns an `AppBundleInspectionResult`. Implement pure path helper `resolveBundleRoot(targetPath: string): string | null` in `app-bundle-inspector.ts` that detects whether a given path is an `.app` bundle folder or points to a nested binary inside an `.app` bundle, normalizing both `/` and `\` cross-platform. Re-export `AppBundleInspector` and `resolveBundleRoot` from `packages/yume-engine/src/index.ts`.

## Explicit Assumptions & Boundaries
- Pure structural refactoring ($S$) adding bundle inspection primitives without changing game engine classification heuristics.
- Engine family classification is implemented downstream in `01.1.2.2.2.2`.
