# 04.1 — macOS Packaging Configuration & Universal CI/CD Pipeline

## Epic
PRD: Implementation for macOS Platform Support (In Progress - Beta Released)

## What was built

Configured Electron packaging in `package.json` for macOS Universal distribution (`dmg` and `zip` targets supporting both Apple Silicon `arm64` and Intel `x64`). Added `ensure:playtime-helper:universal` build script compiling the native Rust playtime helper for both architectures and merging them via `lipo -create`. Added `macos-14` (Apple Silicon M1) to `.github/workflows/test.yml`. Integrated the `build-macos` job into the unified 3-platform release pipeline `.github/workflows/release.yml`, generating `ForMacBeta.txt` and publishing release assets (`.dmg`, `.zip`, `.blockmap`, `.sha256`, `latest-mac.yml`).

## Acceptance criteria

- [x] Configure `mac` and `dmg` configurations in `package.json` with `category: "public.app-category.games"`, `target: ["dmg", "zip"]`, and ICNS/PNG icon paths.
- [x] Add npm script `"build:mac"` and `"package:mac"` to `package.json` with `--universal` parameterization.
- [x] Create `scripts/ensure-playtime-helper-universal.js` to compile `native/playtime-helper` for `aarch64-apple-darwin` and `x86_64-apple-darwin`, merge via `lipo`, and verify architecture validity.
- [x] Add `macos-14` to the test matrix in `.github/workflows/test.yml` to verify cross-platform unit and cargo tests on Apple Silicon runners.
- [x] Add `build-macos` job to `.github/workflows/release.yml` for automated building and publishing of macOS DMG, ZIP, blockmap, and checksum assets upon GitHub release publish.
- [x] Generate standalone `ForMacBeta.txt` instructions in `build_output/mac/` isolated from `.sha256` checksum files.
- [x] Document macOS Beta installation and Gatekeeper quarantine removal (`xattr -cr`) in `README.md` and `CHANGELOG.md`.
