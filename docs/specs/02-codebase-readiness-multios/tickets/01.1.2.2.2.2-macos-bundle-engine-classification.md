- [x] Route detected bundle roots to `AppBundleInspector.fromPath(bundleRoot, fs)`.
- [x] Implement bundle engine classification heuristics matching bundle layout markers:
  - `Contents/Resources/Data/` or `Contents/Frameworks/UnityPlayer.dylib` $\to$ `family: 'unity'`, `tag: 'Unity'`, `variant: 'standard'`, `arch: machoArch || 'unknown'`, `saveStrategy: 'unity-appsupport-playerprefs'`, `runtime: 'native'`, `detectedBy: 'macOS App Bundle (Unity)'`
  - `Contents/Resources/app.nw/` $\to$ `family: 'rpg-maker'`, `tag: 'RPGM'`, `variant: isMZ ? 'mz' : 'mv'`, `arch: machoArch || 'unknown'`, `saveStrategy: 'rpgmaker-bundle-data'`, `runtime: 'nwjs'`, `detectedBy: 'macOS App Bundle (RPG Maker)'`
  - `Contents/Resources/autorun/` or `Contents/MacOS/` containing `.py`/`.pyo` $\to$ `family: 'renpy'`, `tag: "Ren'Py"`, `variant: 'standard'`, `arch: machoArch || 'unknown'`, `saveStrategy: 'renpy-appsupport-saves'`, `runtime: 'python'`, `detectedBy: "macOS App Bundle (Ren'Py)"`
  - `Contents/Resources/*.pck` $\to$ `family: 'godot'`, `tag: 'Godot'`, `variant: 'standard'`, `arch: machoArch || 'unknown'`, `saveStrategy: 'godot-appsupport-user'`, `runtime: 'native'`, `detectedBy: 'macOS App Bundle (Godot)'`
  - Unreal bundle layout $\to$ `family: 'unreal'`, `tag: 'Unreal Engine'`, `variant: 'standard'`, `arch: machoArch || 'unknown'`, `saveStrategy: 'unreal-sav'`, `runtime: 'native'`, `detectedBy: 'macOS App Bundle (Unreal Engine)'`
  - If unclassified, return `family: 'unknown'`, `tag: 'Others'`, `variant: 'standard'`, `arch: machoArch || 'unknown'`, `runtime: 'native'`, `saveStrategy: 'unknown'`, `detectedBy: 'macOS App Bundle (Unclassified)'`.
- [x] Ensure all returned `GameEngineProfile` instances for Unity, RPG Maker MV/MZ, Ren'Py, Godot, Unreal, and unclassified bundles include the mandatory `arch` property populated from candidate Mach-O inspection (`machoArch || 'unknown'`).
- [x] Add unit tests in `packages/yume-engine/tests/app-bundle-inspector.test.ts` validating engine classification and mandatory `arch` property across all supported bundle markers and inner binary inspection.
