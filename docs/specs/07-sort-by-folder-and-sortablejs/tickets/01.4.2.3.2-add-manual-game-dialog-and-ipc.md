# 01.4.2.3.2 — Add Manual Game Dialog, IPC Controller & Preload Wiring ($B$)

## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement native Electron file picker dialog orchestration outside the serialization queue, default folder path validation, IPC contracts, preload bridge, and controller delegation for manual game additions:
1. Default path validation & Dialog orchestration in `src/main/library-state/actions.ts`:
   - Signature:
     ```typescript
     export async function addManualGame(
       context: LibraryContextInternal,
       options?: { folderPath?: string; targetPlatform?: PlatformInput }
     ): Promise<{ ok: boolean; game?: LogicalGame; canceled?: boolean; error?: string }>
     ```
   - Checks `if (context.isDegraded?.() === true) return { ok: false, error: 'degraded-database' };` immediately at function entry prior to invoking file dialogs. Consumes `dialog` from injected `context` (`const { dialog } = context;`). If `dialog?.showOpenDialog` is omitted or unavailable, defensively return `{ ok: false, error: 'dialog-unavailable' }` to ensure 100% in-memory virtual testability without requiring live Electron instances.
   - Extracts explicit folder path and target platform: `const explicitFolderPath = options?.folderPath; const targetPlatform = options?.targetPlatform;`. Before passing to `dialog.showOpenDialog({ defaultPath })`, validates that if `explicitFolderPath` is provided, non-empty, and resides within `config.libraryPaths` (via `isSubsumedBy`), storing the validated path as `const validatedEnclosing = (explicitFolderPath && config.libraryPaths.some(r => isSubsumedBy(explicitFolderPath, r, targetPlatform))) ? explicitFolderPath : undefined;`. If `explicitFolderPath` is missing, invalid, or outside `config.libraryPaths`, safely falls back to `resolveLibraryFolderToOpen(context)` or `config.libraryPaths[0]` as `defaultPath`, while `validatedEnclosing` remains `undefined`.
   - Wraps `dialog.showOpenDialog` in a `try ... catch` error boundary:
     ```typescript
     let result;
     try {
       result = await dialog.showOpenDialog({ defaultPath, filters, properties: ['openFile'] });
     } catch (err) {
       console.error('[ADD_MANUAL_GAME] Open dialog failed:', { error: err, defaultPath });
       return { ok: false, error: err instanceof Error ? err.message : String(err) };
     }
     ```
     logging structured diagnostics and returning `{ ok: false, error }` upon dialog failure or rejection.
   - Opens file dialog with platform-specific executable filters branched on `targetPlatform` (`.exe` on Windows, `.app` on macOS, all/binaries on Linux) asynchronously outside the serialization queue.
   - If dialog is canceled (`result.canceled === true`), returns `{ ok: false, canceled: true }`.
   - If a file is selected, invokes `addManualGameCore(context, selectedPath, { enclosingFolderPath: validatedEnclosing, targetPlatform })`, decoupling `defaultPath` from `enclosingFolderPath` so generic dialog invocations or fallbacks validate against any configured library root while valid scoped prompts enforce folder containment.
2. Facade Binding in `src/main/library-state/index.ts`:
   - Re-export `addManualGame` from `./actions`.
   - Bind `addManualGame` on `createLibraryState`:
     ```typescript
      addManualGame: (options?: { folderPath?: string; targetPlatform?: PlatformInput }) =>
        addManualGame(context, { ...options, targetPlatform: options?.targetPlatform || this.options.targetPlatform }),
     ```
3. IPC Contract & Preload Bridge:
   - Declare on `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     addManualGame(data?: { folderPath?: string } | string): Promise<{ ok: boolean; game?: any; canceled?: boolean; error?: string }>;
     ```
   - Expose in `src/preload.ts`:
     ```typescript
     addManualGame: (data) => ipcRenderer.invoke('library:add-manual-game', data),
     ```
4. IPC Controller Handler in `src/main/ipc/controllers/library.controller.ts`:
   - Register `library:add-manual-game` normalizing the incoming transport payload at the membrane boundary before delegating to domain actions:
      ```typescript
      const options: { folderPath?: string } = typeof payload === 'string'
        ? { folderPath: payload }
        : (payload && typeof payload === 'object' ? payload as { folderPath?: string } : {});
      return libraryState.addManualGame(options);
      ```

Author Vitest unit tests in `src/main/library-state/actions.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
