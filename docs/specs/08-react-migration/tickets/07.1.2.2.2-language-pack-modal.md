## What to build
Build the declarative language pack management dialog (`LanguagePackModal`) composing the reusable `<Modal>` shell and replacing legacy procedural logic in `src/renderer/language-packs/`:

1. **Language Pack Modal (`src/renderer/components/modals/LanguagePackModal.tsx`)**:
   - Create [`src/renderer/components/modals/LanguagePackModal.tsx`](file:///d:/Projects/YumeShelf/src/renderer/components/modals/LanguagePackModal.tsx):
     - Composes `<Modal>`, `<Modal.Header>`, `<Modal.Body>`, and `<Modal.Footer>` from `./Modal`.
     - Expose `LanguagePackModalProps` with optional parameter seams:
       ```typescript
       export interface LanguagePackModalProps {
         isOpen: boolean;
         onClose: () => void;
         fallbackFocusRef?: React.RefObject<HTMLElement | null>;
         electronAPI?: ElectronAPI;
         storage?: UiStorageAdapter;
         onLanguagePackApplied?: (languageCode: string) => void;
       }
       ```
     - Language Pack Lifecycle & Validation:
       1. **Async Lifecycle & Initial Manifest Fetching**: Manages a 4-state visual lifecycle (`loading` -> `idle`/`loaded` -> `submitting` -> `error`). On mount or modal open, invokes `electronAPI.getLanguageState()` and `electronAPI.getLanguagePackManifest()` displaying a loading spinner in the modal body. If manifest fetch fails, transitions to `error` state with retry CTA and surfaces an error toast via `useNotification().showToast('Failed to load language packs')`.
       2. **Language Code Validation**: Validate code against BCP-47 syntax (`/^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/`) prior to persistence or IPC invocation. If invalid, surface error toast feedback via `useNotification().showToast` and abort.
       3. **Pack Installation Lifecycle**: When downloading an uninstalled pack from the manifest, transitions to `submitting` state and invokes `await electronAPI.installLanguagePack(validatedCode)`. During in-flight operations, apply a single-flight mutex (`isBusy = status === 'submitting' || inFlightCode !== null`) and `aria-disabled="true"` to preserve focus continuity without focus eviction. If installation fails (`!result?.ok`), display notification error and abort.
       4. **Language Activation & Storage Persistence**: When activating a built-in or installed pack, persist via `(storage ?? window.localStorage).setItem('yumeshelf_lang', validatedCode)` and dispatch `onLanguagePackApplied?.(validatedCode)`.
     - Renders language selection table, pack import controls, and review surface actions (replacing 6 legacy files and ~664 lines in `src/renderer/language-packs/`).
     - Consumes `useNotification()` (from `../../providers/NotificationProvider`) to display operation feedback and toast messages.
     - Concrete Declarative Component Implementation:
       ```tsx
       /* src/renderer/components/modals/LanguagePackModal.tsx */
       import React, { useState, useEffect, useLayoutEffect, useMemo, useRef } from 'react';
       import { Modal } from './Modal';
       import { useNotification } from '../../providers/NotificationProvider';
       import type { UiStorageAdapter } from '../../state/ui-runtime-state';
       import type { ElectronAPI, LanguagePackManifestResponse, LanguageState, ManifestPack } from '../../../shared/types/ipc';
       import { sanitizeUserPaths } from '../../../shared/path-sanitizer';

       export type LanguagePackListItem = ManifestPack & { isInstalled: boolean };

       export interface LanguagePackModalProps {
         isOpen: boolean;
         onClose: () => void;
         fallbackFocusRef?: React.RefObject<HTMLElement | null>;
         electronAPI?: ElectronAPI;
         storage?: UiStorageAdapter;
         onLanguagePackApplied?: (languageCode: string) => void;
       }

       const BCP47_REGEX = /^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/;

       export const LanguagePackModal: React.FC<LanguagePackModalProps> = ({
         isOpen,
         onClose,
         fallbackFocusRef,
         electronAPI,
         storage,
         onLanguagePackApplied,
       }) => {
         const [status, setStatus] = useState<'loading' | 'idle' | 'submitting' | 'error'>('loading');
         const [packs, setPacks] = useState<LanguagePackListItem[]>([]);
         const [activeCode, setActiveCode] = useState<string>('en');
         const [searchQuery, setSearchQuery] = useState<string>('');
         const [inFlightCode, setInFlightCode] = useState<string | null>(null);

         const manifestReqSeqRef = useRef(0);
         const installSeqRef = useRef(0);
         const isMountedRef = useRef(true);
         const isOpenRef = useRef(isOpen);
         const searchInputRef = useRef<HTMLInputElement | null>(null);
         const closeBtnRef = useRef<HTMLButtonElement | null>(null);
         const packCardRefs = useRef(new Map<string, HTMLDivElement>());
         const actionBtnRefs = useRef(new Map<string, HTMLButtonElement>());
         const pendingInstallFocusCodeRef = useRef<string | null>(null);
         useEffect(() => {
           isOpenRef.current = isOpen;
         }, [isOpen]);
         useEffect(() => {
           isMountedRef.current = true;
           return () => {
             isMountedRef.current = false;
           };
         }, []);

         const { showToast } = useNotification();
         const api = electronAPI ?? (typeof window !== 'undefined' ? window.electronAPI : undefined);
         const store = storage ?? (typeof window !== 'undefined' ? window.localStorage : undefined);

         const loadManifest = async ({
           silent = false,
           installedCode,
         }: { silent?: boolean; installedCode?: string } = {}) => {
           if (!isMountedRef.current) return;
           const seq = ++manifestReqSeqRef.current;
           if (!silent) {
             setStatus('loading');
           }
           try {
             const BCP47_REGEX = /^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/;
             let candidate = 'en';
             try {
               const rawStored = store?.getItem?.('yumeshelf_lang');
               const trimmed = typeof rawStored === 'string' ? rawStored.trim().toLowerCase() : '';
               candidate = BCP47_REGEX.test(trimmed) ? trimmed : 'en';
             } catch (err) {
               console.warn('[LanguagePackModal] Failed to read yumeshelf_lang from storage:', {
                 error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
               });
             }
             if (isMountedRef.current) setActiveCode(candidate);

             let state: LanguageState | undefined;
             if (api?.getLanguageState) {
               try {
                 state = await api.getLanguageState();
               } catch (err) {
                 console.warn('[LanguagePackModal] Failed to get active language state, preserving stored language:', {
                   candidate,
                   error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
                   stack: err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined,
                 });
               }
             }

             const installedCodes = new Set<string>([
               ...(state?.builtIn ?? []).map((p: any) => p.code),
               ...(state?.installed ?? []).map((p: any) => p.code),
             ]);
             const availableCodes = new Set<string>(
               [...(state?.builtIn ?? []), ...(state?.installed ?? [])]
                 .map((p) => String(p.code || '').trim().toLowerCase())
                 .filter(Boolean)
             );
             const validatedCode = availableCodes.size > 0 && !availableCodes.has(candidate) ? 'en' : candidate;
             if (isMountedRef.current) setActiveCode(validatedCode);

             // Safely unwrap manifest payload supporting wrapped { ok, packs } or direct array fixture
             const res: LanguagePackManifestResponse | ManifestPack[] | undefined = await api?.getLanguagePackManifest?.();
             if (res && typeof res === 'object' && 'ok' in res && !res.ok) {
               throw new Error(res.error || 'Failed to load language packs');
             }

             const manifestPacks: ManifestPack[] = Array.isArray(res)
               ? res
               : (Array.isArray(res?.packs) ? res.packs : []);

             const reconciledPacks: LanguagePackListItem[] = manifestPacks.map((pack) => ({
               ...pack,
               isInstalled: installedCodes.has(pack.code),
             }));

             if (seq === manifestReqSeqRef.current && isMountedRef.current && isOpenRef.current) {
               setActiveCode(validatedCode);
               if (installedCode) {
                 const active = typeof document !== 'undefined' ? document.activeElement : null;
                 const cardEl = packCardRefs.current.get(installedCode) ?? null;
                 const btnEl = actionBtnRefs.current.get(installedCode) ?? null;
                 const isOwnedOrEvicted =
                   active === btnEl ||
                   Boolean(cardEl && active && cardEl.contains(active)) ||
                   active === document.body ||
                   active === document.documentElement ||
                   active === null ||
                   !active.isConnected;
                 if (!isOwnedOrEvicted) {
                   pendingInstallFocusCodeRef.current = null;
                 }
               }
               setPacks(reconciledPacks);
               setStatus('idle');
             }
           } catch (err) {
             console.error('[LanguagePackModal] Failed to load language pack manifest:', {
               error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
               stack: err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined,
             });
             if (seq === manifestReqSeqRef.current && isMountedRef.current && isOpenRef.current) {
               if (!silent) {
                 setStatus('error');
               }
               showToast('Failed to load language packs');
             }
           }
         };

         useEffect(() => {
           manifestReqSeqRef.current += 1;
           installSeqRef.current += 1;
           pendingInstallFocusCodeRef.current = null;
           setInFlightCode(null);
           setStatus((prev) => (prev === 'submitting' ? 'idle' : prev));
           if (isOpen) {
             void loadManifest();
           }
         }, [isOpen]);

         const isBusy = status === 'submitting' || inFlightCode !== null;

         useLayoutEffect(() => {
           const targetCode = pendingInstallFocusCodeRef.current;
           if (!targetCode || !isOpen || isBusy) return;
           pendingInstallFocusCodeRef.current = null;
           const active = typeof document !== 'undefined' ? document.activeElement : null;
           const cardEl = packCardRefs.current.get(targetCode) ?? null;
           const targetBtn = actionBtnRefs.current.get(targetCode) ?? null;
           const isOwnedOrEvicted =
             active === targetBtn ||
             Boolean(cardEl && active && cardEl.contains(active)) ||
             active === null ||
             active === document.body ||
             active === document.documentElement ||
             !active.isConnected;
           if (!isOwnedOrEvicted) return;
           (targetBtn ?? searchInputRef.current ?? closeBtnRef.current)?.focus();
         }, [packs, isOpen, isBusy]);

         const filteredPacks = useMemo(() => {
           const q = searchQuery.trim().normalize('NFC').toLowerCase();
           if (!q) return packs;
           return packs.filter((p) => 
             (p.nativeName || p.englishName || p.code).normalize('NFC').toLowerCase().includes(q) || 
             p.code.normalize('NFC').toLowerCase().includes(q) ||
             (p.englishName && p.englishName.normalize('NFC').toLowerCase().includes(q))
           );
         }, [packs, searchQuery]);

         const handleInstall = async (code: string) => {
           if (isBusy) return;
           if (!BCP47_REGEX.test(code)) {
             showToast(`Invalid language code format: ${code}`);
             return;
           }
           const active = typeof document !== 'undefined' ? document.activeElement : null;
           pendingInstallFocusCodeRef.current = active === actionBtnRefs.current.get(code) ? code : null;
           const installSeq = ++installSeqRef.current;
           setInFlightCode(code);
           setStatus('submitting');
           try {
             const res = await api?.installLanguagePack?.(code);
             if (installSeq !== installSeqRef.current || !isMountedRef.current || !isOpenRef.current) return;
             if (res?.ok) {
               showToast(`Installed language pack: ${code}`);
               await loadManifest({ silent: true, installedCode: code });
             } else {
               pendingInstallFocusCodeRef.current = null;
               const sanitizedReason = res?.reason && String(res.reason).trim().length > 0
                 ? sanitizeUserPaths(String(res.reason))
                 : 'Installation failed';
               console.error('[LanguagePackModal] Language pack installation failed:', {
                 code,
                 reason: sanitizedReason,
               });
               showToast(sanitizedReason);
               setStatus('idle');
             }
           } catch (err) {
             if (installSeq !== installSeqRef.current || !isMountedRef.current || !isOpenRef.current) return;
             console.error(`[LanguagePackModal] Unexpected error installing language pack "${code}":`, {
               packCode: code,
               error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
               stack: err instanceof Error && err.stack ? sanitizeUserPaths(err.stack) : undefined,
             });
             showToast('Installation encountered an unexpected error');
             setStatus('idle');
           } finally {
             if (installSeq === installSeqRef.current && isMountedRef.current) {
               setInFlightCode(null);
               setStatus((prev) => (prev === 'submitting' ? 'idle' : prev));
             }
           }
         };

         const handleApply = (code: string) => {
           if (isBusy) return;
           if (!BCP47_REGEX.test(code)) {
             showToast(`Invalid language code format: ${code}`);
             return;
           }
           try {
             store?.setItem('yumeshelf_lang', code);
           } catch (err) {
             console.warn('[LanguagePackModal] Failed to persist active language to storage:', {
               code,
               error: sanitizeUserPaths(err instanceof Error ? err.message : String(err)),
             });
           }
           manifestReqSeqRef.current += 1;
           setActiveCode(code);
           onLanguagePackApplied?.(code);
           showToast(`Activated language: ${code}`);
           onClose();
         };

         return (
           <Modal
             isOpen={isOpen}
             onClose={onClose}
             fallbackFocusRef={fallbackFocusRef}
             panelClassName="language-pack-panel"
             title="Language Packs"
           >
             <Modal.Header>Language Packs</Modal.Header>
             <Modal.Body className="language-pack-body">
               <div className="language-pack-toolbar">
                 <input
                   ref={searchInputRef}
                   type="search"
                   className="language-pack-search"
                   placeholder="Search language packs..."
                   value={searchQuery}
                   onChange={(e) => setSearchQuery(e.target.value)}
                   aria-label="Search language packs"
                 />
               </div>

               {status === 'loading' && (
                 <div className="language-pack-placeholder" role="status" aria-live="polite">
                   Loading language packs...
                 </div>
               )}

               {status === 'error' && (
                 <div className="language-pack-empty" role="alert">
                   <h3>Unable to fetch language packs</h3>
                   <p>Please check your connection and try again.</p>
                   <button
                     type="button"
                     className="small-btn secondary-btn"
                     onClick={() => void loadManifest()}
                   >
                     Retry
                   </button>
                 </div>
               )}

               {status !== 'loading' && status !== 'error' && (
                 <div className="language-pack-results" role="list">
                   {filteredPacks.length === 0 ? (
                     <div className="language-pack-empty">
                       <h3>No language packs found</h3>
                       <p>Try refining your search terms.</p>
                     </div>
                   ) : (
                     filteredPacks.map((pack) => {
                       const isSelected = activeCode === pack.code;
                       const isInFlight = inFlightCode === pack.code;
                       return (
                         <div
                           key={pack.code}
                           ref={(el) => {
                             if (el) packCardRefs.current.set(pack.code, el);
                             else packCardRefs.current.delete(pack.code);
                           }}
                           className="language-pack-card"
                           role="listitem"
                         >
                           <div className="language-pack-card-info">
                             <h3>{pack.nativeName || pack.englishName || pack.code} {pack.englishName && pack.nativeName && pack.englishName !== pack.nativeName && `(${pack.englishName})`}</h3>
                             <p>{pack.code}</p>
                             <div className="language-pack-card-meta">
                               {pack.packVersion && <span className="language-pack-chip">v{pack.packVersion}</span>}
                               {isSelected && <span className="language-pack-chip active">Active</span>}
                             </div>
                           </div>
                           <div className="language-pack-actions">
                             {pack.isInstalled ? (
                               <button
                                 ref={(el) => {
                                   if (el) actionBtnRefs.current.set(pack.code, el);
                                   else actionBtnRefs.current.delete(pack.code);
                                 }}
                                 type="button"
                                 className="small-btn secondary-btn"
                                                                   aria-disabled={isSelected || isBusy ? 'true' : undefined}
                                  style={isSelected || isBusy ? { pointerEvents: 'none', opacity: 0.5 } : undefined}
                                 onClick={() => {
                                   if (!isSelected && !isBusy) handleApply(pack.code);
                                 }}
                               >
                                 {isSelected ? 'Applied' : 'Apply'}
                               </button>
                             ) : (
                               <button
                                 ref={(el) => {
                                   if (el) actionBtnRefs.current.set(pack.code, el);
                                   else actionBtnRefs.current.delete(pack.code);
                                 }}
                                 type="button"
                                 className="small-btn primary-btn"
                                                                   aria-disabled={isBusy ? 'true' : undefined}
                                  style={isBusy ? { pointerEvents: 'none', opacity: 0.5 } : undefined}
                                 onClick={() => {
                                   if (!isBusy) void handleInstall(pack.code);
                                 }}
                               >
                                 {isInFlight ? 'Installing...' : 'Download & Install'}
                               </button>
                             )}
                           </div>
                         </div>
                       );
                     })
                   )}
                 </div>
               )}
             </Modal.Body>
             <Modal.Footer>
               <button ref={closeBtnRef} type="button" className="small-btn secondary-btn" onClick={onClose}>
                 Close
               </button>
             </Modal.Footer>
           </Modal>
         );
       };
       ```

## Acceptance Criteria
- [ ] `LanguagePackModal` composes `<Modal>` and renders language list, import controls, and review surface actions into `#portal-root` (with `document.body` fallback).
- [ ] `LanguagePackModal` implements a 4-state lifecycle (`loading`, `idle`/`loaded`, `submitting`, `error`), fetching manifest via `electronAPI.getLanguageState()` and `electronAPI.getLanguagePackManifest()` with loading spinner and error retry fallback.
- [ ] `LanguagePackModalProps` exposes `fallbackFocusRef?: React.RefObject<HTMLElement | null>`, `storage?: UiStorageAdapter` seam alongside `electronAPI?: ElectronAPI` and `onLanguagePackApplied?: (languageCode: string) => void`.
- [ ] `LanguagePackModal` binds directly to canonical `src/styles/language-packs.css` selectors (`.language-pack-panel`, `.language-pack-body`, `.language-pack-toolbar`, `.language-pack-search`, `.language-pack-results`, `.language-pack-card`, `.language-pack-card-meta`, `.language-pack-chip`, `.language-pack-empty`, `.language-pack-placeholder`) and styles `'Download & Install'` and `'Apply'` / `'Applied'` buttons using verified `.small-btn`, `.secondary-btn`, and `.primary-btn` rules in `src/styles/language-packs.css`, `src/styles/base.css`, and `src/styles/settings.css`.
- [ ] **Given** `'Download & Install'` for `code` has focus and `installLanguagePack(code)` resolves `{ ok: true }`, **when** `handleInstall` triggers `loadManifest({ silent: true, installedCode: code })`, **then** `.language-pack-results` stays mounted without flipping `status` to `'loading'` while the silent refresh promise is pending, focus transfers to the surviving `'Apply'` button via `useLayoutEffect` only when focus is owned by that pack card/button or evicted (`isOwnedOrEvicted`) and never steals focus if the user moved focus to `.language-pack-search`, and if `loadManifest({ silent: true, installedCode: code })` rejects, `.language-pack-results` remains mounted with existing `packs`, `status` returns to `'idle'` via `finally`, and `showToast('Failed to load language packs')` fires without rendering the full-body error panel.
- [ ] Unit test fixtures for `getLanguagePackManifest` in `LanguagePackModal.test.tsx` model canonical producer payloads `{ ok: true, packs: ManifestPack[] }` (using `nativeName`, `englishName`, `packVersion` imported from `src/shared/types/ipc.d.ts`) while defensively supporting raw array fixtures to eliminate mock drift.
- [ ] When `loadManifest` or `handleInstall` rejects or resolves with `{ ok: false, reason }`, the modal logs structured failure diagnostics with `[LanguagePackModal]` prefix to `console.error` (including reason, error message, and stack trace scrubbed via `sanitizeUserPaths` to ensure OS usernames in mock error paths such as `C:\Users\John Doe\...` are sanitized to `<USER_DIR>`, falling back to `'Installation failed'` if reason is empty) in addition to displaying the error toast.
- [ ] **Given** `LanguagePackModal` has an install or apply operation in flight (`isBusy === true`), **when** rendered, **then** action buttons declare `aria-disabled="true"` with pointer event suppression (`pointer-events: none`) and visual dimming (`opacity: 0.5`), preventing duplicate activations while preserving keyboard focus stability.
- [ ] **Given** `LanguagePackModal` renders with `fallbackFocusRef`, **when** the modal closes and its invoking trigger is disconnected from the DOM, **then** focus transfers deterministically to `fallbackFocusRef.current` with zero focus eviction to `document.body`.
- [ ] Tracks modal visibility and request sequences via `isOpenRef`, `manifestReqSeqRef`, and `installSeqRef`, resetting in-flight code and status on `[isOpen]` transitions, and suppresses stale manifest re-fetch and notification toasts upon async resolution if the modal has been closed or re-opened while maintaining mounted state.
- [ ] Validates language codes against BCP-47 syntax (`/^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/`) prior to persistence or IPC invocation; displays notification toast and aborts on invalid format.
- [ ] Invokes `electronAPI.installLanguagePack(validatedCode)` when installing uninstalled manifest packs; activates packs via `(storage ?? window.localStorage).setItem('yumeshelf_lang', validatedCode)` wrapped in `try/catch` with diagnostic `console.warn` (scrubbing error message via `sanitizeUserPaths`) on storage exceptions (guaranteeing that storage quota limits or security restrictions do not crash the handler or prevent in-memory language activation) and `onLanguagePackApplied`.
- [ ] In-flight async operations maintain focus continuity using `aria-disabled="true"` rather than interactive element removal.
- [ ] Pack import and configuration mutations trigger notifications via `useNotification()`.
- [ ] All unit tests in `LanguagePackModal.test.tsx` pass under Vitest.
- [ ] `npm run typecheck` passes with zero errors.
