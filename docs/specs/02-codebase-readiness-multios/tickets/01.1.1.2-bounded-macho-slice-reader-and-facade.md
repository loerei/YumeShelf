# 01.1.1.2 — Bounded Mach-O Slice Reader & Facade in YumeEngine ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Implement bounded file-slice inspection in `MachOInspector.fromPath(filePath: string, fs?: IFileSystem)` and expose `YumeEngine.inspectMachOFile(filePath: string, fs?: IFileSystem)` in `@yumeshelf/engine` reading only a bounded header slice ($\le 4\text{KB}$) via file handles wrapped in a `try...finally` block guaranteeing handle closure and bounded memory usage ($\le 64\text{KB}$). When parsing Universal FAT binaries, validate that the architecture descriptor table fits within the header buffer and only validate architecture slice offsets (`Number(offset) + Number(size) <= fileSize`) using explicit BigInt-to-Number casting when full `fileSize` is provided. Re-export `MachOInspector` from `packages/yume-engine/src/index.ts`.

## Explicit Assumptions & Boundaries
- Pure structural refactoring ($S$) adding file I/O layer on top of in-memory inspector (`01.1.1.1`).
- Operates strictly inside `@yumeshelf/engine` per `AGENTS.md`.
