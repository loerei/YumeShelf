## What to build

Author an isolated, headless `AtomicWriteCoordinator` engine in `src/main/library-state/write-coordinator.ts` that coordinates database reads and writes, debounces disk flushes, serializes mutations via an in-memory promise queue, enforces degradation circuit breakers, guarantees cache rollback on persistence rejection, executes atomic file replacements with file descriptor closing, and guarantees clean synchronous flushes on app shutdown.

  - In `loadDB()`, when disk loading encounters unrecoverable corruption (0-byte file without valid candidate backups, unparseable JSON without valid recovery candidates, or `raw.schemaVersion > CURRENT_SCHEMA_VERSION`), set `this.isDegradedState = true;` and log structured error/warning:

    When a valid database is successfully read, recovered, or migrated, reset `this.isDegradedState = false;`.
  - In `mutate()`, enforce the degradation circuit breaker both before mutator execution and prior to cache commitment:
    ```typescript
    if (this.isDegraded()) {
      console.warn('[LIBRARY_STATE] Persistence aborted: database is in DEGRADED state.', { dbFilePath: this.dbFilePath });
    ```

- [ ] Implement in-memory state caching, transactional working copy isolation, and serialized read-modify-write coordination via asynchronous `getLatestDB(): Promise<DatabaseSchema>`, synchronous snapshot accessor `getCachedDBSync(): DatabaseSchema | null`, and `mutate<T>(mutator: (db: DatabaseSchema) => Promise<T> | T): Promise<T>` backed by an internal promise queue (`private queue = Promise.resolve()`) to serialize concurrent mutations and cold-start calls without lost updates:
  ```typescript
  mutate<T>(mutator: (db: DatabaseSchema) => Promise<T> | T): Promise<T> {
    if (this.isShuttingDown) {
      throw new Error('AtomicWriteCoordinator is shut down; mutations rejected');
    }
    if (this.isDegraded()) {
      console.warn('[LIBRARY_STATE] Persistence aborted: database is in DEGRADED state.', { dbFilePath: this.dbFilePath });
      throw new Error('Database is in degraded state');
    }
    const resultPromise = this.queue.then(async () => {
      if (this.isShuttingDown) {
        throw new Error('AtomicWriteCoordinator is shut down; mutations rejected');
      }
      if (this.isDegraded()) {
        console.warn('[LIBRARY_STATE] Persistence aborted: database is in DEGRADED state.', { dbFilePath: this.dbFilePath });
        throw new Error('Database is in degraded state');
      }
      if (this.cachedDb === null) {
        await this.loadDB();
      }
      if (this.isDegraded()) {
        console.warn('[LIBRARY_STATE] Persistence aborted: database is in DEGRADED state.', { dbFilePath: this.dbFilePath });
        throw new Error('Database is in degraded state');
      }
      if (this.cachedDb === null || this.cachedDb === undefined) {
        this.cachedDb = createDefaultDatabase();
      }
      const workingCopy = structuredClone(this.cachedDb);
      const result = await mutator(workingCopy);
      if (this.isShuttingDown) {
        throw new Error('AtomicWriteCoordinator is shut down; mutations rejected');
      }

      if (this.saveDB) {
        await this.saveDB(workingCopy);
        this.cachedDb = workingCopy;
        this.writeGeneration++;
      } else {
        if (!this.dbFilePath) {
          throw new Error('Cannot write to disk: dbFilePath is undefined');
        }
        this.cachedDb = workingCopy;
        this.writeGeneration++;
        this.isDirty = true;
        this.scheduleDebouncedWrite();
      }

      return result;
    });
    // Advance queue forward even if mutator or persistence rejects, preventing queue poisoning
    this.queue = resultPromise.then(() => {}, () => {});
    return resultPromise;
  }
  ```
  Inside `scheduleDebouncedWrite()`, return immediately if `this.isShuttingDown === true`. Advance `this.queue` using `resultPromise.then(() => {}, () => {})` so that rejected mutations or persistence errors reject only the caller's promise while preserving uncommitted `this.cachedDb` and leaving `this.queue` in a resolved state for subsequent operations and `getLatestDB()` calls.
- [ ] Implement single-flight memoization in `loadDB()`: Guard `loadDB()` against concurrent executions via `private inFlightLoad: Promise<DatabaseSchema> | null = null`. If `this.inFlightLoad !== null`, return `this.inFlightLoad` immediately so all concurrent cold-start callers share the identical in-flight loader promise, ensuring disk I/O, backup snapshot creation (`copyFileSync` to `.${path.basename(this.dbFilePath)}.v${currentVersion}.bak`), crash recovery sweeps, and schema migrations execute strictly once without Win32 sharing violations (`EBUSY` / `EPERM`).
- [ ] Implement queue synchronization in `getLatestDB()`: Inside `getLatestDB()`, ensure initialization and await current in-flight queue mutations before returning the cloned state, guaranteeing read-after-write consistency without queue self-deadlocks:
  ```typescript
  async getLatestDB(): Promise<DatabaseSchema> {
    if (this.cachedDb === null) {
      await this.loadDB();
    }
    await this.queue;
    return structuredClone(this.cachedDb ?? createDefaultDatabase());
  }
  ```
- [ ] Implement snapshot isolation on `getCachedDBSync()`: Return `this.cachedDb !== null ? structuredClone(this.cachedDb) : null`. Callers never receive direct mutable references to internal cache objects.
- [ ] Implement debounced disk write coalescing (`debounceMs?: number`, default: 150ms) and atomic file replacement authoring temporary files matching `.${path.basename(this.dbFilePath)}.tmp.${process.pid}.${Date.now()}.${++this.tempFileCounter}` strictly in `path.dirname(this.dbFilePath)`. Ensure `path.dirname(this.dbFilePath)` exists via `fsSync.mkdirSync(path.dirname(this.dbFilePath), { recursive: true })` (or `await fs.mkdir(dir, { recursive: true })`) prior to temporary file creation. Explicitly close the file descriptor (`closeSync(fd)` / `fileHandle.close()`) immediately after `fsyncSync(fd)` / `fileHandle.sync()` inside `try...finally` prior to `renameSync` / `fs.rename` to prevent Win32 `MoveFileExW` sharing violations (`EPERM`/`EBUSY`). Expose public testability seam `waitForPendingWrites(): Promise<void>` on `IWriteCoordinator` and `AtomicWriteCoordinator` that tracks in-flight asynchronous write promises and resolves when all active debounce timers and disk replacement operations have settled.
- [ ] Concurrency control and retry backoff in async write path: serialize asynchronous disk writes via internal mutex/promise queue; maintain monotonic `writeGeneration` counter; apply bounded retry backoff (up to 3 attempts, 10ms delay) on Windows sharing collisions (`EBUSY`/`EPERM`); only clear `isDirty` if written generation matches latest generation (re-arming debounce timer if newer mutations arrived during write). Wrap the debounced async temp write, descriptor close, and bounded rename retry loop in a `try...catch` block. If all rename attempts fail:
  1. Retain `this.isDirty = true`.
  2. Asynchronously unlink the unrenamed temporary file via `fs.unlink(tempPath).catch(() => {})`.
  3. Log diagnostic warning to `safe-console.warn('[WRITE-COORDINATOR][ERROR] Debounced async write failed, retrying...', error)`.
  4. Re-arm the debounce timer with backoff (500ms).
  5. Catch errors to prevent unhandled promise rejections.
- [ ] Implement non-destructive synchronous shutdown flush `flushSync(): void`:
  - Unconditionally cancel debounce timers, advance `writeGeneration` to invalidate in-flight async writes, and set `this.isShuttingDown = true` FIRST upon entering `flushSync()`.
  - Check `if (!this.isDirty || !this.dbFilePath) return;` immediately to avoid redundant disk I/O and prevent dereferencing undefined `dbFilePath` under custom persistence delegates.
  - Ensure directory exists via `fsSync.mkdirSync(path.dirname(this.dbFilePath), { recursive: true })`.
  - Execute `fsSync.openSync` -> `writeSync` -> `fsyncSync` -> `closeSync` in `try...finally` -> sequential bounded retry loop for `renameSync` (up to `maxRetryAttempts`, default 3, using `options.retryDelayMs`, default 0 in tests, without synchronous busy-wait loops).
  - If `renameSync` fails due to persistent Windows file locks, do NOT perform destructive in-place truncation (`writeFileSync(this.dbFilePath, ...)`). Retain the fsynced `tempPath` on disk, attempt an emergency copy to `.${path.basename(this.dbFilePath)}.bak` wrapped in a defensive `try...catch` block to ensure shutdown never crashes on filesystem errors, and log the error to `safe-console`.
  - Prior to executing schema migrations where `currentVersion < TARGET_VERSION`, verify whether `this.dbFilePath` exists on disk. If it exists, create an un-mutated backup snapshot `.${path.basename(this.dbFilePath)}.v${currentVersion}.bak` in `path.dirname(this.dbFilePath)` using atomic file copy (`fsSync.copyFileSync`) before executing migration steps and rewriting the database file. When `AtomicWriteCoordinator.loadDB` detects `raw.schemaVersion < 2` and executes `migrateStorage(raw)`, await immediate atomic file persistence to disk (using `writeAtomicJson` or atomic replacement with descriptor close and fsync) before resolving `loadDB` and returning `db` to callers, bypassing the 150ms debounced timer during initial storage upgrade to guarantee durability.
- [ ] Partitioned startup crash recovery sweep: guard sweep with `if (!this.dbFilePath || typeof this.dbFilePath !== 'string') return;` and check `fsSync.existsSync(dir)` before reading. Define helper `const escapeRegExp = (str: string): string => str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');` and inspect candidate temporary files matching dynamically compiled regex `new RegExp('^\\.' + escapeRegExp(path.basename(this.dbFilePath)) + '\\.tmp\\.\\d+\\.\\d+(?:\\.\\d+)?$')` in `path.dirname(this.dbFilePath)`.
  - **Path A (Corrupted / Absent Database)**: If `this.dbFilePath` does not exist, is 0-byte truncated, fails JSON parsing, or fails structural validation (`!isPlainObject(existingDb) || !isPlainObject(existingDb.config)` or failing to satisfy either `isPlainObject(existingDb.games)` or valid unmigrated legacy flat game records, or `existingDb.virtualTree && !validateTreeInvariants(existingDb.virtualTree).ok`), inspect candidate temporary files matching the recovery regex. Filter candidates for non-empty, parseable JSON satisfying strict `DatabaseSchema` structural validation: must contain both `games` (`isPlainObject(candidate.games)`) and `config` (`isPlainObject(candidate.config)`). If `candidate.virtualTree` is present, validate via `validateTreeInvariants(candidate.virtualTree)` requiring `{ ok: true }`; if invalid, reject candidate. If `candidate.favoriteOrder` is present, validate as array of non-empty strings ($\le 500$ chars, length $\le 10000$) free of control characters and prototype keys. If valid candidates survive, sort descending by `mtimeMs` and restore the newest candidate to `this.dbFilePath`. If zero temp candidates survive, inspect candidate backup snapshots matching both `.${path.basename(this.dbFilePath)}.bak` and `.${path.basename(this.dbFilePath)}.v*.bak` (sorting candidate backups by `mtimeMs` descending). For pre-V2 backups (`bak.schemaVersion === undefined || bak.schemaVersion < 2`), require `isPlainObject(bak.config)` and valid game records; for V2+ backups (`bak.schemaVersion >= 2`), require `isPlainObject(bak.games) && isPlainObject(bak.config)`, `validateTreeInvariants(bak.virtualTree).ok === true`, and valid `favoriteOrder`. If valid, restore to `this.dbFilePath`.
  - **Path B (Valid Existing Database)**: Only entered if `this.dbFilePath` exists on disk, `statSync(this.dbFilePath).size > 0`, successfully parses as valid JSON, AND satisfies structural validation: `isPlainObject(existingDb) && isPlainObject(existingDb.config)` AND either `isPlainObject(existingDb.games)` (with `!existingDb.virtualTree || validateTreeInvariants(existingDb.virtualTree).ok === true`) OR `(existingDb.schemaVersion === undefined && Object.keys(existingDb).some(k => !['config', 'schemaVersion'].includes(k) && isPlainObject(existingDb[k]) && typeof existingDb[k].folderPath === 'string'))`. When entering Path B, obtain `dbMtime = fsSync.statSync(this.dbFilePath).mtimeMs`. Inspect candidate temporary files and filter ONLY candidates where `candidate.mtimeMs > dbMtime`. For each newer candidate, verify strict structural validation: (1) `isPlainObject(candidate.games) && isPlainObject(candidate.config)`, (2) non-empty candidate `games` if existing database contains games, (3) `validateTreeInvariants(candidate.virtualTree).ok === true` if present, (4) array string bounds on `favoriteOrder`. If newer valid candidate exists, restore newest candidate to `this.dbFilePath`.
  - In `sweepOrphanedTempFiles`, wrap candidate file inspection and unlinking operations in defensive `try...catch` blocks to intercept transient filesystem errors (`EBUSY`, `EPERM`, `ENOENT`).
  - **Cleanup**: Unlink remaining orphaned temporary files matching recovery regex older than `this.processStartTime`.
