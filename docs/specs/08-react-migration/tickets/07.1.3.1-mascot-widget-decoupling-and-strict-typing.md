# 07.1.3.1 — Mascot Widget Decoupling & Strict Typing ($S$)

## Epic
[Epic 08: React Migration & Renderer Reconstruction](file:///d:/Projects/YumeShelf/docs/specs/08-react-migration/PRD.md)

## What to build
Decouple the legacy mascot widget controller from procedural feature controllers, remove module-load time asset preloading, and enforce strict TypeScript typing:

1. **Strict Typing & Module Safety (`mascot-widget.ts`)**:
   - In [`src/renderer/mascot-widget.ts`](file:///d:/Projects/YumeShelf/src/renderer/mascot-widget.ts):
     - Remove `// @ts-nocheck` from line 1 and enforce strict TypeScript typing across all controller options, state, and methods. Static asset imports (`.png`, `.mp3`) on lines 2–7 rely strictly on the ambient declarations provided by `"vite/client"` established in Ticket 01, guaranteeing zero local ambient shims or `@ts-ignore` pragmas are introduced.
     - Accept `storage?: UiStorageAdapter` in `MascotWidgetOptions` (defaulting to `typeof localStorage !== 'undefined' ? localStorage : undefined`). Replace direct ambient references to `localStorage` (`yumeshelf_mascot_x`, `yumeshelf_mascot_y`, `yumeshelf_mascot_bonk_count`, `yumeshelf_mascot_scale`, `yumeshelf_mascot_sound`, `yumeshelf_mascot_volume`) with `storage?.getItem(...)`, `storage?.setItem(...)`, and `storage?.removeItem(...)` to enforce storage isolation.
     - Remove module-load time `new Image()` preloading loop that crashes Vitest in headless Node/HappyDOM environments; defer image preloading to explicit `init()` call.
     - Ensure `#mascot-menu-reset-btn` click listener and keyboard listeners (`onDocumentKeyDown` handling `Enter`/`Space` bonk activation when `event.target === widgetEl` and `Escape` menu dismissal, or dedicated `widgetEl` `keydown` listener if refactored) are cleanly removed in `destroy()` to eliminate event listener leaks.

2. **Structural Decoupling from Legacy Features**:
   - **Decoupling Invariant**: Inline or relocate `getNextShuffledIndex` into `mascot-widget.ts` and delete `import { getNextShuffledIndex } from './features/hide-and-seek'`. This decouples `mascot-widget.ts` from `hide-and-seek.ts` during Ticket 07.1.3.1, guaranteeing that when `src/renderer/features/hide-and-seek.ts` is deleted in Ticket 07.2, no broken imports or compilation failures occur.

3. **Design System Token Alignment & Focus Visibility (`src/styles/mascot.css`)**:
   - Refactor `src/styles/mascot.css` to eliminate hardcoded z-index magic numbers and replace raw `outline: none;` fallback suppression with explicit keyboard `:focus-visible` styling:
     - Bind `.yume-mascot-widget` to `var(--zIndex-widget)` (`1600`).
     - Bind `.mascot-context-menu` and `.bonk-impact-particle` to `var(--zIndex-widget-overlay)` (`1700`).
     - Declare `:focus-visible` outlines on `.yume-mascot-widget` and `.mascot-menu-reset-btn`:
       ```css
       /* src/styles/mascot.css */
       .yume-mascot-widget:focus-visible,
       .mascot-menu-reset-btn:focus-visible {
           outline: 2px solid var(--accent);
           outline-offset: 2px;
       }
       ```

4. **Vitest Unit Tests (`mascot-widget.test.ts`)**:
   - Create unit tests in `src/renderer/mascot-widget.test.ts` verifying:
     - `createMascotWidget` initializes in headless/JSDOM environments.
     - `init()` mounts DOM elements and attaches pointer, contextmenu, and keyboard (`Enter`/`Space`/`Escape`) listeners cleanly.
     - `destroy()` removes all attached DOM and document event listeners (including `#mascot-menu-reset-btn` click and `keydown` listeners) and resets internal state.
     - Passing a mock `UiStorageAdapter` directs all mascot preference and coordinate reads/writes to the mock adapter with zero ambient `localStorage` calls.
