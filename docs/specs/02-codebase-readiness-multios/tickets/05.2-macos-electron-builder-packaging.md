# 05.2 — macOS Electron Packaging Pipeline & Playtime Helper Bundle ($B$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Configure `electron-builder` in `package.json` for macOS targets (`dmg`, `zip`), bundling the native Darwin `playtime-helper` executable via `mac.extraResources`. Relocate Windows native executable mapping from root `build.extraResources` to `build.win.extraResources`. Set `"identity": null` under `build.mac` for development packaging, and update the `"build:mac"` npm script to `cross-env CSC_IDENTITY_AUTO_DISCOVERY=false electron-builder --mac`. Add automated package configuration validation in `tests/release-artifacts.test.js`.
