# 01.2.1 — macOS .app Bundle Scanner Directory Traversal & Structural Seams ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Update `collectGameCandidates` in `src/main/library-state/scanner.ts` to intercept `.app` bundle directories during Step 1 recursion, preventing recursive descent into `Contents/`. Yield each `.app` bundle directly as an independent `CandidateGame` instance (`folderPath: bundlePath, exePath: resolvedExePath, platform: 'macos'`) into `nestedCandidates`, preserving sibling `.app` bundles in multi-game directories under Resolution Matrix Case A. In Step 2 of `collectGameCandidates`, explicitly filter out `.app` directory entries so that direct executable candidate resolution only operates on files or non-bundle entries, eliminating duplicate I/O. In Resolution Matrix Case B (`nestedCandidates.length === 1`), ensure `directCandidate` does not override `nestedCandidates[0]` when `nestedCandidates[0]` is a host-native macOS `.app` bundle while `directCandidate` is non-native (`targetPlatform === 'darwin' && nestedCandidates[0].platform === 'macos' && directCandidate.platform !== 'macos'`). Defensively adapt `fs` passed into `AppBundleInspector.fromPath` if `fs.readFile` or `fs.open` is missing. Ensure native `.app` bundles take precedence over loose `.exe` files in the same directory, and fallback to the canonical binary path (`Contents/MacOS/<bundle-name>`) if bundle inspection yields a null executable path, skipping unresolvable directories with a standardized diagnostic warning (`console.warn('[SCANNER][WARN] Unresolvable .app bundle at "${bundlePath}": executable missing or unreadable')`). Widen `isRecognizedExecutable` and `pickPreferredExecutable` return types to canonical `PlatformType`, and update `pickPreferredExecutable` to return `{ exePath: preferred.resolvedExePath || path.join(currentPath, preferred.name), platform: preferred.platform }` as structural pass-through plumbing.

## Explicit Assumptions & Boundaries
- Structural refactoring ($S$) establishing leaf bundle traversal, sibling game preservation, Case B native preservation, Step 2 bundle filtering, and platform type plumbing.
- 6-tier Darwin candidate ranking is implemented in `01.2.2`.
