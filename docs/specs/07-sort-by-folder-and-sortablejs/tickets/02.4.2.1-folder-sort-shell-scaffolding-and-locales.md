# 02.4.2.1 — Folder Sort Shell Scaffolding, Markup, Styles & Locales ($B$)

## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Establish static DOM shell references, UI markup, styles, and localization keys for the Variant C folder sorting feature:
1. Extend `RendererRefs` in `src/renderer/bootstrap/dom-refs.ts` with `shelfTabsWrapper: HTMLElement | null` and query `#shelf-tabs-wrapper` in `buildRendererRefs(doc)`.
2. Update `src/index.html` adding "By Folder" sort item (`<div class="sort-item" data-sort="folder" id="ui-sort-folder" data-i18n="sort_folder">By Folder</div>`) in `#sort-menu`, adding `#shelf-tabs-wrapper` as a full-width container with initial `style="display: none;"` directly beneath `<div class="header">` (after header's bottom border, before `#loading` and `#game-grid-wrapper`, strictly outside `<div class="controls">`) to prevent startup Cumulative Layout Shift (CLS) on default sort modes, and structuring `#game-grid-wrapper` for dynamic `.library-section` containers.
3. Define tokenized elevation variables in `src/styles/theme.css` (`--zIndex-section-moving: 10;`, `--zIndex-shelf-tabs: 200;`, `--zIndex-tab-drag: 500;`, `--zIndex-card-drag: 1600;`, `--zIndex-path-row-drag: 2100;`), and update `src/style.css` with CSS rules for:
   - Shelf tabs bar layout with sticky positioning (`position: sticky; top: 0; z-index: var(--zIndex-shelf-tabs, 200); background-color: var(--bg-color); border-bottom: 1px solid var(--border-color);`), active tab indicator, badges, scroll buttons (`aria-disabled="true"` styling and dynamic overflow display), `.sortable-tab-fallback` (specifying elevated stacking level `z-index: var(--zIndex-tab-drag, 500)` positioned above shelf tabs bar `z-index: var(--zIndex-shelf-tabs, 200)` and sibling tab elements, beneath header controls `z-index: 1000`), `.sortable-tab-ghost`.
   - GPU-accelerated CSS Grid accordion transitions (`grid-template-rows: 0fr <-> 1fr`), `.is-collapsed` modifier, and chevron rotation (rendered as an accessible inline vector SVG glyph with `aria-hidden="true"` matching `.icon-svg` dimensions and bound to `currentColor`), ensuring expanded sections release overflow clipping upon transition completion (when `.is-collapsed` is absent) to prevent truncating game card dropdown menus (`z-index: 2000`) and tooltips. Collapsed sections (`.is-collapsed` and `aria-expanded="false"`) suppress child interactive elements from the keyboard focus sequence and screen reader traversal via HTML `inert`, while discrete visibility transitions are governed declaratively by CSS transitions to ensure child cards remain visually rendered throughout the collapse animation without premature disappearance or imperative JavaScript timers. Include `@media (prefers-reduced-motion: reduce)` block in `src/style.css` disabling CSS transitions on accordion grid rows and chevron rotation transforms for instantaneous (0ms) state changes.
   - Folder accordion toolbar layout (`.folder-accordion-toolbar { display: flex; align-items: center; justify-content: flex-end; gap: 8px; margin: 8px 0 12px 0; padding: 0 4px; }`) and action button spacing.
   - Section reorder moving highlights (`.section-moving` with `position: relative; z-index: var(--zIndex-section-moving, 10);`) and stacking context isolation (`isolation: isolate`) on `#game-grid-wrapper` and `.library-section` containers containing child z-index escalations beneath sticky shelf tabs (`z-index: var(--zIndex-shelf-tabs, 200)`).
   - Empty folder prompt multi-column layout (`.empty-folder-prompt { grid-column: 1 / -1; min-height: 120px; border: 2px dashed var(--border-color); ... }`), hover state, `.manual-add-btn` (with explicit `type="button"`, contextual accessible name complying with WCAG 2.5.3 by containing the visible label text, and early interaction blocking), `.manual-add-btn` in-flight busy state (`aria-busy="true"`), and `.filtered-folder-empty-state`.
   - Settings paths scroll container (capped at 4 rows with stable scrollbar reservation `scrollbar-gutter: stable`), `.sortable-row-fallback`, `.sortable-row-ghost`.
   - Inline title edit input box styling (`.library-section-header .rename-input`) overriding card-level centered styling with left alignment, natural width matching header title layout, inheriting header typography (`font-weight: 600`, `font-size: inherit`), `background: var(--field-bg)`, `color: var(--text-main)`, `border: 1px solid var(--accent)`, `border-radius: 4px`, and visual harmony with section heading text.
4. Update `src/renderer/ui-text.ts` mapping `currentSortVal === 'folder'` to `d.sort_folder`.
5. Update localization files across built-in locales (`src/locales/builtins/en.json`, `ja.json`, `zh.json`) and language pack (`language-packs/packs/vi.json`) with keys:
   - Folder sorting & accordion: `sort_folder`, `all_folders`, `expand_all`, `collapse_all`, `toggle_folder`.
   - Manual game addition: `manual_add_prompt`, `add_game_to_folder`, `no_matching_games_in_folder`, `empty_folder_selecting`.
   - Shelf tabs navigation: `scroll_tabs_left`, `scroll_tabs_right`.
   - Settings drag & drop: `reorder_library_path`, `drag_to_reorder`.
   - Action & reorder error toasts and domain error codes: `toast_favorite_update_failed`, `toast_tab_reorder_failed`, `toast_path_reorder_failed`, `toast_folder_rename_failed`, `toast_manual_add_failed`, `error_target_not_found`, `error_outside_library`, `error_outside_enclosing_folder`, `error_root_level_executable`, `error_unresolvable_executable`, `error_degraded_database`.
6. Document new feature in `CHANGELOG.md` under `## [2.2.7] - working`.
