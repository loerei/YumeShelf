## What to build
Wrap the decoupled mascot widget controller in a declarative React lifecycle component:

1. **Declarative Wrapper Component (`MascotWidget.tsx`)**:
   - Create [`src/renderer/components/MascotWidget.tsx`](file:///d:/Projects/YumeShelf/src/renderer/components/MascotWidget.tsx):
     - Define and export `MascotPreferences` and `MascotWidgetProps`:
       ```typescript
       import type { UiStorageAdapter } from '../state/ui-runtime-state';

       export interface MascotPreferences {
         show?: boolean;
         scale?: number | string;
         sound?: string;
         volume?: number | string;
       }

       export interface MascotWidgetProps extends MascotPreferences {
         storage?: UiStorageAdapter;
       }
       ```
     - Declarative React component wrapping `createMascotWidget` with automated `init()` on mount and `destroy()` cleanup on unmount inside `useEffect`, passing the injected `storage` prop from `MascotWidgetProps` into `createMascotWidget({ ..., storage })` to enforce storage isolation.
     - Synchronizes declarative prop updates (`show`, `scale`, `sound`, `volume`) to the underlying controller methods (`setVisible`, `setScale`, `setSound`, `setVolume`) via dedicated `useEffect` hooks, eliminating procedural `window.dispatchEvent` / `window.addEventListener` DOM event bus anti-patterns.
     - Preserves DOM container `#mascot-widget-container`, the controller-backed `.yume-mascot-widget` `<button type="button">` (`createMascotWidget` API: `init`, `destroy`, `show`, `hide`, `setVisible`, `setScale`, `setSound`, `setVolume`, `resetPosition`), and right-click `#mascot-context-menu` interactions, keeping mascot visibility controlled solely by `MascotPreferences.show` (`setVisible`) without inventing any minimize/expand toggle state (`isMinimized` / `aria-expanded`). Ground keyboard bonk and context menu behavior explicitly in `src/renderer/mascot-widget.ts`: `createMascotWidget` attaches pointer/contextmenu listeners on `widgetEl` and handles `Enter`/`Space` bonk activation when `event.target === widgetEl` alongside `Escape` menu dismissal via `onDocumentKeyDown` (removed symmetrically in `destroy()`; or if refactored in `07.1.3.1` to a dedicated `widgetEl` `keydown` listener, removed symmetrically in `destroy()`).

2. **Vitest Unit Tests (`MascotWidget.test.tsx`)**:
   - Create tests in `src/renderer/components/MascotWidget.test.tsx` verifying:
     - Component renders DOM container `#mascot-widget-container` with `.yume-mascot-widget` as a focusable `<button type="button">` (`tabIndex` is not `-1`).
     - Calls `init()` on mount and `destroy()` on unmount.
     - Activating `Enter` / `Space` `keydown` on `.yume-mascot-widget` invokes `triggerBonk()` and produces observable state transitions (`mockStorage.getItem('yumeshelf_mascot_bonk_count') === '1'`, `.bonk-animating` class applied to `.yume-mascot-widget`, and `#yume-mascot-img` switched to the `'bonked'` asset state).
     - Dispatching `contextmenu` on `.yume-mascot-widget` toggles `#mascot-context-menu` `style.display` from `'none'` to `'flex'` (`!== 'none'`), and dispatching `Escape` returns `#mascot-context-menu` `style.display` back to `'none'`.
     - Unmounting `<MascotWidget />` invokes `destroy()` and tears down `keydown` / `contextmenu` listeners so subsequent `Enter`/`Space` or `Escape` dispatches no longer increment `yumeshelf_mascot_bonk_count` or mutate menu state.
     - `<MascotWidget storage={mockStorage} />` passes `mockStorage` to `createMascotWidget`.
     - Automated `fs.readFileSync` stylesheet check verifying `src/styles/mascot.css` declares `.yume-mascot-widget:focus-visible, .mascot-menu-reset-btn:focus-visible` with `outline: 2px solid var(--accent)`.
     - Sound playback testing utilizes a shared `createMockAudio` helper or global `Audio` stubbing to avoid unhandled HTMLMediaElement exceptions in happy-dom test environments.

## Acceptance Criteria
- [ ] `<MascotWidget />` renders `#mascot-widget-container` with `.yume-mascot-widget` as a focusable `<button type="button">` (`tabIndex` is not `-1`) and initializes mascot controller on mount, with visibility controlled solely via `MascotPreferences.show` (`setVisible`) and `#mascot-context-menu` without phantom `isMinimized` state.
- [ ] `<MascotWidget />` invokes `destroy()` on unmount, tearing down `keydown`, `contextmenu`, pointer listeners, and interval loops so subsequent `Enter`/`Space` or `Escape` dispatches no longer increment `yumeshelf_mascot_bonk_count` or mutate menu state.
- [ ] **Given** `.yume-mascot-widget` is mounted, **when** `Enter` or `Space` `keydown` is dispatched on `.yume-mascot-widget`, **then** `triggerBonk()` increments `yumeshelf_mascot_bonk_count` to `'1'` in `mockStorage`, applies `.bonk-animating` to `.yume-mascot-widget`, and switches `#yume-mascot-img` to `'bonked'` asset state; **when** `contextmenu` is dispatched on `.yume-mascot-widget`, **then** `#mascot-context-menu` `style.display` toggles from `'none'` to `'flex'` (`!== 'none'`), and `Escape` returns `style.display` back to `'none'`.
- [ ] `<MascotWidget />` exports `MascotPreferences` and `MascotWidgetProps`, synchronizing prop updates (`show`, `scale`, `sound`, `volume`) to controller methods via `useEffect` without global DOM event dispatching.
- [ ] `<MascotWidget />` passes injected `storage` prop into `createMascotWidget({ ..., storage })` to enforce isolated preference persistence.
- [ ] Mascot presentation and elevation layering integrate with `src/styles/mascot.css` declaring widget and overlay z-indices under the design token system, declaring `.yume-mascot-widget:focus-visible, .mascot-menu-reset-btn:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`, and honoring `@media (prefers-reduced-motion: reduce)` by resetting transition and animation durations to 0s for motion-sensitive users.
- [ ] Whenever a volume slider control (`<input type="range" ... />`) is rendered for mascot volume, it declares `aria-valuetext={`${volume}%`}` to provide formatted percentage clarity over raw numerical scalar values.
- [ ] All unit tests in `src/renderer/components/MascotWidget.test.tsx` pass under Vitest.
- [ ] `npm run typecheck` passes with zero errors.
