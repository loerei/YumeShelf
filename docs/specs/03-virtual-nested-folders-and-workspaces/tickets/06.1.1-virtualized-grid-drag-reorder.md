## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build

Implement pointer drag start, move, and drop on the virtualized grid container using coordinate-to-item mapping from `04.2` to support 1D reordering. Supports reordering `favoriteOrder` on Favorite Desk and intra-folder children sequence in Library mode, persisting changes atomically without folder creation or nesting logic.

## Acceptance criteria

- [ ] Implement pointer drag lifecycle (drag start, drag over, drag leave, drop) on virtualized grid cards mounted within `#virtual-folder-container` (`05.1.1.2`).
- [ ] Implement `createDragReorderController` accepting optional parameter seams: `dragGestureOptions?: DragGestureOptions`, `autoScrollOptions?: AutoScrollOptions`, `clock?: IClock`, and `showToastPillFn?: (message: string) => void` (defaulting to `showToastPill`), propagating them directly to `DragGestureTimer` and `calculateEdgeScrollVelocity` for deterministic testability, and exposing `dispose(): void` to unbind event listeners and cancel active timers.
- [ ] Consume coordinate-to-item mapping from virtualized grid windowing engine (`[NEW] src/renderer/utils/virtual-grid-windowing.ts`, `04.2`) to resolve drop target index from virtual data coordinates rather than unmounted DOM nodes.
- [ ] On "Favorite Desk" (`07.1.1`), dragging and dropping cards reorders the 1D sequence of `favoriteOrder`, collecting and dispatching canonical physical keys (`primaryInstance?.gameKey || game.gameKey`) via `electronAPI.saveFavoriteOrder`. If save fails or rejects, roll back `favoriteOrder` and display error toast via `(options?.showToastPillFn || showToastPill)('Failed to save favorites order')`. Disallow folder creation gestures or card grouping.
- [ ] In "Library" mode (`07.1.1`), dragging and dropping cards at the current navigation level reorders child nodes within `currentFolder.children`, capturing previous `virtualTree` snapshot and dispatching updates via `electronAPI.saveVirtualTree`. If save fails or rejects, roll back `virtualTree`, re-render active view, and display error toast via `(options?.showToastPillFn || showToastPill)('Failed to save folder changes')`.
- [ ] Render visual drop indicator line between cards indicating target insertion index during drag.
- [ ] Automated unit and UI tests in `src/renderer/controllers/drag-reorder.test.ts` verifying 1D reordering on Favorite Desk, intra-folder reordering in Library mode, snapshot rollback on save failure, coordinate mapping resolution across windowed viewports, and `afterEach(() => controller.dispose())` teardown.
- [ ] Execute automated drag reorder tests via `npm run test:vitest -- src/renderer/controllers/drag-reorder.test.ts` with standard output containing `'✓ renderer/controllers/drag-reorder.test.ts'` and `'Test Files  1 passed (1)'` with exit code 0.
