# 03.2.1 — Rust Playtime Helper Process Tree Traversal Pure Seam ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Extract the pure graph traversal logic in `native/playtime-helper/src/main.rs` into a decoupled, platform-agnostic function `pid_tree_has_live_members_from_relations(root_pid: u32, relations: &[(u32, u32)]) -> bool` with pre-allocated capacity (`HashSet::with_capacity(relations.len())`, `HashMap::with_capacity(relations.len())`), immediate return `false` on empty relations, and bounded traversal depth (`MAX_TREE_DEPTH = 128`). This separates the process graph search algorithm from OS-specific process enumeration APIs (`libproc`, `sysctl`, `CreateToolhelp32Snapshot`, `/proc`).

## Explicit Assumptions & Boundaries
- Pure structural refactoring ($S$) operating in-memory on tuples of `(pid, ppid)`.
- Enables 100% deterministic unit testing on CI without needing live OS process trees.
