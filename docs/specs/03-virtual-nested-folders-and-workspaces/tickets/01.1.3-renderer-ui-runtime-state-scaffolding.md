## What to build
Extend the centralized reactive UI runtime state store (`UiRuntimeState`) in `src/renderer/state/ui-runtime-state.ts` and controller bindings in `src/renderer/bootstrap/app-composition.ts` with getters, setters, and subscriptions for `virtualTree`, `favoriteOrder`, `currentPath`, and `activeWorkspaceMode`.

## Acceptance criteria
- [ ] Extend `UiRuntimeState` typedef and interface in `src/renderer/state/ui-runtime-state.ts`, preserving all existing state accessors actively utilized across `src/renderer/bootstrap/app-composition.ts` and `src/renderer/library/runtime.ts` and adding virtual tree, workspace accessors, $O(1)$ indexed entity lookups, and typed reactive subscriptions:
  ```typescript
  export interface DragTargetInfo {
    id?: string;
    type?: string;
  }

  export type UiStateKey =
    | 'virtualTree'
    | 'favoriteOrder'
    | 'currentPath'
    | 'activeWorkspaceMode'
    | 'allGames'
    | 'currentSort';

  export interface UiRuntimeState {
    // Existing State Accessors
    getAllGames: () => any[];
    setAllGames: (games: any[]) => void;
    getCategoryTree: () => any[];
    setCategoryTree: (tree: any[]) => void;
    getActiveCategoryId: () => string | null;
    setActiveCategoryId: (value: string | null) => void;
    getCurrentLibraryConfig: () => any;
    setCurrentLibraryConfig: (config: any) => void;
    getDraggedGameFolder: () => string | null;
    setDraggedGameFolder: (value: string | null) => void;
    getDragTargetInfo: () => DragTargetInfo | null;
    setDragTargetInfo: (value: DragTargetInfo | null) => void;
    getCurrentSort: () => string;
    setCurrentSort: (sort: string) => void;

    // Virtual Tree & Workspace Accessors
    getVirtualTree: () => VirtualFolderNode | null;
    setVirtualTree: (tree: VirtualFolderNode | null) => void;
    getFavoriteOrder: () => string[];
    setFavoriteOrder: (order: string[]) => void;
    getCurrentPath: () => string[];
    setCurrentPath: (path: string[]) => void;
    getActiveWorkspaceMode: () => 'favorites' | 'library';
    setActiveWorkspaceMode: (mode: 'favorites' | 'library') => void;

    // O(1) Indexed Entity Accessors
    getGameByKey: (gameKey: string) => any | undefined;
    getGamesMap: () => ReadonlyMap<string, any>;

    // Subscriptions
    subscribe: (listener: (key: UiStateKey, value: any) => void) => () => void;
    onVirtualTreeChange: (listener: (tree: VirtualFolderNode | null) => void) => () => void;
    onWorkspaceModeChange: (listener: (mode: 'favorites' | 'library') => void) => () => void;
    onCurrentPathChange: (listener: (path: string[]) => void) => () => void;
    onFavoriteOrderChange: (listener: (order: string[]) => void) => () => void;
    onAllGamesChange: (listener: (games: any[]) => void) => () => void;
    onCurrentSortChange: (listener: (sort: string) => void) => () => void;
  }
  ```
  Ensure `DragTargetInfo` is exported from `src/renderer/state/ui-runtime-state.ts`.
  Guard any browser storage access via `typeof localStorage !== 'undefined' ? localStorage.getItem(...) : null` to preserve headless/Node testability.
- [ ] Implement getters, setters, and subscriptions on the `createUiRuntimeState()` instance. Maintain a cached `Map<string, any>` populated during `setAllGames(games)` indexing each game under `game.gameKey`, `game.id`, and all secondary instance keys (`game.instances?.forEach(inst => map.set(inst.gameKey, game))`) to eliminate $O(N)$ linear scans in hot paths (`partitionSortChildren`, folder preview extraction, windowed hit testing, global search).
- [ ] In `setVirtualTree`, `setFavoriteOrder`, `setCurrentPath`, `setActiveWorkspaceMode`, `setCurrentSort`, and `setAllGames`, notify registered listeners synchronously (`notifyListeners('currentSort', value)`).
- [ ] Pass state accessors into `startupControllerOptions` within `src/renderer/bootstrap/app-composition.ts`.
- [ ] Author automated unit tests in `src/renderer/state/ui-runtime-state.test.ts` verifying state mutations, $O(1)$ map lookups, synchronous listener firing (`onAllGamesChange`, `onVirtualTreeChange`, `onWorkspaceModeChange`, `onCurrentPathChange`, `onFavoriteOrderChange`, `onCurrentSortChange`), and listener deregistration via returned unsubscribe closures, configuring an isolated in-memory `mockLocalStorage` fixture in `beforeEach` / `afterEach`.
