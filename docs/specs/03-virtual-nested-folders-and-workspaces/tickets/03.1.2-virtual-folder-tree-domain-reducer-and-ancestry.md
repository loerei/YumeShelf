  Export 1-based level span helper `getSubtreeFolderDepth(folder: VirtualFolderNode): number`:
  ```typescript
  /**
   * Computes the virtual folder level span of the subtree rooted at folder.
   * A folder with no child subfolders returns 1 (representing its own level).
   * A folder with nested subfolders returns 1 + max(childFolderDepths).
   */
  export function getSubtreeFolderDepth(folder: VirtualFolderNode): number {
    let maxChildFolderDepth = 0;
    for (const child of folder.children) {
      if (child.type === 'folder') {
        maxChildFolderDepth = Math.max(maxChildFolderDepth, getSubtreeFolderDepth(child));
      }
    }
    return 1 + maxChildFolderDepth;
  }
  ```
  Explicitly specify that `getSubtreeFolderDepth` returns a minimum of `1` for any folder node (representing its own level). Accept `TreeManagerOptions` (defaulting to `DEFAULT_TREE_MANAGER_OPTIONS` from `03.1.1`).
- [ ] Implement `createFolder(tree, name, targetItemKeysOrIds, parentFolderId?: string, options?: TreeManagerOptions): CreateFolderResult` enforcing atomic two-phase staging (Pre-flight Validation -> Mutation) to ensure items are NEVER detached before destination container and depth validation succeed:
  - **Phase 1: Ingress & Pre-Flight Validation (Zero Mutations)**:
    1. Ingress validation:
       ```typescript
       if (!Array.isArray(targetItemKeysOrIds) || targetItemKeysOrIds.length === 0) {
         return { ok: false, error: 'empty-targets', folder: null };
       }
       ```
    2. Name validation: validate `name` (falling back safely to `'New Folder'` if empty or whitespace-only).
    3. Parent container resolution: resolve `parentFolderId` (defaulting to `'root'`). Verify that `parentFolder` exists in `tree` and `parentFolder.type === 'folder'`. If not, return `{ ok: false, error: 'invalid-parent-folder', folder: null }`.
    4. Parent depth bounds check: verify `parentFolderDepth + 1 <= maxDepth`.
    5. Root target boundary check: if `targetItemKeysOrIds.includes('root') || (tree.id && targetItemKeysOrIds.includes(tree.id))`, abort immediately with `{ ok: false, error: 'invalid-target-root', folder: null }` without mutating tree state.
    6. Target item resolution: resolve all existing nodes in `tree` matching `targetItemKeysOrIds`.
    7. Ancestry & cycle check: if resolved target items contain folders, ensure none is `parentFolder` or an ancestor of `parentFolder`. Verify each target folder's subtree depth satisfies `(parentFolderDepth + 1) + getSubtreeFolderDepth(targetFolder) <= maxDepth`.
    8. Zero-child guard: if 0 target items resolve in `tree`, abort immediately with `{ ok: false, error: 'empty-folder-not-allowed', folder: null }` without mutating tree state.
  - **Phase 2: Atomic Mutation & Pruning**:
    1. Detach the resolved target items from their source parent folders.
    2. Instantiate `newFolder: VirtualFolderNode` containing the resolved items in `newFolder.children`.
    3. Insert `newFolder` into `parentFolder.children`.
    4. Execute `pruneEmptyFolders(tree)` (preserving root container) to automatically dissolve any parent folders left empty by moving the grouped items.
    5. Return `{ ok: true, folder: newFolder }`.
