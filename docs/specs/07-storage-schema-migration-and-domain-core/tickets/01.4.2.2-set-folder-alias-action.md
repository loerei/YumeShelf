## Epic

## What to build
Implement vertical slice for folder title alias persistence across domain logic, facade binding, IPC contract, preload bridge, and controller handler:
1. Signature and Domain Action in `src/main/library-state/actions.ts`:
   ```typescript
   export async function setFolderAlias(
     context: LibraryContextInternal,
     folderPath: string,
     alias: string,
     targetPlatform?: PlatformInput
   ): Promise<{ ok: boolean; config?: LibraryConfig; error?: string }>
   ```
   At entry, enforces defensive input validation: computes `const canonicalFolderPath = typeof folderPath === 'string' ? normalizePathForPlatform(folderPath, targetPlatform) : '';` and if `typeof folderPath !== 'string' || !folderPath.trim() || /\0|\r|\n/.test(folderPath) || ['__proto__', 'constructor', 'prototype'].includes(folderPath.trim()) || !canonicalFolderPath || ['__proto__', 'constructor', 'prototype'].includes(canonicalFolderPath)`, fails fast immediately logging `console.warn('[SECURITY][SET_FOLDER_ALIAS] Blocked invalid folder path containing illegal characters or unsafe key:', { folderPath });` and returning `{ ok: false, error: 'invalid-folder-path' }`.
2. Dual degraded database guard:
   - Checks `if (context.isDegraded?.() === true)` at entry and immediately after `await context.loadDB()`, logging structured diagnostic warning:
     ```typescript
     if (context.isDegraded?.() === true) {
       console.warn('[LIBRARY_STATE][SET_FOLDER_ALIAS] Operation aborted: database is in DEGRADED state', { folderPath, alias });
       return { ok: false, error: 'degraded-database' };
     }
     ```
3. Database load and config normalization pre-step:
   - Loads current database snapshot: `const db = await context.loadDB();`
   - Re-checks `if (context.isDegraded?.() === true)` emitting the same structured warning and returning `{ ok: false, error: 'degraded-database' }`.
   - Normalizes config shape: `const config = normalizeLibraryConfigShape(db.config, targetPlatform);`
4. Prototype safety:
   - Rejects or strips prototype pollution keys (`__proto__`, `constructor`, `prototype`) across both raw `folderPath.trim()` and post-normalization `canonicalFolderPath = normalizePathForPlatform(folderPath, targetPlatform)` (blocking relative, case-variant, and trailing-slash bypasses such as `./__proto__`, `foo/../constructor`, `__PROTO__`, and `prototype/`).
5. Boundary validation:
   - Derives `canonicalFolderPath = normalizePathForPlatform(folderPath, targetPlatform)`.
   - Pre-indexes pre-existing canonical keys in `config.folderAliases`:
     ```typescript
     const preExistingCanonicalKeys = new Set(Object.keys(config.folderAliases || {}).map(k => normalizePathForPlatform(k, targetPlatform)));
     const isPreExisting = preExistingCanonicalKeys.has(canonicalFolderPath);
     ```
   - Boundary containment check via `isSubsumedBy(canonicalFolderPath, root, targetPlatform)` against `config.libraryPaths` MUST ONLY evaluate newly introduced alias keys (`!isPreExisting`), permitting callers to clear (`alias = ""`) or update durable tombstones for folders whose enclosing library roots have been disconnected or removed.
   - Rejects newly introduced paths outside library roots with `{ ok: false, error: 'outside-library' }`, logging diagnostic warning `console.warn('[SECURITY][SET_FOLDER_ALIAS] Blocked unauthorized folder path outside library roots:', { folderPath });`.
6. Canonicalization & Input Sanitization:
   - Canonicalizes `folderPath` using `normalizePathForPlatform(folderPath, targetPlatform)` when indexing and saving keys in `config.folderAliases`.
   - Enforces safe string coercion (`const rawAlias = typeof alias === 'string' ? alias : '';`), bounds `rawAlias` to maximum 255 characters, strips non-printable/newline control characters (`[\r\n\t\x00-\x1f]`), and trims whitespace.
   - If empty after trim, safely deletes the canonical folder key from `folderAliases` using `delete config.folderAliases[canonicalFolderPath]` only after confirming it is an own property (`Object.prototype.hasOwnProperty.call`) to allow clean fallback to `getFolderBaseName(folderPath)`.
7. Atomic persistence, snapshot rollback, & error boundary:
   - Snapshot in-memory `folderAliases` before mutation: `const previousAliases = { ...(config.folderAliases || {}) };`.
   - Assigns `db.config = config;` and triggers atomic save via `await (context.persistDbDirectly || context.saveDB)(db)` wrapped in a `try ... catch` persistence error boundary. On success, returns `{ ok: true, config }`. On persistence rejection or I/O failure, restores `config.folderAliases = previousAliases;`, logs structured diagnostics `console.error('[LIBRARY_STATE][SET_FOLDER_ALIAS] Failed to persist folder alias:', { folderPath, alias, error: err })` and safely returns `{ ok: false, error: err instanceof Error ? err.message : String(err) }`, preventing unhandled promise rejections across IPC or in-memory state desynchronization.
7. Facade Binding in `src/main/library-state/index.ts`:
   - Re-export `setFolderAlias` from `./actions`.
   - Bind `setFolderAlias` on `createLibraryState` wrapped in `serializedQueue`:
     ```typescript
     setFolderAlias: (folderPath: string, alias: string, targetPlatform?: PlatformInput) =>
       serializedQueue(() => setFolderAlias(context, folderPath, alias, targetPlatform)),
     ```
8. IPC Contract & Preload Bridge:
   - Declare on `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     setFolderAlias(folderPath: string, alias: string): Promise<{ ok: boolean; config?: LibraryConfig; error?: string }>;
     ```
   - Expose in `src/preload.ts`:
     ```typescript
     setFolderAlias: (folderPath, alias) => ipcRenderer.invoke('library:set-folder-alias', { folderPath, alias }),
     ```
9. IPC Controller Handler in `src/main/ipc/controllers/library.controller.ts`:
   - Register `library:set-folder-alias` normalizing incoming transport payload at the membrane boundary: validate that `payload` is a non-null object with string properties (`folderPath`, `alias`), returning `{ ok: false, error: 'invalid-payload' }` on malformed payloads before delegating to `libraryState.setFolderAlias(payload.folderPath, payload.alias)`.

Author Vitest unit tests in `src/main/library-state/actions-alias.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
