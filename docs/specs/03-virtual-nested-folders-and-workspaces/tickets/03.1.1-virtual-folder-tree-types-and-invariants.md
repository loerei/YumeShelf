# 03.1.1 — Shared Virtual Tree Types and Structural Invariants

## Epic
PRD 03: Virtual Nested Folders (App Folders) & Dual Workspace Views ("Favorite Desk" vs "Library")

## What to build
Author `[NEW] src/shared/virtual-tree/types.ts` and `[NEW] src/shared/virtual-tree/invariants.ts` exporting tree node interfaces (`VirtualFolderNode`, `VirtualGameRefNode`, `AncestryItem`), tree configuration options (`TreeManagerOptions`), and pure structural validation predicates (cycle detection, root immutability, depth clamping <= 16, folder name length <= 100).

## Acceptance criteria
- [ ] Author `[NEW] src/shared/virtual-tree/types.ts` (or `src/shared/types/clock.ts`) exporting `VirtualFolderNode`, `VirtualGameRefNode`, `AncestryItem`, `TreeManagerOptions { maxDepth?: number; maxNameLength?: number; maxTotalNodes?: number; idGenerator?: () => string; now?: () => number }`, `IClock`, `MockClock`, and shared test utility factory `createMockClock(): MockClock` (advancing queued animation callbacks in discrete, bounded 16ms frame steps).
- [ ] Author `[NEW] src/shared/virtual-tree/invariants.ts` exporting validation functions: `validateNodeName`, `isRootNode`, `detectCycle`, `assertDepthWithinBounds`, `assertUniqueFolderIds`, `assertUniqueGameKeys`, `assertNoPrototypePollution`, and composite `validateTreeInvariants(tree: unknown, options?: TreeManagerOptions): { ok: boolean; error?: string }` enforcing top-level root container invariance via `isRootNode(tree)` (`isPlainObject(tree) === true`, `tree.type === 'folder'`, `tree.id === 'root'`, returning `{ ok: false, error: 'invalid-root-node' }` if invalid), visited object reference tracking via `visited = new Set<unknown>()` (returning `{ ok: false, error: 'cyclic-tree-detected' }` on repeated references to intercept cycles and prevent stack overflow DoS), recursion depth ceiling enforcement (`depth <= (options?.maxDepth || 16)`, returning `{ ok: false, error: 'max-depth-exceeded' }`), recursive node schema and types (`'folder'` vs `'game'`), safe identifier constraints on `node.id` matching `^[a-zA-Z0-9_-]+$` (length <= 100) to prevent DOM attribute injection and CSS selector errors, name sanitization, control character sanitization on `node.gameKey` (rejecting ASCII control characters `\0`, `\r`, `\n` and prototype keys), disjoint namespace enforcement between folder IDs and game keys (rejecting any `gameKey` equal to `'root'`, `tree.id`, or matching an existing folder `id` with `{ ok: false, error: 'identifier-collision-detected' }`), string/array bounds, finite `dateCreated` numbers, cumulative node ceiling (`maxTotalNodes: 10000`), structural graph invariants, and strict rejection of prototype keys (`__proto__`, `constructor`, `prototype`) on `node.id` as well as `node.gameKey`.
- [ ] Automated unit tests in `tests/virtual-tree-invariants.test.js` verifying tree type compliance, cycle detection on arbitrary directed graphs, depth bounds clamping, name validation, folder ID uniqueness, safe `node.id` regex pattern enforcement (`^[a-zA-Z0-9_-]+$`), game key uniqueness, prototype pollution detection (including `node.id` matching prototype properties), node schema type validation, and composite `validateTreeInvariants` assertions.
- [ ] Execute automated invariant unit tests via `npm run test:single -- tests/virtual-tree-invariants.test.js` with standard output containing `'✔ VirtualTree invariants'` and `'ℹ pass 12'` with exit code 0.
