# 05.2 — Tool Settings & Credential Configuration Modal

## Epic
PRD 04: Community Add-on Marketplace, Task Runner & Cascading Tool Manager

## What to build
The per-tool settings and credential configuration modal: dynamic form generation from `manifest.configSchema` and `manifest.credentialsSchema`, testing credentials against the Main process API, and saving encrypted tokens via `CredentialVaultService`.

## Explicit Assumptions & Boundaries
- Plaintext credentials are transmitted across IPC only during active user saves and tested strictly in the Main process; never persisted in cleartext.

- [ ] Dynamically render form fields based on `manifest.configSchema` (text, select, boolean, number) and `manifest.credentialsSchema` (masked password inputs).
