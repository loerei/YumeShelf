# 02.2.1.1 — Bundle Root Resolution Seam, Stem & effectiveDir Integration ($S$)

## Epic
PRD: Codebase Readiness for MultiOS Platform Support

## What to build
Import `resolveBundleRoot` from `../bundle/app-bundle-inspector.js` in `packages/yume-engine/src/save-resolvers/index.ts`. Update `getExeStem(exePath: string, bundleRoot?: string | null): string` in `packages/yume-engine/src/save-resolvers/path-utils.ts` to accept optional `bundleRoot`, computing stem from `baseName(bundleRoot, '.app')` when provided or when `baseName(exePath).endsWith('.app')`, normalizing trailing slashes, and sanitizing stems by stripping path separators, null bytes (`\0`, `%00`), and traversal tokens to prevent circular module dependencies and path traversal risks. In `packages/yume-engine/src/save-resolvers/index.ts`, compute `effectiveDir = bundleRoot || dirName(exePath)` and pass `effectiveDir` as the directory argument across all child save resolvers (`resolveRpgMakerSave`, `resolveRenPySave`, `resolveUnitySave`, `resolveUnrealSave`, `resolveGodotSave`, `resolveUserProfileSave`, `heuristicSaveScan`, `appDataFuzzyMatch`).

## Explicit Assumptions & Boundaries
- Pure structural refactoring ($S$) integrating the bundle root detection seam across the save resolution subsystem.
- Decoupled from `02.1` environment paths interface.
