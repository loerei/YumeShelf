# 01.4.2.2 — Set Folder Alias Domain Action & IPC Integration ($B$)

## Epic
PRD: Sort By Folder (Variant C) & Game Card Drag-Drop Migration to SortableJS

## What to build
Implement vertical slice for folder title alias persistence across domain logic, facade binding, IPC contract, preload bridge, and controller handler:
1. Signature and Domain Action in `src/main/library-state/actions.ts`:
   ```typescript
   export async function setFolderAlias(
     context: LibraryContextInternal,
     folderPath: string,
     alias: string,
     targetPlatform?: PlatformInput
   ): Promise<{ ok: boolean; config?: LibraryConfig; error?: string }>
   ```
2. Dual degraded database guard:
   - Checks `if (context.isDegraded?.() === true)` at entry and immediately after `await context.loadDB()`, safely aborting and returning `{ ok: false, error: 'degraded-database' }`.
3. Database load and config normalization pre-step:
   - Loads current database snapshot: `const db = await context.loadDB();`
   - Re-checks `if (context.isDegraded?.() === true)` returning `{ ok: false, error: 'degraded-database' }`.
   - Normalizes config shape: `const config = normalizeLibraryConfigShape(db.config, targetPlatform);`
4. Prototype safety:
   - Rejects or strips prototype pollution keys (`__proto__`, `constructor`, `prototype`).
5. Boundary validation:
   - Validates that `folderPath` resides within at least one configured directory in `config.libraryPaths` using `isSubsumedBy` from `src/shared/path-subsumption.ts`. Rejects paths outside library roots with `{ ok: false, error: 'outside-library' }`, logging diagnostic warning `console.warn('[SECURITY][SET_FOLDER_ALIAS] Blocked unauthorized folder path outside library roots:', { folderPath });`.
6. Canonicalization & Input Sanitization:
   - Canonicalizes `folderPath` using `normalizePathForPlatform(folderPath, targetPlatform)` when indexing and saving keys in `config.folderAliases`.
   - Bounds `alias` to maximum 255 characters, strips non-printable/newline control characters (`[\r\n\t\x00-\x1f]`), and trims whitespace.
   - If empty after trim, safely deletes the canonical folder key from `folderAliases` using `delete config.folderAliases[folderKey]` only after confirming it is an own property (`Object.prototype.hasOwnProperty.call`) to allow clean fallback to `getFolderBaseName(folderPath)`.
7. Atomic persistence, snapshot rollback, & error boundary:
   - Snapshot in-memory `folderAliases` before mutation: `const previousAliases = { ...(config.folderAliases || {}) };`.
   - Assigns `db.config = config;` and triggers atomic save via `await (context.persistDbDirectly || context.saveDB)(db)` wrapped in a `try ... catch` persistence error boundary. On success, returns `{ ok: true, config }`. On persistence rejection or I/O failure, restores `config.folderAliases = previousAliases;`, logs structured diagnostics `console.error('[LIBRARY_STATE][SET_FOLDER_ALIAS] Failed to persist folder alias:', { folderPath, alias, error: err })` and safely returns `{ ok: false, error: err instanceof Error ? err.message : String(err) }`, preventing unhandled promise rejections across IPC or in-memory state desynchronization.
7. Facade Binding in `src/main/library-state/index.ts`:
   - Re-export `setFolderAlias` from `./actions`.
   - Bind `setFolderAlias` on `createLibraryState` wrapped in `serializedQueue`:
     ```typescript
     setFolderAlias: (folderPath: string, alias: string, targetPlatform?: PlatformInput) =>
       serializedQueue(() => setFolderAlias(context, folderPath, alias, targetPlatform)),
     ```
8. IPC Contract & Preload Bridge:
   - Declare on `ElectronAPI` in `src/shared/types/ipc.d.ts`:
     ```typescript
     setFolderAlias(folderPath: string, alias: string): Promise<{ ok: boolean; config?: LibraryConfig; error?: string }>;
     ```
   - Expose in `src/preload.ts`:
     ```typescript
     setFolderAlias: (folderPath, alias) => ipcRenderer.invoke('library:set-folder-alias', { folderPath, alias }),
     ```
9. IPC Controller Handler in `src/main/ipc/controllers/library.controller.ts`:
   - Register `library:set-folder-alias` delegating to `libraryState.setFolderAlias(payload.folderPath, payload.alias)`.

Author Vitest unit tests in `src/main/library-state/actions.test.ts` and `src/main/ipc/controllers/library.controller.test.ts`.
